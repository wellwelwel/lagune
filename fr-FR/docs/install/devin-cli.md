# Installer Lagune comme plugin sur Devin CLI

> Installez Lagune comme plugin sur Devin CLI, et gardez-le à jour.

Canonique: https://lagune.ai/fr-FR/docs/install/devin-cli
Langue: fr-FR
Original: https://lagune.ai/docs/install/devin-cli
Dernière mise à jour: 2026-11-03

Connectez-vous à **Devin**, puis installez le plugin depuis votre terminal :

```bash
devin auth login
devin plugins install wellwelwel/lagune
```

## Mise à jour

Pour mettre à jour **Lagune**, exécutez :

```bash
devin plugins update lagune
```

## Commandes

Tapez les commandes sous le nom du plugin, comme `/lagune:lagune-charter` pour `/lagune-charter`. Le menu `/` les liste aussi.
