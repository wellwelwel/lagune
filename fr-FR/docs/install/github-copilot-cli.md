# Installer Lagune comme plugin sur GitHub Copilot CLI

> Installez Lagune comme plugin sur GitHub Copilot CLI, et gardez-le à jour.

Canonique: https://lagune.ai/fr-FR/docs/install/github-copilot-cli
Langue: fr-FR
Original: https://lagune.ai/docs/install/github-copilot-cli
Dernière mise à jour: 2026-11-05

Installez le plugin depuis votre terminal :

```bash
copilot plugin marketplace add wellwelwel/lagune
copilot plugin install lagune@lagune
```

Dans un éditeur, installez **Lagune** pour **GitHub Copilot** avec [**skills.sh**](https://lagune.ai/fr-FR/docs/install/universal).

## Mise à jour

Pour mettre à jour **Lagune**, exécutez :

```bash
copilot plugin marketplace update lagune
copilot plugin update lagune@lagune
```

## Commandes

Tapez les commandes par leur nom, comme `/lagune-charter`.

## Questions fréquentes

### Comment installer Lagune sur GitHub Copilot CLI ?

Exécutez copilot plugin marketplace add wellwelwel/lagune, puis copilot plugin install lagune@lagune.

### Comment mettre à jour Lagune sur GitHub Copilot CLI ?

Exécutez copilot plugin marketplace update lagune, puis copilot plugin update lagune@lagune.

### Comment exécuter les commandes de Lagune sur GitHub Copilot CLI ?

Tapez-les par leur nom, comme /lagune-charter.

### Puis-je utiliser Lagune avec GitHub Copilot dans VS Code ?

Oui. Dans VS Code ou un autre éditeur, installez Lagune avec skills.sh plutôt qu'avec le plugin.
