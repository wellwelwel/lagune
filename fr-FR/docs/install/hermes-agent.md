# Installer Lagune comme plugin sur Hermes Agent

> Installez Lagune comme plugin sur Hermes Agent, et gardez-le à jour.

Canonique: https://lagune.ai/fr-FR/docs/install/hermes-agent
Langue: fr-FR
Original: https://lagune.ai/docs/install/hermes-agent
Dernière mise à jour: 2026-11-04

Installez le plugin depuis votre terminal :

```bash
hermes plugins install wellwelwel/lagune --enable
```

- Quand **Hermes Agent** vous demande de confirmer un plugin extérieur à son catalogue, **confirmez-le**.
- Quand il propose d'installer les dépendances **Node.js** du dépôt, **refusez**.

## Mise à jour

Pour mettre à jour **Lagune**, exécutez :

```bash
hermes plugins update lagune
```

## Commandes

Tapez les commandes sous le nom du plugin, comme `/lagune:lagune-charter` pour `/lagune-charter` et `/lagune:lagune` pour `/lagune`.
