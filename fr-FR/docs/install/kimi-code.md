# Installer Lagune comme plugin sur Kimi Code

> Installez Lagune comme plugin sur Kimi Code, et gardez-le à jour.

Canonique: https://lagune.ai/fr-FR/docs/install/kimi-code
Langue: fr-FR
Original: https://lagune.ai/docs/install/kimi-code
Dernière mise à jour: 2026-11-05

Installez le plugin depuis une session **Kimi Code**, choisissez **Trust and install**, puis démarrez une nouvelle session pour le charger :

```text
/plugins install https://github.com/wellwelwel/lagune
/new
```

## Mise à jour

Pour mettre à jour **Lagune**, installez-le de nouveau :

```text
/plugins install https://github.com/wellwelwel/lagune
/new
```

## Commandes

Tapez les commandes sous le nom du plugin, comme `/lagune:lagune-charter` pour `/lagune-charter`. Le menu `/` les liste sous la forme `/skill:lagune:lagune-charter`, qui fonctionne aussi.

## Questions fréquentes

### Comment installer Lagune sur Kimi Code ?

Dans une session Kimi Code, exécutez /plugins install https://github.com/wellwelwel/lagune, choisissez Trust and install, puis exécutez /new.

### Comment mettre à jour Lagune sur Kimi Code ?

Exécutez de nouveau /plugins install https://github.com/wellwelwel/lagune, puis /new.

### Comment exécuter les commandes de Lagune sur Kimi Code ?

Tapez-les sous le nom du plugin, comme /lagune:lagune-charter, ou comme les liste le menu /, comme /skill:lagune:lagune-charter.
