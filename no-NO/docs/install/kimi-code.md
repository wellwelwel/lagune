# Installer Lagune som plugin i Kimi Code

> Installer Lagune som plugin i Kimi Code og hold det oppdatert.

Kanonisk URL: https://lagune.ai/no-NO/docs/install/kimi-code
Språk: no-NO
Original: https://lagune.ai/docs/install/kimi-code
Sist oppdatert: 2026-11-09

Installer pluginen fra en økt i **Kimi Code**, velg **Trust and install**, og start deretter en ny økt for å laste den inn:

```prompt
/plugins install https://github.com/wellwelwel/lagune
/new
```

## Oppdatering

Installer **Lagune** på nytt for å oppdatere det:

```prompt
/plugins install https://github.com/wellwelwel/lagune
/new
```

## Kommandoer

Skriv inn kommandoene med navnet på pluginen foran, for eksempel `/lagune:lagune-charter` for `/lagune-charter`. Menyen `/` viser dem som `/skill:lagune:lagune-charter`, og det fungerer også.

## Vanlige spørsmål

### Hvordan installerer jeg Lagune i Kimi Code?

Kjør /plugins install https://github.com/wellwelwel/lagune i en økt i Kimi Code, velg Trust and install, og kjør deretter /new.

### Hvordan oppdaterer jeg Lagune i Kimi Code?

Kjør /plugins install https://github.com/wellwelwel/lagune på nytt, deretter /new.

### Hvordan kjører jeg kommandoene til Lagune i Kimi Code?

Skriv dem inn med navnet på pluginen foran, for eksempel /lagune:lagune-charter, eller slik menyen / viser dem, for eksempel /skill:lagune:lagune-charter.
