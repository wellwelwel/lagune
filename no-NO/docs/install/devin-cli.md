# Installer Lagune som plugin i Devin CLI

> Installer Lagune som plugin i Devin CLI og hold den oppdatert.

Kanonisk URL: https://lagune.ai/no-NO/docs/install/devin-cli
Språk: no-NO
Original: https://lagune.ai/docs/install/devin-cli
Sist oppdatert: 2026-11-09

Logg inn på **Devin**, og installer deretter pluginen fra terminalen:

```bash
devin auth login
devin plugins install wellwelwel/lagune
```

## Oppdatering

Oppdater **Lagune** ved å kjøre:

```bash
devin plugins update lagune
```

## Kommandoer

Skriv kommandoene med navnet på pluginen foran, for eksempel `/lagune:lagune-charter` for `/lagune-charter`. Menyen `/` viser dem også.
