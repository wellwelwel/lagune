# Installer Lagune som plugin i GitHub Copilot CLI

> Installer Lagune som plugin i GitHub Copilot CLI og hold det oppdatert.

Kanonisk URL: https://lagune.ai/no-NO/docs/install/github-copilot-cli
Språk: no-NO
Original: https://lagune.ai/docs/install/github-copilot-cli
Sist oppdatert: 2026-11-09

Installer pluginen fra terminalen:

```bash
copilot plugin marketplace add wellwelwel/lagune
copilot plugin install lagune@lagune
```

I en editor installerer du **Lagune** for **GitHub Copilot** med [**skills.sh**](https://lagune.ai/no-NO/docs/install/universal).

## Oppdatering

Kjør følgende for å oppdatere **Lagune**:

```bash
copilot plugin marketplace update lagune
copilot plugin update lagune@lagune
```

## Kommandoer

Skriv inn kommandoene med navn, for eksempel `/lagune-charter`.

## Vanlige spørsmål

### Hvordan installerer jeg Lagune i GitHub Copilot CLI?

Kjør copilot plugin marketplace add wellwelwel/lagune, deretter copilot plugin install lagune@lagune.

### Hvordan oppdaterer jeg Lagune i GitHub Copilot CLI?

Kjør copilot plugin marketplace update lagune, deretter copilot plugin update lagune@lagune.

### Hvordan kjører jeg kommandoene til Lagune i GitHub Copilot CLI?

Skriv dem inn med navn, for eksempel /lagune-charter.

### Kan jeg bruke Lagune med GitHub Copilot i VS Code?

Ja. I VS Code eller en annen editor installerer du Lagune med skills.sh i stedet for pluginen.
