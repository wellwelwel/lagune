# Installer Lagune som plugin i Hermes Agent

> Installer Lagune som plugin i Hermes Agent og hold det oppdatert.

Kanonisk URL: https://lagune.ai/no-NO/docs/install/hermes-agent
Språk: no-NO
Original: https://lagune.ai/docs/install/hermes-agent
Sist oppdatert: 2026-11-09

Installer pluginen fra terminalen:

```bash
hermes plugins install wellwelwel/lagune --enable
```

- Når **Hermes Agent** ber deg bekrefte en plugin utenfor katalogen sin, **bekreft den**.
- Når den tilbyr å installere avhengighetene for **Node.js** i repositoryet, **avslå**.

## Oppdatering

Kjør følgende for å oppdatere **Lagune**:

```bash
hermes plugins update lagune
```

## Kommandoer

Skriv inn kommandoene med navnet på pluginen foran, for eksempel `/lagune:lagune-charter` for `/lagune-charter` og `/lagune:lagune` for `/lagune`.
