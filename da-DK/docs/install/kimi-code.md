# Installér Lagune i Kimi Code som et plugin

> Installér Lagune i Kimi Code som et plugin, og hold det opdateret.

Kanonisk URL: https://lagune.ai/da-DK/docs/install/kimi-code
Sprog: da-DK
Original: https://lagune.ai/docs/install/kimi-code
Sidst opdateret: 2026-11-09

Installér pluginnet fra en session i **Kimi Code**, vælg **Trust and install**, og start derefter en ny session for at indlæse det:

```prompt
/plugins install https://github.com/wellwelwel/lagune
/new
```

## Opdatering

Installér **Lagune** igen for at opdatere det:

```prompt
/plugins install https://github.com/wellwelwel/lagune
/new
```

## Kommandoer

Skriv kommandoerne under pluginnets navn, såsom `/lagune:lagune-charter` for `/lagune-charter`. Menuen `/` viser dem som `/skill:lagune:lagune-charter`, hvilket også virker.

## Ofte stillede spørgsmål

### Hvordan installerer jeg Lagune i Kimi Code?

I en session i Kimi Code kører du /plugins install https://github.com/wellwelwel/lagune, vælger Trust and install og kører derefter /new.

### Hvordan opdaterer jeg Lagune i Kimi Code?

Kør /plugins install https://github.com/wellwelwel/lagune igen og derefter /new.

### Hvordan kører jeg kommandoerne i Lagune i Kimi Code?

Skriv dem under pluginnets navn, såsom /lagune:lagune-charter, eller som menuen / viser dem, såsom /skill:lagune:lagune-charter.
