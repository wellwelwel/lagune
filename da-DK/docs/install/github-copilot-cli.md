# Installér Lagune i GitHub Copilot CLI som et plugin

> Installér Lagune i GitHub Copilot CLI som et plugin, og hold det opdateret.

Kanonisk URL: https://lagune.ai/da-DK/docs/install/github-copilot-cli
Sprog: da-DK
Original: https://lagune.ai/docs/install/github-copilot-cli
Sidst opdateret: 2026-11-09

Installér pluginnet fra din terminal:

```bash
copilot plugin marketplace add wellwelwel/lagune
copilot plugin install lagune@lagune
```

I en editor installerer du **Lagune** til **GitHub Copilot** med [**skills.sh**](https://lagune.ai/da-DK/docs/install/universal).

## Opdatering

Kør følgende for at opdatere **Lagune**:

```bash
copilot plugin marketplace update lagune
copilot plugin update lagune@lagune
```

## Kommandoer

Skriv kommandoerne ved deres navn, såsom `/lagune-charter`.

## Ofte stillede spørgsmål

### Hvordan installerer jeg Lagune i GitHub Copilot CLI?

Kør copilot plugin marketplace add wellwelwel/lagune og derefter copilot plugin install lagune@lagune.

### Hvordan opdaterer jeg Lagune i GitHub Copilot CLI?

Kør copilot plugin marketplace update lagune og derefter copilot plugin update lagune@lagune.

### Hvordan kører jeg kommandoerne i Lagune i GitHub Copilot CLI?

Skriv dem ved deres navn, såsom /lagune-charter.

### Kan jeg bruge Lagune med GitHub Copilot i VS Code?

Ja. I VS Code eller en anden editor installerer du Lagune med skills.sh i stedet for pluginnet.
