# Installér Lagune i Devin CLI som et plugin

> Installér Lagune i Devin CLI som et plugin, og hold det opdateret.

Kanonisk URL: https://lagune.ai/da-DK/docs/install/devin-cli
Sprog: da-DK
Original: https://lagune.ai/docs/install/devin-cli
Sidst opdateret: 2026-11-09

Log ind på **Devin**, og installér derefter pluginnet fra din terminal:

```bash
devin auth login
devin plugins install wellwelwel/lagune
```

## Opdatering

Kør følgende for at opdatere **Lagune**:

```bash
devin plugins update lagune
```

## Kommandoer

Skriv kommandoerne under pluginnets navn, såsom `/lagune:lagune-charter` for `/lagune-charter`. Menuen `/` viser dem også.
