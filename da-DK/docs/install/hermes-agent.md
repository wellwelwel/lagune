# Installér Lagune i Hermes Agent som et plugin

> Installér Lagune i Hermes Agent som et plugin, og hold det opdateret.

Kanonisk URL: https://lagune.ai/da-DK/docs/install/hermes-agent
Sprog: da-DK
Original: https://lagune.ai/docs/install/hermes-agent
Sidst opdateret: 2026-11-09

Installér pluginnet fra din terminal:

```bash
hermes plugins install wellwelwel/lagune --enable
```

- Når **Hermes Agent** beder dig bekræfte et plugin uden for sit katalog, så **bekræft det**.
- Når den tilbyder at installere repositoriets afhængigheder til **Node.js**, så **afvis**.

## Opdatering

Kør følgende for at opdatere **Lagune**:

```bash
hermes plugins update lagune
```

## Kommandoer

Skriv kommandoerne under pluginnets navn, såsom `/lagune:lagune-charter` for `/lagune-charter` og `/lagune:lagune` for `/lagune`.

## Ofte stillede spørgsmål

### Hvordan installerer jeg Lagune i Hermes Agent?

Kør hermes plugins install wellwelwel/lagune --enable. Bekræft pluginnet, når du bliver spurgt, og afvis at installere repositoriets afhængigheder til Node.js.

### Hvordan opdaterer jeg Lagune i Hermes Agent?

Kør hermes plugins update lagune.

### Hvordan kører jeg kommandoerne i Lagune i Hermes Agent?

Skriv dem under pluginnets navn, såsom /lagune:lagune-charter og /lagune:lagune.
