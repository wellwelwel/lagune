# Como instalar o Lagune no GitHub Copilot CLI como plugin

> Instale o Lagune no GitHub Copilot CLI como plugin e mantenha-o atualizado.

Canônica: https://lagune.ai/pt-BR/docs/install/github-copilot-cli
Idioma: pt-BR
Original: https://lagune.ai/docs/install/github-copilot-cli
Última atualização: 2026-11-05

Instale o plugin pelo terminal:

```bash
copilot plugin marketplace add wellwelwel/lagune
copilot plugin install lagune@lagune
```

Em um editor, instale o **Lagune** para o **GitHub Copilot** com o [**skills.sh**](https://lagune.ai/pt-BR/docs/install/universal).

## Atualização

Para atualizar o **Lagune**, execute:

```bash
copilot plugin marketplace update lagune
copilot plugin update lagune@lagune
```

## Comandos

Digite os comandos pelo nome, como `/lagune-charter`.

## Perguntas frequentes

### Como instalar o Lagune no GitHub Copilot CLI?

Execute copilot plugin marketplace add wellwelwel/lagune e depois copilot plugin install lagune@lagune.

### Como atualizar o Lagune no GitHub Copilot CLI?

Execute copilot plugin marketplace update lagune e depois copilot plugin update lagune@lagune.

### Como executar os comandos do Lagune no GitHub Copilot CLI?

Digite-os pelo nome, como /lagune-charter.

### Dá para usar o Lagune com o GitHub Copilot no VS Code?

Sim. No VS Code ou em outro editor, instale o Lagune com o skills.sh em vez do plugin.
