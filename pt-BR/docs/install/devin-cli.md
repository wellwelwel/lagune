# Como instalar o Lagune no Devin CLI como plugin

> Instale o Lagune no Devin CLI como plugin e mantenha-o atualizado.

Canônica: https://lagune.ai/pt-BR/docs/install/devin-cli
Idioma: pt-BR
Original: https://lagune.ai/docs/install/devin-cli
Última atualização: 2026-11-05

Faça login no **Devin** e depois instale o plugin pelo terminal:

```bash
devin auth login
devin plugins install wellwelwel/lagune
```

## Atualização

Para atualizar o **Lagune**, execute:

```bash
devin plugins update lagune
```

## Comandos

Digite os comandos com o nome do plugin na frente, como `/lagune:lagune-charter` para `/lagune-charter`. O menu `/` também os lista.
