# Como instalar o Lagune no Hermes Agent como plugin

> Instale o Lagune no Hermes Agent como plugin e mantenha-o atualizado.

Canônica: https://lagune.ai/pt-BR/docs/install/hermes-agent
Idioma: pt-BR
Original: https://lagune.ai/docs/install/hermes-agent
Última atualização: 2026-11-04

Instale o plugin pelo terminal:

```bash
hermes plugins install wellwelwel/lagune --enable
```

- Quando o **Hermes Agent** pedir para você confirmar um plugin de fora do catálogo dele, **confirme**.
- Quando ele oferecer instalar as dependências de **Node.js** do repositório, **recuse**.

## Atualização

Para atualizar o **Lagune**, execute:

```bash
hermes plugins update lagune
```

## Comandos

Digite os comandos com o nome do plugin na frente, como `/lagune:lagune-charter` para `/lagune-charter` e `/lagune:lagune` para `/lagune`.

## Perguntas frequentes

### Como instalar o Lagune no Hermes Agent?

Execute hermes plugins install wellwelwel/lagune --enable. Confirme o plugin quando for solicitado e recuse a instalação das dependências de Node.js do repositório.

### Como atualizar o Lagune no Hermes Agent?

Execute hermes plugins update lagune.

### Como executar os comandos do Lagune no Hermes Agent?

Digite-os com o nome do plugin na frente, como /lagune:lagune-charter e /lagune:lagune.
