# Como instalar o Lagune no Kimi Code como plugin

> Instale o Lagune no Kimi Code como plugin e mantenha-o atualizado.

Canônica: https://lagune.ai/pt-BR/docs/install/kimi-code
Idioma: pt-BR
Original: https://lagune.ai/docs/install/kimi-code
Última atualização: 2026-11-09

Instale o plugin em uma sessão do **Kimi Code**, escolha **Trust and install** e depois inicie uma nova sessão para carregá-lo:

```prompt
/plugins install https://github.com/wellwelwel/lagune
/new
```

## Atualização

Para atualizar o **Lagune**, instale-o de novo:

```prompt
/plugins install https://github.com/wellwelwel/lagune
/new
```

## Comandos

Digite os comandos com o nome do plugin na frente, como `/lagune:lagune-charter` para `/lagune-charter`. O menu `/` os lista como `/skill:lagune:lagune-charter`, o que também funciona.

## Perguntas frequentes

### Como instalar o Lagune no Kimi Code?

Em uma sessão do Kimi Code, execute /plugins install https://github.com/wellwelwel/lagune, escolha Trust and install e depois execute /new.

### Como atualizar o Lagune no Kimi Code?

Execute /plugins install https://github.com/wellwelwel/lagune de novo e depois /new.

### Como executar os comandos do Lagune no Kimi Code?

Digite-os com o nome do plugin na frente, como /lagune:lagune-charter, ou como o menu / os lista, como /skill:lagune:lagune-charter.
