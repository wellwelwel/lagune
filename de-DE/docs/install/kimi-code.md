# Lagune als Plugin in Kimi Code installieren

> Installiere Lagune als Plugin in Kimi Code und halte es aktuell.

Kanonische URL: https://lagune.ai/de-DE/docs/install/kimi-code
Sprache: de-DE
Original: https://lagune.ai/docs/install/kimi-code
Zuletzt aktualisiert: 2026-11-03

Installiere das Plugin in einer Sitzung von **Kimi Code**, wähle **Trust and install** und starte dann eine neue Sitzung, um es zu laden:

```text
/plugins install https://github.com/wellwelwel/lagune
/new
```

## Aktualisierung

Um **Lagune** zu aktualisieren, installiere das Plugin erneut:

```text
/plugins install https://github.com/wellwelwel/lagune
/new
```

## Befehle

Gib die Befehle mit vorangestelltem Plugin-Namen ein, etwa `/lagune:lagune-charter` für `/lagune-charter`. Das Menü `/` listet sie als `/skill:lagune:lagune-charter` auf, was ebenfalls funktioniert.

## Häufige Fragen

### Wie installiere ich Lagune in Kimi Code?

Führe in einer Sitzung von Kimi Code /plugins install https://github.com/wellwelwel/lagune aus, wähle Trust and install und führe dann /new aus.

### Wie aktualisiere ich Lagune in Kimi Code?

Führe /plugins install https://github.com/wellwelwel/lagune erneut aus, dann /new.

### Wie führe ich die Befehle von Lagune in Kimi Code aus?

Gib sie mit vorangestelltem Plugin-Namen ein, etwa /lagune:lagune-charter, oder so, wie das Menü / sie auflistet, etwa /skill:lagune:lagune-charter.
