# Lagune als Plugin in GitHub Copilot CLI installieren

> Installiere Lagune als Plugin in GitHub Copilot CLI und halte es aktuell.

Kanonische URL: https://lagune.ai/de-DE/docs/install/github-copilot-cli
Sprache: de-DE
Original: https://lagune.ai/docs/install/github-copilot-cli
Zuletzt aktualisiert: 2026-11-04

Installiere das Plugin über dein Terminal:

```bash
copilot plugin marketplace add wellwelwel/lagune
copilot plugin install lagune@lagune
```

Installiere **Lagune** für **GitHub Copilot** in einem Editor mit [**skills.sh**](https://lagune.ai/de-DE/docs/install/universal).

## Aktualisierung

Um **Lagune** zu aktualisieren, führe Folgendes aus:

```bash
copilot plugin marketplace update lagune
copilot plugin update lagune@lagune
```

## Befehle

Gib die Befehle mit ihrem Namen ein, etwa `/lagune-charter`.

## Häufige Fragen

### Wie installiere ich Lagune in GitHub Copilot CLI?

Führe copilot plugin marketplace add wellwelwel/lagune aus, dann copilot plugin install lagune@lagune.

### Wie aktualisiere ich Lagune in GitHub Copilot CLI?

Führe copilot plugin marketplace update lagune aus, dann copilot plugin update lagune@lagune.

### Wie führe ich die Befehle von Lagune in GitHub Copilot CLI aus?

Gib sie mit ihrem Namen ein, etwa /lagune-charter.

### Kann ich Lagune mit GitHub Copilot in VS Code nutzen?

Ja. Installiere Lagune in VS Code oder einem anderen Editor mit skills.sh statt mit dem Plugin.
