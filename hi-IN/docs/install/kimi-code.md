# Kimi Code पर Lagune को प्लगइन के रूप में इंस्टॉल करें

> Kimi Code पर Lagune को प्लगइन के रूप में इंस्टॉल करें और उसे अपडेट रखें।

कैनोनिकल: https://lagune.ai/hi-IN/docs/install/kimi-code
भाषा: hi-IN
मूल: https://lagune.ai/docs/install/kimi-code
आख़िरी अपडेट: 2026-11-06

**Kimi Code** सेशन में प्लगइन इंस्टॉल करें, **Trust and install** चुनें, फिर उसे लोड करने के लिए नया सेशन शुरू करें:

```text
/plugins install https://github.com/wellwelwel/lagune
/new
```

## अपडेट

**Lagune** को अपडेट करने के लिए उसे फिर से इंस्टॉल करें:

```text
/plugins install https://github.com/wellwelwel/lagune
/new
```

## कमांड

कमांड प्लगइन के नाम के साथ टाइप करें, जैसे `/lagune:lagune-charter`, जो `/lagune-charter` कमांड है। `/` मेन्यू में ये `/skill:lagune:lagune-charter` के रूप में दिखती हैं, और इस रूप में टाइप करने पर भी ये काम करती हैं।

## अक्सर पूछे जाने वाले सवाल

### Kimi Code पर Lagune कैसे इंस्टॉल करें?

Kimi Code सेशन में /plugins install https://github.com/wellwelwel/lagune चलाएँ, Trust and install चुनें, फिर /new चलाएँ।

### Kimi Code पर Lagune को कैसे अपडेट करें?

/plugins install https://github.com/wellwelwel/lagune फिर से चलाएँ, उसके बाद /new चलाएँ।

### Kimi Code पर Lagune की कमांड कैसे चलाएँ?

इन्हें प्लगइन के नाम के साथ टाइप करें, जैसे /lagune:lagune-charter, या उसी रूप में जैसे / मेन्यू इन्हें दिखाता है, जैसे /skill:lagune:lagune-charter।
