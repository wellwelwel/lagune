# skills.sh या GitHub CLI से किसी भी एजेंट में Lagune इंस्टॉल करें

> skills CLI या GitHub CLI से किसी भी AI एजेंट में Lagune इंस्टॉल करें, और उसे अपडेट रखें।

कैनोनिकल: https://lagune.ai/hi-IN/docs/install/universal
भाषा: hi-IN
मूल: https://lagune.ai/docs/install/universal
आख़िरी अपडेट: 2026-11-09

**skills.sh**

[**skills.sh**](https://www.skills.sh/wellwelwel/lagune) के ज़रिए अपने टर्मिनल से **Lagune** की कमांड अपने प्रोजेक्ट में इंस्टॉल करें:

```bash
npx skills add wellwelwel/lagune -y
```

या यह प्रॉम्प्ट अपने एजेंट में पेस्ट करें:

```md
`npx --yes skills add wellwelwel/lagune --yes` चलाओ और इससे बने स्किल निर्देशों का अभी पालन करो। इसका पूरा आउटपुट पढ़ो, ज़रूरत हो तो पहले उसे किसी अस्थायी फ़ाइल में रीडायरेक्ट करो। रिलेटिव पाथ उस सपोर्टिंग-फ़ाइल डायरेक्टरी से तय करो जो यह देता है।
```

**GitHub CLI**

[**GitHub CLI**](https://cli.github.com/) 2.90.0 या उससे नए वर्शन के ज़रिए अपने टर्मिनल से **Lagune** की कमांड अपने प्रोजेक्ट में इंस्टॉल करें:

```bash
gh skill install wellwelwel/lagune --all --scope project
```

या यह प्रॉम्प्ट अपने एजेंट में पेस्ट करें:

```md
`gh skill install wellwelwel/lagune --all --scope project` चलाओ और इसका पूरा आउटपुट पढ़ो, ज़रूरत हो तो पहले उसे किसी अस्थायी फ़ाइल में रीडायरेक्ट करो।
```

## अपडेट

**skills.sh**

**Lagune** को अपडेट करने के लिए यह चलाएँ:

```bash
npx skills update
```

या यह प्रॉम्प्ट अपने एजेंट में पेस्ट करें:

```md
`npx --yes skills update -y` चलाओ और इसका पूरा आउटपुट पढ़ो, ज़रूरत हो तो पहले उसे किसी अस्थायी फ़ाइल में रीडायरेक्ट करो।
```

**GitHub CLI**

**Lagune** को अपडेट करने के लिए यह चलाएँ:

```bash
gh skill update --all
```

या यह प्रॉम्प्ट अपने एजेंट में पेस्ट करें:

```md
`gh skill update --all` चलाओ और इसका पूरा आउटपुट पढ़ो, ज़रूरत हो तो पहले उसे किसी अस्थायी फ़ाइल में रीडायरेक्ट करो।
```

**सैंडबॉक्स**

जिस सैंडबॉक्स में नेटवर्क एक्सेस नहीं है, उसमें कमांड इंजन डाउनलोड नहीं कर सकतीं। इसे अपने टर्मिनल से अपने प्रोजेक्ट में इंस्टॉल करें, पहली बार और हर अपडेट के बाद:

```bash
npm i -D lagune@0.18.1
```

## अक्सर पूछे जाने वाले सवाल

### किसी भी AI एजेंट में Lagune कैसे इंस्टॉल करें?

अपने प्रोजेक्ट में npx skills add wellwelwel/lagune -y या gh skill install wellwelwel/lagune --all --scope project चलाएँ, या इंस्टॉल प्रॉम्प्ट अपने एजेंट में पेस्ट करें।

### किसी भी AI एजेंट में Lagune को कैसे अपडेट करें?

अगर आपने इसे skills.sh से इंस्टॉल किया है, तो npx skills update चलाएँ, और अगर GitHub CLI से इंस्टॉल किया है, तो gh skill update --all चलाएँ। आप अपडेट प्रॉम्प्ट अपने एजेंट में पेस्ट भी कर सकते हैं।

### क्या मैं Lagune को एक से ज़्यादा तरीकों से इंस्टॉल कर सकता हूँ?

नहीं। दो तरीकों से इंस्टॉल करने पर एजेंट हर कमांड दो बार दिखाता है, या एक कॉपी इस्तेमाल करता है और दूसरी छिपा देता है।
