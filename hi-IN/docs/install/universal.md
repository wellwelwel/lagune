# skills.sh से किसी भी एजेंट में Lagune इंस्टॉल करें

> skills CLI से किसी भी AI एजेंट में Lagune इंस्टॉल करें, और उसे अपडेट रखें।

कैनोनिकल: https://lagune.ai/hi-IN/docs/install/universal
भाषा: hi-IN
मूल: https://lagune.ai/docs/install/universal
आख़िरी अपडेट: 2026-11-06

**टर्मिनल**

[**skills.sh**](https://www.skills.sh/wellwelwel/lagune) के ज़रिए अपने टर्मिनल से **Lagune** की कमांड इंस्टॉल करें:

```bash
npx skills add wellwelwel/lagune
```

**प्रॉम्प्ट**

यह प्रॉम्प्ट अपने एजेंट में पेस्ट करें:

```md
`npx --yes skills add wellwelwel/lagune` चलाओ और इससे बने स्किल निर्देशों का अभी पालन करो। इसका पूरा आउटपुट पढ़ो, ज़रूरत हो तो पहले उसे किसी अस्थायी फ़ाइल में रीडायरेक्ट करो। रिलेटिव पाथ उस सपोर्टिंग-फ़ाइल डायरेक्टरी से तय करो जो यह देता है।
```

## अपडेट

**टर्मिनल**

**Lagune** को अपडेट करने के लिए यह चलाएँ:

```bash
npx skills update
```

**प्रॉम्प्ट**

**Lagune** को अपडेट करने के लिए यह प्रॉम्प्ट अपने एजेंट में पेस्ट करें:

```md
`npx --yes skills update -y` चलाओ और इसका पूरा आउटपुट पढ़ो, ज़रूरत हो तो पहले उसे किसी अस्थायी फ़ाइल में रीडायरेक्ट करो।
```

---

**हर एजेंट में एक ही तरीका**

**Lagune** को **skills.sh** से या उसके **प्लगइन** से इंस्टॉल करें, दोनों से कभी नहीं।

**अनुमतियाँ**

कमांड इंजन को `npx --yes lagune@0.18.0` के रूप में चलाती हैं, और हर [एजेंट का इंस्टॉल पेज](https://lagune.ai/hi-IN/docs) वह नियम दिखाता है जो इसे पहले से अनुमति देता है। जिस सैंडबॉक्स में नेटवर्क एक्सेस नहीं है, उसमें इंजन को अपने टर्मिनल से अपने प्रोजेक्ट में इंस्टॉल करें, पहली बार और हर अपडेट के बाद:

```bash
npm i -D lagune@0.18.0
```

## अक्सर पूछे जाने वाले सवाल

### किसी भी AI एजेंट में Lagune कैसे इंस्टॉल करें?

अपने प्रोजेक्ट में npx skills add wellwelwel/lagune चलाएँ, या इंस्टॉल प्रॉम्प्ट अपने एजेंट में पेस्ट करें।

### skills CLI से इंस्टॉल किए गए Lagune को कैसे अपडेट करें?

npx skills update चलाएँ, या अपडेट प्रॉम्प्ट अपने एजेंट में पेस्ट करें।

### क्या मैं Lagune को skills CLI और प्लगइन, दोनों से इंस्टॉल कर सकता हूँ?

नहीं। दोनों से इंस्टॉल करने पर एजेंट हर कमांड दो बार दिखाता है, या एक कॉपी इस्तेमाल करता है और दूसरी छिपा देता है।
