# Devin CLI में Lagune को प्लगइन के रूप में इंस्टॉल करें

> Devin CLI में Lagune को प्लगइन के रूप में इंस्टॉल करें, और उसे अपडेट रखें।

कैनोनिकल: https://lagune.ai/hi-IN/docs/install/devin-cli
भाषा: hi-IN
मूल: https://lagune.ai/docs/install/devin-cli
आख़िरी अपडेट: 2026-11-06

**Devin** में साइन इन करें, फिर अपने टर्मिनल से प्लगइन इंस्टॉल करें:

```bash
devin auth login
devin plugins install wellwelwel/lagune
```

## अपडेट

**Lagune** को अपडेट करने के लिए यह चलाएँ:

```bash
devin plugins update lagune
```

## कमांड

कमांड प्लगइन के नाम के साथ टाइप करें, जैसे `/lagune:lagune-charter`, जो `/lagune-charter` कमांड है। `/` मेन्यू में भी इनकी सूची दिखती है।
