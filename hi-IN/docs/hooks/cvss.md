# cvss हुक: CVSS v4.0 वेक्टर को स्कोर दें

> कमांड लाइन से एक या कई CVSS v4.0 वेक्टर को FIRST कैलकुलेटर वाले ही गणित से स्कोर दें, और हर वेक्टर का मतलब आसान शब्दों में पढ़ें।

कैनोनिकल: https://lagune.ai/hi-IN/docs/hooks/cvss
भाषा: hi-IN
मूल: https://lagune.ai/docs/hooks/cvss
आख़िरी अपडेट: 2026-11-06

`cvss` हुक किसी **CVSS v4.0 वेक्टर** को स्कोर देता है और उसका स्कोर और गंभीरता का स्तर छापता है। यही वह रेटिंग है जो [`/lagune-plan`](https://lagune.ai/hi-IN/docs/commands/plan) कमांड हर सुधार पर और [`/lagune-prove`](https://lagune.ai/hi-IN/docs/commands/prove) कमांड हर सुरक्षा एडवाइज़री पर लिखती है। यह उन रेटिंग के पीछे का नियतात्मक इंजन है, जो [FIRST कैलकुलेटर](https://www.first.org/cvss/calculator/4.0) वाला ही गणित इस्तेमाल करता है, और आप इसे खुद चला सकते हैं।

## चलाएँ

हर वेक्टर `--vector` के साथ दें। हुक हर वेक्टर के लिए एक लाइन छापता है: उसका स्कोर और स्तर।

**एक वेक्टर**

```bash
npx lagune read cvss --vector 'CVSS:4.0/AV:N/AC:L/AT:N/PR:N/UI:N/VC:H/VI:H/VA:H/SC:N/SI:N/SA:N'
# => 9.3, Critical
```

**कई वेक्टर**

एक साथ कई वेक्टर को स्कोर देने के लिए `--vector` दोहराएँ। हर वेक्टर के लिए एक लाइन आती है, उसी क्रम में।

```bash
npx lagune read cvss \
  --vector 'CVSS:4.0/AV:N/AC:L/AT:N/PR:N/UI:N/VC:H/VI:H/VA:H/SC:N/SI:N/SA:N' \
  --vector 'CVSS:4.0/AV:N/AC:L/AT:N/PR:N/UI:N/VC:H/VI:H/VA:H/SC:N/SI:N/SA:N/MAV:A'
# => 9.3, Critical
# => 8.7, High
```

**आसान शब्दों में**

हर मेट्रिक का मतलब आसान शब्दों में पढ़ने के लिए `--explain` जोड़ें। जब Threat या Environmental मेट्रिक स्कोर बदलते हैं, तो पहले सिर्फ़ Base स्कोर आता है।

```bash
npx lagune read cvss --explain --vector 'CVSS:4.0/AV:N/AC:L/AT:N/PR:N/UI:N/VC:H/VI:H/VA:H/SC:N/SI:N/SA:N/MAV:A'
# => 8.7, High
# =>   Base metrics alone: 9.3, Critical
# =>   Attack Vector: Network, modified to Adjacent
# =>   Attack Complexity: Low
# =>   ...
```

## नतीजा कैसे पढ़ें

| स्तर       | स्कोर       |
| ---------- | ----------- |
| `None`     | 0.0         |
| `Low`      | 0.1 से 3.9  |
| `Medium`   | 4.0 से 6.9  |
| `High`     | 7.0 से 8.9  |
| `Critical` | 9.0 से 10.0 |

सिर्फ़ Base मेट्रिक वाला वेक्टर ख़ामी को ही स्कोर देता है और सबसे बुरी स्थिति मानकर चलता है: हर सुरक्षा ज़रूरत High है और ख़ामी पर असल दुनिया में हमले हो रहे हैं। Environmental मेट्रिक (`MAV` और बाकी मॉडिफ़ाइड मेट्रिक, साथ में `CR`, `IR` और `AR`) स्कोर को किसी एक डिप्लॉयमेंट के हिसाब से तय करते हैं, और Threat मेट्रिक (`E`) एक्सप्लॉइट के बारे में जो जानकारी है उसके हिसाब से।

अमान्य वेक्टर पर `invalid vector:` के साथ यह छपता है कि क्या ग़लत है, और हुक नॉन-ज़ीरो एग्ज़िट कोड देता है।

### CLI विकल्प

| विकल्प      | वैल्यू               | विवरण                                                                                                |
| ----------- | -------------------- | ---------------------------------------------------------------------------------------------------- |
| `--vector`  | एक `CVSS:4.0` वेक्टर | एक वेक्टर को स्कोर दें। कई को स्कोर देने के लिए इसे दोहराएँ, हर वेक्टर के लिए एक लाइन, उसी क्रम में। |
| `--explain` |                      | हर रेटिंग लाइन के नीचे हर मेट्रिक का मतलब आसान शब्दों में जोड़ें।                                    |

कम से कम एक `--vector` ज़रूरी है। वेक्टर कभी अकेला पोज़िशनल आर्ग्युमेंट नहीं होता, इसलिए उसे फ़्लैग समझने की ग़लती नहीं हो सकती।

**फ़्लैग वैल्यू क्यों**

हर वेक्टर फ़्लैग वैल्यू के रूप में दिया जाता है, उसे कभी कमांड के अंदर जोड़कर नहीं लिखा जाता। कोट या बैकटिक वाली वैल्यू भी बेअसर रहती है और शेल में इंजेक्ट नहीं हो सकती। इसे हमेशा सिंगल कोट में रखें, ताकि आपका शेल पहले ही इसे एक्सपैंड न कर दे।

**यह क्या कवर नहीं करता**

सिर्फ़ CVSS v4.0: v2.0, v3.0 या v3.1 वेक्टर को स्कोर देने के बजाय ठुकरा दिया जाता है, क्योंकि **Lagune** हर निष्कर्ष को v4.0 में स्कोर देता है।

**टिप**

plan चरण की जाँच हर CVSS लाइन पर यही गणित दोबारा चलाती है, इसलिए अपने वेक्टर से भटका हुआ स्कोर योजना स्वीकार होने से पहले ही पकड़ में आ जाता है।

## अक्सर पूछे जाने वाले सवाल

### Lagune CVSS स्कोर कैसे निकालता है?

cvss हुक CVSS v4.0 के लिए FIRST के रेफ़रेंस कैलकुलेटर का पालन करता है, इसलिए किसी वेक्टर का स्कोर ठीक वही आता है जो FIRST की साइट पर आता है।

### क्या मैं इससे CVSS v3.1 वेक्टर को स्कोर दे सकता हूँ?

नहीं। Lagune हर निष्कर्ष को CVSS v4.0 में स्कोर देता है, और हुक किसी भी दूसरे वर्ज़न को स्कोर देने के बजाय ठुकरा देता है।

### --explain फ़्लैग क्या करता है?

यह हर मेट्रिक का मतलब आसान शब्दों में बताता है और कुल स्कोर के बगल में Base स्कोर दिखाता है, ताकि कोई भी देख सके कि वेक्टर क्या कहता है और प्रोजेक्ट के संदर्भ ने स्कोर को कैसे बदला।
