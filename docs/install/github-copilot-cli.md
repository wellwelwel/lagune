# Install Lagune on GitHub Copilot CLI as a Plugin

> Install Lagune on GitHub Copilot CLI as a plugin, and keep it updated.

Canonical: https://lagune.ai/docs/install/github-copilot-cli
Last updated: 2026-11-04

Install the plugin from your terminal:

```bash
copilot plugin marketplace add wellwelwel/lagune
copilot plugin install lagune@lagune
```

In an editor, install **Lagune** for **GitHub Copilot** with the [**skills.sh**](https://lagune.ai/docs/install/universal).

## Update

To update **Lagune**, run:

```bash
copilot plugin marketplace update lagune
copilot plugin update lagune@lagune
```

## Commands

Type the commands by name, such as `/lagune-charter`.

## Frequently Asked Questions

### How do I install Lagune on GitHub Copilot CLI?

Run copilot plugin marketplace add wellwelwel/lagune, then copilot plugin install lagune@lagune.

### How do I update Lagune on GitHub Copilot CLI?

Run copilot plugin marketplace update lagune, then copilot plugin update lagune@lagune.

### How do I run Lagune's commands on GitHub Copilot CLI?

Type them by name, such as /lagune-charter.

### Can I use Lagune with GitHub Copilot in VS Code?

Yes. In VS Code or another editor, install Lagune with the skills.sh instead of the plugin.
