# Install Lagune on Devin CLI as a Plugin

> Install Lagune on Devin CLI as a plugin, and keep it updated.

Canonical: https://lagune.ai/docs/install/devin-cli
Last updated: 2026-11-05

Sign in to **Devin**, then install the plugin from your terminal:

```bash
devin auth login
devin plugins install wellwelwel/lagune
```

## Update

To update **Lagune**, run:

```bash
devin plugins update lagune
```

## Commands

Type the commands under the plugin's name, such as `/lagune:lagune-charter` for `/lagune-charter`. The `/` menu also lists them.
