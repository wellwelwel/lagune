# Install Lagune on Kimi Code as a Plugin

> Install Lagune on Kimi Code as a plugin, and keep it updated.

Canonical: https://lagune.ai/docs/install/kimi-code
Last updated: 2026-11-04

Install the plugin from a **Kimi Code** session, choose **Trust and install**, then start a new session to load it:

```text
/plugins install https://github.com/wellwelwel/lagune
/new
```

## Update

To update **Lagune**, install it again:

```text
/plugins install https://github.com/wellwelwel/lagune
/new
```

## Commands

Type the commands under the plugin's name, such as `/lagune:lagune-charter` for `/lagune-charter`. The `/` menu lists them as `/skill:lagune:lagune-charter`, which also works.

## Frequently Asked Questions

### How do I install Lagune on Kimi Code?

In a Kimi Code session, run /plugins install https://github.com/wellwelwel/lagune, choose Trust and install, then run /new.

### How do I update Lagune on Kimi Code?

Run /plugins install https://github.com/wellwelwel/lagune again, then /new.

### How do I run Lagune's commands on Kimi Code?

Type them under the plugin's name, such as /lagune:lagune-charter, or as the / menu lists them, such as /skill:lagune:lagune-charter.
