# Instalar Lagune en Hermes Agent como plugin

> Instala Lagune en Hermes Agent como plugin y mantenlo actualizado.

URL canónica: https://lagune.ai/es-ES/docs/install/hermes-agent
Idioma: es-ES
Original: https://lagune.ai/docs/install/hermes-agent
Última actualización: 2026-11-03

Instala el plugin desde tu terminal:

```bash
hermes plugins install wellwelwel/lagune --enable
```

- Cuando **Hermes Agent** te pida confirmar un plugin ajeno a su catálogo, **confírmalo**.
- Cuando se ofrezca a instalar las dependencias de **Node.js** del repositorio, **recházalo**.

## Actualización

Para actualizar **Lagune**, ejecuta:

```bash
hermes plugins update lagune
```

## Comandos

Escribe los comandos precedidos del nombre del plugin, como `/lagune:lagune-charter` para `/lagune-charter` y `/lagune:lagune` para `/lagune`.

### ¿Cómo actualizo Lagune en Hermes Agent?

Ejecuta hermes plugins update lagune.

### ¿Cómo ejecuto los comandos de Lagune en Hermes Agent?

Escríbelos precedidos del nombre del plugin, como /lagune:lagune-charter y /lagune:lagune.
