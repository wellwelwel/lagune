# Instalar Lagune en Devin CLI como plugin

> Instala Lagune en Devin CLI como plugin y mantenlo actualizado.

URL canónica: https://lagune.ai/es-ES/docs/install/devin-cli
Idioma: es-ES
Original: https://lagune.ai/docs/install/devin-cli
Última actualización: 2026-11-05

Inicia sesión en **Devin** y después instala el plugin desde tu terminal:

```bash
devin auth login
devin plugins install wellwelwel/lagune
```

## Actualización

Para actualizar **Lagune**, ejecuta:

```bash
devin plugins update lagune
```

## Comandos

Escribe los comandos precedidos del nombre del plugin, como `/lagune:lagune-charter` para `/lagune-charter`. El menú `/` también los muestra.
