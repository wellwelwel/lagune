# Instalar Lagune en GitHub Copilot CLI como plugin

> Instala Lagune en GitHub Copilot CLI como plugin y mantenlo actualizado.

URL canónica: https://lagune.ai/es-ES/docs/install/github-copilot-cli
Idioma: es-ES
Original: https://lagune.ai/docs/install/github-copilot-cli
Última actualización: 2026-11-03

Instala el plugin desde tu terminal:

```bash
copilot plugin marketplace add wellwelwel/lagune
copilot plugin install lagune@lagune
```

En un editor, instala **Lagune** para **GitHub Copilot** con [**skills.sh**](https://lagune.ai/es-ES/docs/install/universal).

## Actualización

Para actualizar **Lagune**, ejecuta:

```bash
copilot plugin marketplace update lagune
copilot plugin update lagune@lagune
```

## Comandos

Escribe los comandos por su nombre, como `/lagune-charter`.

## Preguntas frecuentes

### ¿Cómo instalo Lagune en GitHub Copilot CLI?

Ejecuta copilot plugin marketplace add wellwelwel/lagune y después copilot plugin install lagune@lagune.

### ¿Cómo actualizo Lagune en GitHub Copilot CLI?

Ejecuta copilot plugin marketplace update lagune y después copilot plugin update lagune@lagune.

### ¿Cómo ejecuto los comandos de Lagune en GitHub Copilot CLI?

Escríbelos por su nombre, como /lagune-charter.

### ¿Puedo usar Lagune con GitHub Copilot en VS Code?

Sí. En VS Code o en otro editor, instala Lagune con skills.sh en lugar del plugin.
