# Instalar Lagune en Kimi Code como plugin

> Instala Lagune en Kimi Code como plugin y mantenlo actualizado.

URL canónica: https://lagune.ai/es-ES/docs/install/kimi-code
Idioma: es-ES
Original: https://lagune.ai/docs/install/kimi-code
Última actualización: 2026-11-03

Instala el plugin desde una sesión de **Kimi Code**, elige **Trust and install** y después inicia una sesión nueva para cargarlo:

```text
/plugins install https://github.com/wellwelwel/lagune
/new
```

## Actualización

Para actualizar **Lagune**, vuelve a instalarlo:

```text
/plugins install https://github.com/wellwelwel/lagune
/new
```

## Comandos

Escribe los comandos precedidos del nombre del plugin, como `/lagune:lagune-charter` para `/lagune-charter`. El menú `/` los muestra como `/skill:lagune:lagune-charter`, que también funciona.

## Preguntas frecuentes

### ¿Cómo instalo Lagune en Kimi Code?

En una sesión de Kimi Code, ejecuta /plugins install https://github.com/wellwelwel/lagune, elige Trust and install y después ejecuta /new.

### ¿Cómo actualizo Lagune en Kimi Code?

Vuelve a ejecutar /plugins install https://github.com/wellwelwel/lagune y después /new.

### ¿Cómo ejecuto los comandos de Lagune en Kimi Code?

Escríbelos precedidos del nombre del plugin, como /lagune:lagune-charter, o tal como los muestra el menú /, como /skill:lagune:lagune-charter.
