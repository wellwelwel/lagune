# /lagune: AI가 작성하는 동안 코드 보안 강화

> 요청한 작업을 만들고, 보안 원칙에 따라 작성하는 즉시 보안을 강화합니다. 따로 따라야 할 흐름은 없습니다.

표준 URL: https://lagune.ai/ko-KR/docs/commands/lagune
언어: ko-KR
원문: https://lagune.ai/docs/commands/lagune
마지막 업데이트: 2026-11-04

⌨️ 요청한 작업을, 작성하는 순간부터 안전하게 완성합니다. **`/lagune`** 명령어는 어느 단계에서든 어떤 프롬프트든 받아 원하는 것을 만들고, 결과를 돌려주기 전에 안전한 기본값으로 보안을 강화합니다.

## 사용법

어떤 프롬프트에든 **`/lagune`** 명령어를 붙이고, 평소처럼 작업 내용을 설명하세요.

**📘 에이전트 지침**

```md
# 에이전트를 위한 내 프로젝트 지침

<!-- ... -->

## 보안

- 코드를 만들거나 수정할 때마다 `/lagune` 스킬을 사용해서 기본적으로 안전성을 높여 줘.
```

    - 예: **AGENTS.md**, **CLAUDE.md**, **.github/copilot-instructions.md**, **.cursorrules** 등

**💬 새 기능**

```prompt
/lagune 사용자가 프로필에 원하는 사진을 업로드할 수 있게 해 줘.
```

**💬 버그 수정**

```prompt
/lagune 사용자가 폼을 제출해도 아무 일도 일어나지 않아. 원인이 뭔지 살펴보고 고쳐 줘.
```

**💬 리팩터링**

```prompt
/lagune 페이로드 로직을 분리하고 개선해 줘
```

**선택 사항이지만 있으면 더 좋은 보안 원칙**

**`/lagune`** 명령어는 보안 원칙이 있든 없든 실행됩니다. 보안 원칙이 있으면 프로젝트만의 규칙이 만드는 모든 것에 반영됩니다. [`/lagune-charter`](https://lagune.ai/ko-KR/docs/commands/charter) 명령어로 한 번만 정해 두세요.

## 작동 방식

Lagune에는 아무것도 기록하지 않은 채, 작업을 다음 세 과정으로 감쌉니다:

1. 보안 원칙이 있으면 불러와 그 원칙이 구현 전체를 규율하게 하고, 아직 없으면 기본적으로 안전한 기준선을 대신 적용합니다.
2. 프로젝트의 [카탈로그](https://lagune.ai/ko-KR/docs/catalog)를 살펴보고 작업과 관련된 전문 지식만 불러옵니다. 감사 흐름이 필요할 때만 불러오는 바로 그 지식입니다.
3. 코드를 작성하면서 방어를 적용하고, 작업을 돌려주기 전에 자신의 결과물을 다시 읽어 보안 통제가 실제로 효과가 있는지 확인합니다.

그 결과, 프로젝트에는 첫 줄부터 안전하고 제대로 작동하는 코드가 남습니다.

**언제든 사용하기**

detect 단계도, plan 단계도, 뒷정리도 필요 없습니다. **`/lagune`** 명령어는 막 만든 프로젝트 뼈대에도, 성숙한 코드베이스의 변경에도 똑같이 잘 맞으며, 나중이 아니라 작업하는 동안 보안을 강화합니다.

## 하지 않는 일

- `.lagune` 디렉터리에는 산출물도 추적 정보도 전혀 기록하지 않으므로, 만들어 내는 것은 요청한 대로 보안이 강화된 코드뿐입니다.
- 프롬프트를 들어주려고 규칙을 느슨하게 하지 않으므로, 요청한 내용이 보안 원칙에 어긋난다면 그대로 안전하지 않게 만드는 대신 먼저 멈추고 알려 줍니다.

## 자주 묻는 질문

### /lagune 명령어는 무엇을 하나요?

어느 단계에서든 어떤 프롬프트든 받아 요청한 것을 만들고, 결과를 돌려주기 전에 안전한 기본값으로 보안을 강화합니다. 방어는 나중이 아니라 코드를 작성하는 동안 적용됩니다.

### /lagune 명령어를 쓰려면 보안 원칙이 있어야 하나요?

아니요. 보안 원칙이 있든 없든 실행됩니다. 보안 원칙이 있으면 프로젝트만의 규칙이 만드는 모든 것에 반영되고, 없으면 기본적으로 안전한 기준선을 대신 적용합니다.

### /lagune 명령어와 Blue Team 흐름은 무엇이 다른가요?

/lagune 명령어는 따라야 할 흐름 없이, 작성하는 동안 새 작업을 안전하게 만듭니다. Blue Team 흐름은 기존 프로젝트를 대상으로 다섯 감사 단계를 차례로 실행합니다.

### /lagune 명령어는 발견 사항을 추적하거나 산출물을 기록하나요?

아니요. .lagune 디렉터리에는 산출물도 추적 정보도 전혀 기록하지 않습니다. 만들어 내는 것은 요청한 대로 보안이 강화된 코드뿐입니다.

### 에이전트가 /lagune 명령어를 자동으로 쓰게 하려면 어떻게 하나요?

에이전트의 지침 파일(AGENTS.md, CLAUDE.md, .cursorrules 등)에 코드를 만들거나 수정할 때마다 /lagune 스킬을 사용하라는 지침을 추가하세요.
