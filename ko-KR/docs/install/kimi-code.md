# Kimi Code에 Lagune 플러그인 설치하기

> Kimi Code에 Lagune을 플러그인으로 설치하고 최신 상태로 유지하세요.

표준 URL: https://lagune.ai/ko-KR/docs/install/kimi-code
언어: ko-KR
원문: https://lagune.ai/docs/install/kimi-code
마지막 업데이트: 2026-11-03

**Kimi Code** 세션에서 플러그인을 설치하고 **Trust and install**을 선택한 다음, 새 세션을 시작해 플러그인을 불러오세요:

```text
/plugins install https://github.com/wellwelwel/lagune
/new
```

## 업데이트

**Lagune**을 업데이트하려면 다시 설치하세요:

```text
/plugins install https://github.com/wellwelwel/lagune
/new
```

## 명령어

명령어는 플러그인 이름을 붙여 입력하세요. 예를 들어 `/lagune:lagune-charter` 명령어를 입력하면 `/lagune-charter` 명령어가 실행됩니다. `/` 메뉴에는 명령어가 `/skill:lagune:lagune-charter` 형식으로 표시되며, 이 형식으로 입력해도 실행됩니다.

## 자주 묻는 질문

### Kimi Code에 Lagune을 설치하려면 어떻게 하나요?

Kimi Code 세션에서 /plugins install https://github.com/wellwelwel/lagune 명령어를 실행하고 Trust and install을 선택한 다음 /new 명령어를 실행하세요.

### Kimi Code에서 Lagune을 업데이트하려면 어떻게 하나요?

/plugins install https://github.com/wellwelwel/lagune 명령어를 다시 실행한 다음 /new 명령어를 실행하세요.

### Kimi Code에서 Lagune 명령어를 실행하려면 어떻게 하나요?

/lagune:lagune-charter 명령어처럼 플러그인 이름을 붙여 입력하거나, /skill:lagune:lagune-charter 명령어처럼 / 메뉴에 표시되는 형식으로 입력하세요.
