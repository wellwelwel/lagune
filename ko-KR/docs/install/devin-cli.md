# Devin CLI에 Lagune 플러그인 설치하기

> Devin CLI에 Lagune을 플러그인으로 설치하고 최신 상태로 유지하세요.

표준 URL: https://lagune.ai/ko-KR/docs/install/devin-cli
언어: ko-KR
원문: https://lagune.ai/docs/install/devin-cli
마지막 업데이트: 2026-11-03

**Devin**에 로그인한 다음 터미널에서 플러그인을 설치하세요:

```bash
devin auth login
devin plugins install wellwelwel/lagune
```

## 업데이트

**Lagune**을 업데이트하려면 다음 명령어를 실행하세요:

```bash
devin plugins update lagune
```

## 명령어

명령어는 플러그인 이름을 붙여 입력하세요. 예를 들어 `/lagune:lagune-charter` 명령어를 입력하면 `/lagune-charter` 명령어가 실행됩니다. `/` 메뉴에서도 명령어 목록을 볼 수 있습니다.

## 자주 묻는 질문

### Devin CLI에 Lagune을 설치하려면 어떻게 하나요?

devin auth login 명령어로 로그인한 다음 devin plugins install wellwelwel/lagune 명령어를 실행하세요.

### Devin CLI에서 Lagune을 업데이트하려면 어떻게 하나요?

devin plugins update lagune 명령어를 실행하세요.

### Devin CLI에서 Lagune 명령어를 실행하려면 어떻게 하나요?

/lagune:lagune-charter 명령어처럼 플러그인 이름을 붙여 입력하세요. / 메뉴에서도 명령어 목록을 볼 수 있습니다.
