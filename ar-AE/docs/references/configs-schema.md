# مخطط الإعدادات

> مخطط JSON Schema لإعدادات مشروع Lagune، للإكمال التلقائي والتحقق في محررك، يتبع Lagune الحالي أو مثبّتًا على إصدار.

Canonical: https://lagune.ai/ar-AE/docs/references/configs-schema
اللغة: ar-AE
الأصل: https://lagune.ai/docs/references/configs-schema
آخر تحديث: 2026-11-09

يسجّل `.lagune/configs.json` [**الفئات**](https://lagune.ai/ar-AE/docs/categories) التي يستخدمها المشروع، ويفهرس [**تخصصاته**](https://lagune.ai/ar-AE/docs/catalog) الخاصة، ويحدد ما تستثنيه [**الفاحصات**](https://lagune.ai/ar-AE/docs/hooks/configure). ويسمح مخطط JSON Schema الخاص به لمحررك بإكمال كل حقل تلقائيًا والتنبيه إلى خطأ إملائي أو فئة غير معروفة أثناء تعديل الملف.

## المخطط الحالي

كلما كتب **Lagune** الملف ولم يجد فيه `$schema`، يوجّه الملف إلى المخطط الحالي:

```json
{
  "$schema": "https://lagune.ai/schemas/configs.json",
  "categories": ["owasp", "javascript"]
}
```

يتبع هذا العنوان دائمًا **Lagune** الحالي. والملف المكتوب قبل **Lagune** 0.16.0 يحصل عليه عند تغييره التالي، وتنبّه إليه كل مرحلة حتى ذلك الحين.

## ثبّت إصدارًا

يحمل كل إصدار من **Lagune** بدءًا من 0.16.0 المخطط كما كان في ذلك الإصدار، منشورًا على **npm** ومقدَّمًا عبر **jsDelivr**. ولتثبيت إصدار، ضع رقمه بعد `lagune@` في عنوان `$schema`:

```json
{
  "$schema": "https://cdn.jsdelivr.net/npm/lagune@0.16.0/schemas/configs.json"
}
```

يقبل الإصدار أي نطاق semver:

| الإصدار            | المخطط                  |
| ------------------ | ----------------------- |
| `0.16.0`           | مخطط الإصدار 0.16.0     |
| `0.16.x` أو `0.16` | مخطط أحدث إصدار من 0.16 |
| `0.x` أو `0`       | مخطط أحدث إصدار من 0.x  |
| `latest`           | مخطط أحدث إصدار         |

## الأسئلة الشائعة

### هل يحتاج Lagune إلى المخطط؟

لا. المخطط يساعد محررك فقط، ويقرأ Lagune الملف بالطريقة نفسها مع ‎$schema أو بدونه.

### هل سيستبدل Lagune مخططًا مثبّتًا؟

لا. لا يكتب Lagune ‎$schema إلا حين لا يحتوي الملف عليه، ويحافظ على أي عنوان تضعه.

### متى يجب أن أثبّت إصدارًا؟

حين يعمل المشروع بإصدار محدد من Lagune، ليتحقق محررك من الملف وفق ما يقبله ذلك الإصدار.
