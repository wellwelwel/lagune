# ثبّت Lagune على Devin CLI كإضافة

> ثبّت Lagune على Devin CLI كإضافة، وحافظ على تحديثه.

Canonical: https://lagune.ai/ar-AE/docs/install/devin-cli
اللغة: ar-AE
الأصل: https://lagune.ai/docs/install/devin-cli
آخر تحديث: 2026-11-09

سجّل الدخول إلى **Devin**، ثم ثبّت الإضافة من الطرفية:

```bash
devin auth login
devin plugins install wellwelwel/lagune
```

## التحديث

لتحديث **Lagune**، شغّل:

```bash
devin plugins update lagune
```

## الأوامر

اكتب الأوامر تحت اسم الإضافة، مثل `/lagune:lagune-charter` بدلًا من `/lagune-charter`. وتسردها قائمة `/` أيضًا.

## الأسئلة الشائعة

### كيف أثبّت Lagune على Devin CLI؟

سجّل الدخول عبر devin auth login، ثم شغّل devin plugins install wellwelwel/lagune.

### كيف أحدّث Lagune على Devin CLI؟

شغّل devin plugins update lagune.

### كيف أشغّل أوامر Lagune على Devin CLI؟

اكتبها تحت اسم الإضافة، مثل ‎/lagune:lagune-charter. وتسردها قائمة ‎/‎ أيضًا.
