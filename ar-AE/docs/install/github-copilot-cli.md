# ثبّت Lagune على GitHub Copilot CLI كإضافة

> ثبّت Lagune على GitHub Copilot CLI كإضافة، وحافظ على تحديثه.

Canonical: https://lagune.ai/ar-AE/docs/install/github-copilot-cli
اللغة: ar-AE
الأصل: https://lagune.ai/docs/install/github-copilot-cli
آخر تحديث: 2026-11-09

ثبّت الإضافة من الطرفية:

```bash
copilot plugin marketplace add wellwelwel/lagune
copilot plugin install lagune@lagune
```

في المحرر، ثبّت **Lagune** لـ **GitHub Copilot** عبر [**skills.sh**](https://lagune.ai/ar-AE/docs/install/universal).

## التحديث

لتحديث **Lagune**، شغّل:

```bash
copilot plugin marketplace update lagune
copilot plugin update lagune@lagune
```

## الأوامر

اكتب الأوامر بأسمائها، مثل `/lagune-charter`.

## الأسئلة الشائعة

### كيف أثبّت Lagune على GitHub Copilot CLI؟

شغّل copilot plugin marketplace add wellwelwel/lagune، ثم copilot plugin install lagune@lagune.

### كيف أحدّث Lagune على GitHub Copilot CLI؟

شغّل copilot plugin marketplace update lagune، ثم copilot plugin update lagune@lagune.

### كيف أشغّل أوامر Lagune على GitHub Copilot CLI؟

اكتبها بأسمائها، مثل /lagune-charter.

### هل يمكنني استخدام Lagune مع GitHub Copilot في VS Code؟

نعم. في VS Code أو أي محرر آخر، ثبّت Lagune عبر skills.sh بدلًا من الإضافة.
