# ثبّت Lagune على Kimi Code كإضافة

> ثبّت Lagune على Kimi Code كإضافة، وحافظ على تحديثه.

Canonical: https://lagune.ai/ar-AE/docs/install/kimi-code
اللغة: ar-AE
الأصل: https://lagune.ai/docs/install/kimi-code
آخر تحديث: 2026-11-09

ثبّت الإضافة من جلسة **Kimi Code**، واختر **Trust and install**، ثم ابدأ جلسة جديدة لتحميلها:

```text
/plugins install https://github.com/wellwelwel/lagune
/new
```

## التحديث

لتحديث **Lagune**، ثبّته مجددًا:

```text
/plugins install https://github.com/wellwelwel/lagune
/new
```

## الأوامر

اكتب الأوامر تحت اسم الإضافة، مثل `/lagune:lagune-charter` بدلًا من `/lagune-charter`. وتسردها قائمة `/` بالصيغة `/skill:lagune:lagune-charter`، وهي تعمل أيضًا.

## الأسئلة الشائعة

### كيف أثبّت Lagune على Kimi Code؟

في جلسة Kimi Code، شغّل ‎/plugins install https://github.com/wellwelwel/lagune ثم اختر Trust and install، ثم شغّل ‎/new.

### كيف أحدّث Lagune على Kimi Code؟

شغّل ‎/plugins install https://github.com/wellwelwel/lagune مجددًا، ثم ‎/new.

### كيف أشغّل أوامر Lagune على Kimi Code؟

اكتبها تحت اسم الإضافة، مثل ‎/lagune:lagune-charter، أو كما تسردها قائمة ‎/‎، مثل ‎/skill:lagune:lagune-charter.
