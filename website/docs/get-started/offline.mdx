**Lagune**'s commands run every deterministic step through its engine, the `lagune` package on **npm**:

```bash
npx lagune <subcommand>
```

Each call checks **npm** for the engine's latest version. To work with no network at all, install the engine in the project:

```bash
npm install --save-dev lagune
```

`npx` then runs the project's copy, with no download.

:::info[Sandboxed agents]
Some agents start with the network off. In the **Codex** `workspace-write` sandbox, for example, downloading the engine needs an approval, and an engine installed in the project never asks.
:::

## Keep it in step

An installed engine stays at its version. Run the same `npm install` after each `npx skills update`, so it keeps up with the updated commands.
