**Lagune**'s commands run every deterministic step through its engine, the `lagune` package on **npm**, with the exact version they carry:

```bash
npx --yes --prefer-offline lagune@{{version}} <subcommand>
```

The first call downloads the engine once, and `--prefer-offline` keeps every later call off the network. To work with no network at all, install the engine in the project instead, at the version your commands carry:

```bash
npm install --save-dev --save-exact lagune@{{version}}
```

`npx` then resolves the engine command from the project's `node_modules`, with no download.

:::info[Sandboxed agents]
Some agents start with the network off. In the **Codex** `workspace-write` sandbox, for example, the first engine download needs one approval, and an engine installed in the project never asks.
:::

## Keep it in step

The version your commands call moves with each `npx skills update`. After each update, run the same `npm install` with the version the updated commands call.

:::tip
A mismatch never breaks silently: when the installed engine is not the version a command calls, `npx` fetches that version, which needs the network again.
:::
