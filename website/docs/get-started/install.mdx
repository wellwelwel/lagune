**Lagune** helps your AI agent make a project more secure. You point it at your code, and the agent figures out what your system actually does, then guides you through the security work that matters for it. **Lagune** is the first project of the [Security-Driven Hardening (SDH)](/docs/references/paper) methodology.

:::tip[Support the OSS]
Love **Lagune**? <ArrowLink to="https://github.com/wellwelwel/lagune">Give us a ⭐ on **GitHub**</ArrowLink>
:::

## Pick your agent

<AgentPicker />

:::info

- **Lagune** runs on **Node.js** under the hood, you use whatever language you want.
- To run completely offline, install **Lagune** in your project with `npm i -D lagune@{{version}}`.

:::

## Categories

**Lagune**'s security knowledge comes as [**specializations**](/docs/catalog), grouped into [**categories**](/docs/categories).

<CategoryPicker />

:::tip
A project starts with `owasp` by default, and [`/lagune.charter`](/docs/commands/charter) adds the categories its reading of the project supports when analyzing the project.
:::

## Requirements

You will need [**Node.js (LTS)**](https://nodejs.org/en/download/package-manager) installed on your system.
