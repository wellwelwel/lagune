Install the extension from your terminal:

```bash
qwen extensions install lagune
```

**Qwen Code** installs **Lagune**'s latest release from **npm**, so each change reaches you with the next release.

## Update

**Qwen Code** leaves the extension at its installed release until you update it, or until you install it with `--auto-update`. To update **Lagune**, run:

```bash
qwen extensions update lagune
```

## Commands

Type the commands under the extension's name: where these docs show `/lagune-charter`, type `/lagune:lagune-charter`.

---

:::info[Permissions]

The extension carries **Lagune**'s engine and runs it through two tools: `lagune_read`, which only reads your project, and `lagune_write`, which changes only its `.lagune/` folder. To allow them up front, add these rules to `.qwen/settings.json` for one project, or to `~/.qwen/settings.json` for all of them:

```json
{
  "permissions": {
    "allow": ["mcp__lagune__lagune_read", "mcp__lagune__lagune_write"]
  }
}
```

Where the engine runs through **npx** instead, as it does for the **skills.sh**, allow `Shell(npx --yes lagune@*)`.

:::
