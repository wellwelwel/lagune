Install the plugin from your terminal:

```bash
droid plugin marketplace add wellwelwel/lagune
droid plugin install lagune@lagune
```

## Update

To update **Lagune**, run:

```bash
droid plugin marketplace update lagune
droid plugin update lagune@lagune
```

## Commands

Type the commands by their names, such as `/lagune-charter`.

---

:::info[Permissions]

The plugin carries **Lagune**'s engine and runs it through two tools: `lagune_read`, which only reads your project, and `lagune_write`, which changes only its `.lagune/` folder. The first call to each asks for your permission, and choosing to always allow it keeps it allowed until **Factory Droid** refreshes the plugin.

:::
