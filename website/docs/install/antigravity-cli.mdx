Install the plugin from your terminal:

```bash
agy plugin install https://github.com/wellwelwel/lagune/tree/plugin-antigravity
```

## Update

**Antigravity CLI** leaves the plugin at its installed version until you install it again, which replaces the installed copy. To update **Lagune**, run:

```bash
agy plugin install https://github.com/wellwelwel/lagune/tree/plugin-antigravity
```

## Commands

Type the commands under the plugin's name, such as `/lagune:lagune-charter` wherever these docs write `/lagune-charter`.

---

:::info[Permissions]

The plugin carries **Lagune**'s engine and runs it through two tools: `lagune_read`, which only reads your project, and `lagune_write`, which changes only its `.lagune/` folder. **Antigravity CLI** loads them while a session's first message runs, so a command sent as that first message runs the engine through **npx** instead, and every later message uses the tools. To allow both routes up front, add these rules to `~/.gemini/antigravity-cli/settings.json`:

```json
{
  "permissions": {
    "allow": [
      "mcp(lagune_lagune/lagune_read)",
      "mcp(lagune_lagune/lagune_write)",
      "command(regex:npx --yes lagune@[0-9.]+)"
    ]
  }
}
```
