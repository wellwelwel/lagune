Install the plugin from a **Kimi Code** session, choose **Trust and install**, then start a new session to load it:

```prompt
/plugins install https://github.com/wellwelwel/lagune
/new
```

## Update

To update **Lagune**, install it again:

```prompt
/plugins install https://github.com/wellwelwel/lagune
/new
```

## Commands

Type the commands under the plugin's name, such as `/lagune:lagune-charter` for `/lagune-charter`. The `/` menu lists them as `/skill:lagune:lagune-charter`, which also works.
