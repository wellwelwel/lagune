Install the plugin from a **Kimi Code** session, choose **Trust and install** when asked, then start a new session to load it:

```text
/plugins install https://github.com/wellwelwel/lagune/tree/main
/new
```

## Update

**Kimi Code** leaves the plugin at its installed version until you install it again, which replaces the installed copy. To update **Lagune**, run:

```text
/plugins install https://github.com/wellwelwel/lagune/tree/main
/new
```

## Commands

Type the commands under the plugin's name: where these docs show `/lagune.charter`, type `/lagune:lagune.charter`. The `/` menu lists them as `/skill:lagune:lagune.charter`, and both forms run the same command.
