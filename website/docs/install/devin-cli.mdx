**Devin CLI** installs plugins into your **Devin** account, so sign in first, then install the plugin from your terminal:

```bash
devin auth login
devin plugins install wellwelwel/lagune
```

## Update

To update **Lagune**, run:

```bash
devin plugins update lagune
```

## Commands

Type the commands under the plugin's name: where these docs show `/lagune.charter`, type `/lagune:lagune.charter`. The `/` menu also lists them.
