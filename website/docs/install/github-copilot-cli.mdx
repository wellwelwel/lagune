Install the plugin from your terminal:

```bash
copilot plugin marketplace add wellwelwel/lagune
copilot plugin install lagune@lagune
```

For **GitHub Copilot** in an editor, install **Lagune** with the [**skills.sh**](/docs/install/universal).

## Update

**GitHub Copilot CLI** leaves the plugin at its installed version until you update it. To update **Lagune**, run:

```bash
copilot plugin marketplace update lagune
copilot plugin update lagune@lagune
```

## Commands

Type the commands by their names, such as `/lagune.charter`.
