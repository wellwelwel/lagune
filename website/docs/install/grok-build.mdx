Install the plugin from your terminal:

```bash
grok plugin install wellwelwel/lagune --trust
```

## Update

To update **Lagune**, run:

```bash
grok plugin update lagune
```

## Commands

Type the commands with a hyphen in place of the dot, as the `/` menu lists them: where these docs show `/lagune.charter`, type `/lagune-charter`. **Grok Build** also takes them under the plugin's name, such as `/lagune:lagune-charter`, and both forms run the same command.

---

:::info[Permissions]

The first engine call asks for your permission. To allow it up front, add this rule to `~/.grok/config.toml`:

```toml
[permission]
allow = ["Bash(npx --yes lagune@*)"]
```

:::
