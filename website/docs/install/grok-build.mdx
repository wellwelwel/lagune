Install the plugin from your terminal:

```bash
grok plugin install wellwelwel/lagune@plugin-grok --trust
```

## Update

To update **Lagune**, run:

```bash
grok plugin update lagune
```

## Commands

Type the commands by their names, such as `/lagune-charter`. **Grok Build** also takes them under the plugin's name, such as `/lagune:lagune-charter`, and both forms run the same command.

---

:::info[Permissions]

The plugin carries **Lagune**'s engine and runs it through two tools: `lagune_read`, which only reads your project, and `lagune_write`, which changes only its `.lagune/` folder. To allow them up front, add these rules to `~/.grok/config.toml`:

```toml
[permission]
allow = ["MCPTool(lagune__lagune_read)", "MCPTool(lagune__lagune_write)"]
```

Where the engine runs through **npx** instead, as it does for the **skills.sh**, also allow `Bash(npx --yes lagune@*)`.

:::
