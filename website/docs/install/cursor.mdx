In **Cursor**, open **Customize**, select **From GitHub Repository**, and enter `https://github.com/wellwelwel/lagune`. Then select **Install** on **Lagune** and choose a project or user scope.

In the **Cursor CLI**, add the marketplace from your terminal, from the branch whose plugin carries **Lagune**'s engine:

```bash
agent plugin marketplace add https://github.com/wellwelwel/lagune --git-ref plugin-cursor
```

Then type `/plugins` in an `agent` session and install **Lagune**.

## Update

**Cursor** keeps **Lagune** at the commit it indexed until you refresh the marketplace. To update **Lagune**, select **Refresh** on the `lagune` marketplace in **Customize**. The **Cursor CLI** keeps the commit it added, so add the marketplace again:

```bash
agent plugin marketplace remove lagune
agent plugin marketplace add https://github.com/wellwelwel/lagune --git-ref plugin-cursor
```

## Commands

Type the commands by their names, such as `/lagune-charter`.

---

:::info[Permissions]

In the **Cursor CLI**, the plugin carries **Lagune**'s engine and runs it through two tools: `lagune_read`, which only reads your project, and `lagune_write`, which changes only its `.lagune/` folder. The first call to each asks for your permission. To allow them up front, add these rules to `.cursor/cli.json` for one project, or to `~/.cursor/cli-config.json` for all of them:

```json
{
  "permissions": {
    "allow": [
      "Mcp(plugin-lagune-lagune:lagune_read)",
      "Mcp(plugin-lagune-lagune:lagune_write)"
    ]
  }
}
```

Where the engine runs through **npx** instead, as it does for the **skills.sh**, also allow `Shell(npx:--yes lagune@*)`.

**Cursor** itself installs the plugin without the engine, so its commands run the engine through **npx**. In its default Auto-review mode, the sandbox cannot write **npm**'s cache, which lies outside your project, so **Cursor**'s classifier reviews each engine call and may ask for your permission. To run the engine inside the sandbox, turn on the shared build cache in `~/.cursor/sandbox.json`:

```json
{
  "enableSharedBuildCache": true
}
```
