**Lagune**'s commands install with the [**skills** CLI](https://github.com/vercel-labs/skills), so **Lagune** works with every agent it supports, including **Claude Code**, **Codex**, **Cursor**, **Gemini CLI**, and **GitHub Copilot**. Its [**Supported Agents**](https://github.com/vercel-labs/skills#supported-agents) list keeps the full set, with the key for each.

The **skills** CLI detects the agents in your project, or asks which ones to set up:

```bash
npx skills add wellwelwel/lagune
```

To choose them yourself, pass each key from that list with `--agent`:

```bash
npx skills add wellwelwel/lagune --agent claude-code codex
```

:::note[Not in the list]
**CoStrict**, **SHAI**, and **Xum** are not in that list. A project the **Lagune** CLI installed for one of them keeps working on `lagune@0.15.0`, as [**Migrate**](/docs/commands/migrate) explains.
:::
