Lagune works with **{{agents}} AI coding agents**, including Claude Code, Codex, Cursor, Gemini CLI, and GitHub Copilot. Each agent maps to a CLI key you pass to `init`, listed in the table below.

Pick your agent by passing its key, for example `npx -y lagune@latest init <alias>`. Without it, **Lagune** asks you to choose.

```prompt
# For example, using Lagune with Claude
npx -y lagune@latest init claude
```

- Deprecated agents will be removed in v1.0.0. Until then they keep their last shape, and the Status column names the agent to pick instead.
