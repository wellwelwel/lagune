# /lagune-detect

🔬 รู้ว่าระบบของคุณทำอะไรจริง ๆ และความเสี่ยงอยู่ตรงไหน

## สิ่งที่คำสั่งนี้ทำแผนผัง

**Lagune** อ่านโค้ดและทำแผนผังสิ่งที่พบ ข้อตรวจพบแต่ละรายการบอกว่าคืออะไร ทำไมจึงสำคัญ และมีหลักฐานอะไร ตัวอย่างเช่น:

- **การอัปโหลดไฟล์** ระบบรับไฟล์จากผู้ใช้:
  - _ทำไมจึงสำคัญ:_ ไฟล์ที่ปลอมตัวเป็นรูปภาพอาจซ่อนโค้ดอันตรายไว้
  - _หลักฐาน:_ handler `POST /upload` เชื่อ MIME type ที่ไคลเอนต์ส่งมา โดยไม่ตรวจชนิดจริงของไฟล์
- **การล็อกอินและเซสชัน** ผู้ใช้ล็อกอินเพื่อเข้าบัญชีของตัวเอง:
  - _ทำไมจึงสำคัญ:_ การจัดการเซสชันที่อ่อนแอทำให้บัญชีหนึ่งถูกอีกบัญชีหนึ่งยึดได้
  - _หลักฐาน:_ ลอจิกการออกเซสชัน ซึ่งออกเซสชันโดยไม่กำหนดเวลาหมดอายุ

ระหว่างนั้น detect จะให้ผลตัดสินกับความรู้เฉพาะทางทุกรายการใน [แคตตาล็อก](/docs/catalog) ของโปรเจกต์คุณโดยเทียบกับโค้ด นำรายการที่มีบริบทตรงกับโปรเจกต์ไปใช้ และบันทึกไว้ใต้ **Applied specializations** ซึ่งเป็นรายการที่ harden และ verify นำกลับมาใช้

จากนั้นคุณจะได้แผนผังที่ชัดเจนว่าระบบทำอะไรบ้างและความเสี่ยงอยู่ตรงไหน พร้อมให้ขั้นตอนถัดไปลงมือ

:::tip

- รันซ้ำเพื่ออัปเดตแผนผัง: ข้อตรวจพบที่แก้แล้วจะหายไป และข้อตรวจพบใหม่จะเข้ามา
- แผนผังจาก detect อยู่ที่ `.lagune/memory/detect.md`

:::
