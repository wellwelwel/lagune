## หลักการทำงาน

คำสั่งนี้อ่านโค้ดทุกจุดที่ harden บันทึกไว้ และยืนยันว่าโค้ดตรงกับที่อ้างไว้จริง การพิสูจน์ก็คือการเทียบนี้ คือเทียบโค้ดกับบันทึก มาตรการควบคุมแต่ละรายการจะได้ผลตัดสินอย่างใดอย่างหนึ่งจาก 3 แบบ:

| ผลตัดสิน                     | ความหมาย                                                 |
| ---------------------------- | -------------------------------------------------------- |
| ✅ Risk closed               | โค้ดทำตามที่บันทึกอ้างไว้ทุกประการ                       |
| ❌ Risk not closed           | มาตรการควบคุมยังเปิดอยู่ verify จะส่งคุณกลับไปที่ harden |
| ❓ Cannot tell from the code | ดูหลักฐานจากโค้ดอย่างเดียวไม่ได้                         |

จากนั้น verify จะปิดความเสี่ยงที่พิสูจน์แล้วว่าปิดได้ออกจากทั้งห่วงโซ่เมื่อคุณยืนยัน ตัวอย่างเช่น:

- **การอัปโหลดไฟล์** (ผลตัดสิน: **✅ Risk closed**)
  - _วิธีพิสูจน์:_ อ่าน handler ของการอัปโหลดแล้วเห็นว่าตรวจชนิดจริงของไฟล์จากเนื้อหา บังคับขนาดสูงสุด และปฏิเสธทุกอย่างที่นอกเหนือจากนั้น ตรงตามที่บันทึกอ้างไว้ทุกประการ
  - _หลักฐาน:_ ฟังก์ชัน `handleUpload` ซึ่งตรวจชนิดจริงของไฟล์จากเนื้อหา

ถ้าความเสี่ยงยังไม่ปิด verify จะบอกตรง ๆ และส่งคุณกลับไปที่ [`/lagune-harden`](/docs/commands/harden) เพราะการแก้ไขยังเปิดอยู่

:::tip

- คำสั่งนี้สร้างต่อจากบันทึก hardening ทั้งหมด
- คำสั่งนี้อ่านโค้ดของคุณเพื่อตัดสินเท่านั้น และไม่ลดทอนมาตรการควบคุมหรือเขียนโค้ดใหม่เพื่อให้ผลตัดสินผ่าน
- รันซ้ำเพื่อปรับผลตัดสินให้ตรงกับสภาพปัจจุบัน: ผลตัดสินที่ล้าสมัยจะหายไป และความเสี่ยงที่ไม่ได้ปิดอยู่แล้วจะกลับมาถูกชี้ว่าเป็นปัญหาอีกครั้ง
- เมื่อพิสูจน์ได้ว่าความเสี่ยงปิดแล้ว คำสั่งนี้จะถามคุณหนึ่งครั้ง แล้วลบข้อตรวจพบนั้นออกจากทั้งห่วงโซ่ (detect, plan, harden และการติดตาม)
- คำสั่งนี้ไม่เขียนรายงานของตัวเอง: ผลตัดสินแต่ละรายการอยู่ในบล็อกของมาตรการควบคุมนั้นใน `.lagune/memory/harden.md` ซึ่ง harden จะอ่านในการรันครั้งถัดไป

:::

:::warning[ต้องรัน harden ก่อน]
verify สร้างต่อจาก [`/lagune-harden`](/docs/commands/harden)
:::

## รอบการทำงานสิ้นสุด

เมื่อปิดทุกอย่างในขอบเขตแล้ว รอบการทำงานจึงสิ้นสุดลง และจะเปิดใหม่ก็ต่อเมื่อโค้ดเปลี่ยน ความปลอดภัยปิดให้จบได้ เวิร์กโฟลว์จึงมีจุดสิ้นสุด ไม่ใช่วนซ้ำไม่รู้จบ
