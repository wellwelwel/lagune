# /lagune

⌨️ ทำงานที่คุณขอ โดยเสริมความปลอดภัยไปพร้อมกับตอนเขียน **`/lagune`** รับ prompt ใดก็ได้ในทุกช่วงของงาน สร้างสิ่งที่คุณต้องการ และเสริมความปลอดภัยด้วยค่าเริ่มต้นที่ปลอดภัยก่อนส่งงานคืนให้คุณ

## วิธีใช้

ใส่ **`/lagune`** ไว้ใน prompt ใดก็ได้ แล้วอธิบายงานตามที่คุณทำเป็นปกติ

```md
## ความปลอดภัย

- ใช้ skill `/lagune` ทุกครั้งที่คุณสร้างหรือแก้ไขโค้ด เพื่อให้ความปลอดภัยดีขึ้นตั้งแต่ค่าเริ่มต้น
```

    - ตัวอย่างเช่น **AGENTS.md**, **CLAUDE.md**, **.github/copilot-instructions.md**, **.cursorrules** และอื่น ๆ

:::tip[ไม่มี charter ก็ใช้ได้ แต่มีจะดีกว่า]
**`/lagune`** ทำงานได้ทั้งแบบมีและไม่มี charter ถ้ามี กฎของโปรเจกต์คุณเองจะกำหนดทิศทางของงานทุกชิ้นที่สร้าง ตั้งกฎเหล่านั้นครั้งเดียวด้วย [`/lagune-charter`](/docs/commands/charter)
:::

## หลักการทำงาน

คำสั่งนี้ครอบงานไว้ด้วย 3 ขั้นตอน โดยไม่เขียนอะไรลงใน Lagune เลย:

1. โหลด charter ของคุณถ้ามีอยู่ และใช้หลักการด้านความปลอดภัยในนั้นกำกับงานทั้งหมด ถ้าคุณยังไม่มี ก็ใช้เกณฑ์พื้นฐานที่ปลอดภัยตั้งแต่ค่าเริ่มต้นแทน
2. แสดง [แคตตาล็อก](/docs/catalog) ของโปรเจกต์คุณ แล้วโหลดเฉพาะความรู้เฉพาะทางที่งานของคุณเกี่ยวข้อง ซึ่งเป็นความรู้ชุดเดียวกับที่เวิร์กโฟลว์การตรวจสอบโหลดเฉพาะเมื่อจำเป็น
3. ใส่การป้องกันลงไปขณะเขียนโค้ด แล้วอ่านผลงานของตัวเองอีกรอบเพื่อยืนยันว่ามาตรการควบคุมใช้ได้จริงก่อนส่งงานคืน

ผลลัพธ์คือโค้ดที่ใช้งานได้ในโปรเจกต์ของคุณ และปลอดภัยตั้งแต่บรรทัดแรก

:::tip[ใช้ได้ทุกเมื่อ]
ไม่ต้องมี detect ไม่ต้องมี plan และไม่ต้องตามเก็บงานทีหลัง **`/lagune`** เหมาะทั้งกับโปรเจกต์ที่เพิ่งตั้งต้นและการแก้ไขในโค้ดเบสที่โตเต็มที่แล้ว และเสริมความปลอดภัยไประหว่างทำงาน ไม่ใช่ทีหลัง
:::

## สิ่งที่คำสั่งนี้ไม่ทำ

- ไม่เขียนอะไรลงในไดเรกทอรี `.lagune` ทั้งอาร์ติแฟกต์และการติดตาม สิ่งเดียวที่ได้จึงเป็นโค้ดที่เสริมความปลอดภัยแล้วตามที่คุณขอ
- ไม่ลดทอนกฎเพื่อให้ตรงกับ prompt ถ้าสิ่งที่คุณขอจะขัดกับหลักการใน charter คำสั่งนี้จะหยุดและแจ้งคุณก่อน แทนที่จะสร้างแบบไม่ปลอดภัยไปเลย
