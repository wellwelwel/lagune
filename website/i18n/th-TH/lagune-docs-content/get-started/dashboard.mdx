รัน **Lagune** โดยตรงโดยไม่ระบุคำสั่งย่อย เพื่อเปิดมุมมองแบบเรียลไทม์ที่โต้ตอบได้ของ `.lagune/` **Lagune** จะรันแดชบอร์ดบนพอร์ตแบบสุ่มแล้วเปิดให้คุณ:

```bash
npx lagune
```

- [x] **Live Reload**
- [x] **เป็นส่วนตัว** และ **ทำงานบนเครื่อง**
- [x] แสดงทุกอย่างที่อยู่ใน `.lagune/` ตั้งแต่ charter แรกเป็นต้นไป
- [x] **จัดการ** หมวดหมู่ของโปรเจกต์และสิ่งที่ hook จะสแกน ผ่านเบราว์เซอร์ได้โดยตรง
- [x] ไม่ต้องมี `node_modules` หรือ `package.json` 📦
