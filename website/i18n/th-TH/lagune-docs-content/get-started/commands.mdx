เมื่อ [ติดตั้ง](/docs) **Lagune** แล้ว เอเจนต์ **AI** ของคุณจะได้รับชุด skill ที่ใช้ได้ 2 แบบ และทั้งสองแบบอยู่ภายใต้ **charter**: ทำให้งานใหม่ปลอดภัยไปพร้อมกับที่สร้าง หรือรันการตรวจสอบเต็มรูปแบบกับโปรเจกต์

<Tabs queryString="mode">
  <TabItem value="build" label="⌨️ สร้างและพัฒนา" default>

คุณไม่จำเป็นต้องทำงานให้เสร็จก่อนจึงจะทำให้ปลอดภัย ใช้ [**`/lagune`**](/docs/commands/lagune) กับงานที่คุณกำลังเขียน**อยู่ตอนนี้**:

| Skill                                         | สิ่งที่ทำให้คุณ                                                             |
| --------------------------------------------- | --------------------------------------------------------------------------- |
| [**/lagune-charter**](/docs/commands/charter) | กำหนดกฎความปลอดภัยของโปรเจกต์ ซึ่งเป็นรากฐานที่ `/lagune` ยึดในการสร้าง     |
| [**/lagune**](/docs/commands/lagune)          | สร้างสิ่งที่คุณขอและเสริมความปลอดภัยไปพร้อมกับที่เขียน ตามแนวทางของ charter |

:::tip[ใช้ได้ทุกเมื่อ]
[**`/lagune`**](/docs/commands/lagune) ทำตามกฎใน charter ของคุณทุกครั้งที่รัน โดยรับ prompt ใดก็ได้ สร้างสิ่งที่คุณขอ และเสริมความปลอดภัยด้วยค่าเริ่มต้นที่ปลอดภัยไประหว่างทาง ไม่ใช่ทีหลัง
:::

**ขั้นตอนแบบ Blue Team** เต็มรูปแบบ: อ่านว่าโปรเจกต์ทำอะไร ทำแผนผังความเสี่ยง แล้วปิดความเสี่ยงเหล่านั้น แต่ละ skill ต่อยอดจากตัวก่อนหน้า คุณจึงแค่ทำตามรายการจากบนลงล่าง:

| #   | Skill                                         | สิ่งที่ทำให้คุณ                                                                |
| --- | --------------------------------------------- | ------------------------------------------------------------------------------ |
| 1   | [**/lagune-charter**](/docs/commands/charter) | กำหนดกฎความปลอดภัยของโปรเจกต์ โดยเสนอให้คุณหรือปรับตามสิ่งที่คุณบอก            |
| 2   | [**/lagune-detect**](/docs/commands/detect)   | อ่านโค้ดของคุณและทำแผนผังว่าระบบทำอะไรและความเสี่ยงอยู่ตรงไหน                  |
| 3   | [**/lagune-plan**](/docs/commands/plan)       | เปลี่ยนสิ่งที่ detect พบเป็นแผนการป้องกัน พร้อมการแก้ไขสำหรับข้อตรวจพบแต่ละข้อ |
| 4   | [**/lagune-harden**](/docs/commands/harden)   | นำการแก้ไขในแผนไปใช้กับโค้ดของคุณอย่างปลอดภัยทีละรายการ                        |
| 5   | [**/lagune-verify**](/docs/commands/verify)   | พิสูจน์ว่าการแก้ไขแต่ละรายการใช้ได้จริง แล้วปิดรายการที่พิสูจน์แล้ว            |
