**Lagune** ช่วยให้เอเจนต์ AI ของคุณทำให้โปรเจกต์ปลอดภัยขึ้น คุณเพียงชี้ไปที่โค้ด แล้วเอเจนต์จะค้นหาว่าระบบของคุณทำอะไรจริง ๆ จากนั้นพาคุณทำงานด้านความปลอดภัยที่สำคัญกับระบบนั้น **Lagune** เป็นโปรเจกต์แรกของระเบียบวิธี [Security-Driven Hardening (SDH)](/docs/references/paper)

:::tip[สนับสนุนโอเพนซอร์ส]
ชอบ **Lagune** ไหม <ArrowLink to="https://github.com/wellwelwel/lagune">ให้ ⭐ เราบน **GitHub**</ArrowLink>
:::

## เลือกเอเจนต์ของคุณ

<AgentPicker />

:::info

- เบื้องหลัง **Lagune** ทำงานบน **Node.js** แต่คุณใช้ภาษาใดก็ได้ตามต้องการ
- หากต้องการรันแบบออฟไลน์ทั้งหมด ให้ติดตั้ง **Lagune** ในโปรเจกต์ด้วย `npm i -D lagune@{{version}}`

:::

## หมวดหมู่

ความรู้ด้านความปลอดภัยของ **Lagune** มาในรูปแบบ [**ความรู้เฉพาะทาง**](/docs/catalog) ที่จัดกลุ่มเป็น [**หมวดหมู่**](/docs/categories)

<CategoryPicker />

:::tip
ทุกโปรเจกต์เริ่มต้นด้วย `owasp` แล้วคำสั่ง [`/lagune-charter`](/docs/commands/charter) จะเพิ่มหมวดหมู่ที่ผลการอ่านโปรเจกต์รองรับ
:::

## สิ่งที่ต้องมี

ระบบของคุณต้องติดตั้ง [**Node.js (LTS)**](https://nodejs.org/en/download/package-manager) ไว้แล้ว
