<InstallHeader name='skills.sh' />

Установите команды **Lagune** в свой проект из терминала через [**skills.sh**](https://www.skills.sh/wellwelwel/lagune):

```bash
npx skills add wellwelwel/lagune -y
```

Или вставьте этот промпт в своего агента:

```md
Выполни `npx --yes skills add wellwelwel/lagune --yes` и сразу следуй сгенерированным инструкциям навыка. Прочитай весь вывод, при необходимости сначала перенаправив его во временный файл. Разрешай относительные пути от директории со вспомогательными файлами, которую он указывает.
```

  </TabItem>
  <TabItem value="github-cli" label="GitHub CLI">

<InstallHeader name='GitHub CLI' />

Установите команды **Lagune** в свой проект из терминала через [**GitHub CLI**](https://cli.github.com/) версии 2.90.0 или новее:

```bash
gh skill install wellwelwel/lagune --all --scope project
```

Или вставьте этот промпт в своего агента:

```md
Выполни `gh skill install wellwelwel/lagune --all --scope project` и прочитай весь вывод, при необходимости сначала перенаправив его во временный файл.
```

  </TabItem>
</Tabs>

## Обновление

<Tabs groupId="skills-installer">
  <TabItem value="skills-sh" label="skills.sh" default>

Чтобы обновить **Lagune**, выполните:

```bash
npx skills update
```

Или вставьте этот промпт в своего агента:

```md
Выполни `npx --yes skills update -y` и прочитай весь вывод, при необходимости сначала перенаправив его во временный файл.
```

  </TabItem>
  <TabItem value="github-cli" label="GitHub CLI">

Чтобы обновить **Lagune**, выполните:

```bash
gh skill update --all
```

Или вставьте этот промпт в своего агента:

```md
Выполни `gh skill update --all` и прочитай весь вывод, при необходимости сначала перенаправив его во временный файл.
```

  </TabItem>
</Tabs>

---

:::info[Песочница]

В песочнице без доступа к сети команды не могут скачать движок. Установите его в проект из своего терминала, один раз и после каждого обновления:

```bash
npm i -D lagune@{{version}}
```

:::
