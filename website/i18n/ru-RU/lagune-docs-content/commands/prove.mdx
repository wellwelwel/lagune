# /lagune-prove

🧪 Превратите каждую обнаруженную находку в запускаемое свидетельство, ориентированное только на защиту, для ответственного раскрытия.

Для каждой находки из карты обнаружения команда пишет самодостаточный бюллетень и тест, который проверяет **безопасный путь**, поэтому тест падает, пока проблема существует, и проходит, как только код исправлен.

:::tip
Тесты **Lagune** хранятся изолированно в `.lagune/`, отдельно от вашего собственного набора тестов.
:::

## Использование

## Как это работает

Команда читает исходный код, на который указывает каждая находка, и для каждой доказанной находки создает в `.lagune/proofs/` директорию ровно с двумя файлами:

| Файл                           | Что это                                                                                                                                         |
| ------------------------------ | ----------------------------------------------------------------------------------------------------------------------------------------------- |
| `report.test.mjs` (или `.cjs`) | Тест. Он запускается на Poku, если ваш проект уже его использует, а иначе на встроенном раннере Node.js, поэтому ничего устанавливать не нужно. |
| `report.md`                    | Самодостаточный бюллетень: критичность, последствия, как воспроизвести и команда запуска, понятный сам по себе.                                 |

Доказательства всегда пишутся на JavaScript, поэтому они переносимы, на каком бы языке ни был написан ваш проект. Индекс `README.md` ссылается на каждое доказательство и дает одну команду, чтобы запустить их все.

:::tip

- Команда **необязательна и автономна**: она не входит в пять фаз и не является частью цепочки отслеживания.
- Она пишет только в `.lagune/proofs/` и никогда не трогает артефакты фаз или ваш код, который она только читает.
- Находка, тест которой не воспроизводит проблему, не получает доказательства, и команда попросит запустить [`/lagune-detect`](/docs/commands/detect) для этого места, чтобы сверить данные.
- Повторный запуск сверяет доказательства: директория находки, которой больше нет или которая больше не воспроизводится, удаляется.

:::

:::important

**Она запускается, только когда вы ее вызываете:** агент никогда не запускает ее сам.

:::

:::warning[Опирается на detect]
Prove читает карту обнаружения от [`/lagune-detect`](/docs/commands/detect), поэтому сначала запустите detect.
:::

## Только защита и только с разрешения

Прежде чем что-либо создавать, команда убеждается, что у вас есть разрешение тестировать цель, и отказывает в любом запросе на работающий эксплойт, атакующую нагрузку или обход обнаружения. Доказательство демонстрирует безопасное поведение и никогда не содержит атакующих входных данных.

## От доказательства к раскрытию

Два файла каждой доказанной находки вместе помещаются в **приватный GitHub Gist**, чтобы сообщить об уязвимости. Они свидетельствуют о существующей нераскрытой проблеме, поэтому `.gitignore` внутри `.lagune/proofs/` не пускает их ни в один коммит: делитесь ими только через этот Gist, пока мейнтейнеры не устранят проблему.

Закрывать находку в цепочке **Lagune** по-прежнему должны [`/lagune-harden`](/docs/commands/harden) и [`/lagune-verify`](/docs/commands/verify): prove создает свидетельства, но ничего не закрывает.
