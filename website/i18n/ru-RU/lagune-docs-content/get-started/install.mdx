**Lagune** помогает вашему ИИ-агенту сделать проект безопаснее. Вы указываете на свой код, агент разбирается, что на самом деле делает ваша система, а затем ведет вас через ту работу по безопасности, которая для нее важна. **Lagune** является первым проектом методологии [Security-Driven Hardening (SDH)](/docs/references/paper).

:::tip[Поддержите открытый код]
Нравится **Lagune**? <ArrowLink to="https://github.com/wellwelwel/lagune">Поставьте нам ⭐ на **GitHub**</ArrowLink>
:::

## Выберите агента

<AgentPicker />

:::info

- Внутри **Lagune** работает на **Node.js**, но вы пишете на любом языке.
- Чтобы работать полностью офлайн, установите **Lagune** в проект командой `npm i -D lagune@{{version}}`.

:::

## Категории

Знания **Lagune** о безопасности поставляются в виде [**специализаций**](/docs/catalog), сгруппированных по [**категориям**](/docs/categories).

<CategoryPicker />

:::tip
Проект начинается с `owasp`, а [`/lagune-charter`](/docs/commands/charter) добавляет категории, которые подтверждает анализ проекта.
:::

## Требования

В системе должен быть установлен [**Node.js (LTS)**](https://nodejs.org/en/download/package-manager).
