Запустите **Lagune** напрямую, без подкоманды, чтобы получить интерактивное представление `.lagune/` в реальном времени. Команда поднимает дашборд и открывает его на случайном порту:

```bash
npx lagune
```

- [x] **Live Reload**
- [x] **Приватно** и **локально**
- [x] Показывает все, что есть в `.lagune/`, начиная с первых принципов безопасности
- [x] **Управляйте** категориями проекта прямо из браузера
- [x] Не нужны ни `node_modules`, ни `package.json` 📦
