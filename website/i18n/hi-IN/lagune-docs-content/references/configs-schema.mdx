`.lagune/configs.json` में दर्ज होता है कि प्रोजेक्ट किन [**श्रेणियों**](/docs/categories) का इस्तेमाल करता है, इसमें प्रोजेक्ट की अपनी [**विशेषज्ञताओं**](/docs/catalog) का इंडेक्स रहता है, और यही तय करता है कि [**चेकर**](/docs/hooks/configure) किन चीज़ों को छोड़ दें। इसके JSON Schema की मदद से, फ़ाइल एडिट करते समय आपका एडिटर हर फ़ील्ड को ऑटोकम्प्लीट करता है और कोई टाइपो या अनजानी श्रेणी पकड़ लेता है।

## मौजूदा स्कीमा

जब भी **Lagune** यह फ़ाइल लिखता है और उसमें कोई `$schema` नहीं पाता, तो वह फ़ाइल को मौजूदा स्कीमा की ओर इशारा करवा देता है:

```json
{
  "$schema": "https://lagune.ai/schemas/configs.json",
  "categories": ["owasp", "javascript"]
}
```

यह पता हमेशा मौजूदा **Lagune** के साथ चलता है। **Lagune** 0.16.0 से पहले लिखी गई फ़ाइल को यह पता अपने अगले बदलाव पर मिलता है, और तब तक हर चरण इसकी ओर ध्यान दिलाता है।

## कोई वर्शन तय करें

0.16.0 और उसके बाद की हर **Lagune** रिलीज़ में स्कीमा वैसा ही रहता है जैसा वह उस वर्शन में था, जो **npm** पर प्रकाशित होता है और **jsDelivr** से मिलता है। कोई वर्शन तय करने के लिए, उसे `lagune@` के ठीक बाद लिखें, यानी `$schema` वाले पते में:

```json
{
  "$schema": "https://cdn.jsdelivr.net/npm/lagune@0.16.0/schemas/configs.json"
}
```

वर्शन में कोई भी semver रेंज चल जाती है:

| वर्शन              | स्कीमा                          |
| ------------------ | ------------------------------- |
| `0.16.0`           | 0.16.0 वाला स्कीमा              |
| `0.16.x` या `0.16` | सबसे नई 0.16 रिलीज़ वाला स्कीमा |
| `0.x` या `0`       | सबसे नई 0.x रिलीज़ वाला स्कीमा  |
| `latest`           | सबसे नई रिलीज़ वाला स्कीमा      |
