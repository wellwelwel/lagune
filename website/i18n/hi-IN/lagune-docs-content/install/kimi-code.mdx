**Kimi Code** सेशन में प्लगइन इंस्टॉल करें, **Trust and install** चुनें, फिर उसे लोड करने के लिए नया सेशन शुरू करें:

```prompt
/plugins install https://github.com/wellwelwel/lagune
/new
```

## अपडेट

**Lagune** को अपडेट करने के लिए उसे फिर से इंस्टॉल करें:

```prompt
/plugins install https://github.com/wellwelwel/lagune
/new
```

## कमांड

कमांड प्लगइन के नाम के साथ टाइप करें, जैसे `/lagune:lagune-charter`, जो `/lagune-charter` कमांड है। `/` मेन्यू में ये `/skill:lagune:lagune-charter` के रूप में दिखती हैं, और इस रूप में टाइप करने पर भी ये काम करती हैं।
