**Lagune** hjælper din AI-agent med at gøre et projekt mere sikkert. Du peger det mod din kode, og agenten finder ud af, hvad dit system rent faktisk gør, og guider dig derefter gennem det sikkerhedsarbejde, der betyder noget for det. **Lagune** er det første projekt i metoden [Security-Driven Hardening (SDH)](/docs/references/paper).

:::tip[Støt open source]
Kan du lide **Lagune**? <ArrowLink to="https://github.com/wellwelwel/lagune">Giv os en ⭐ på **GitHub**</ArrowLink>
:::

## Vælg din agent

<AgentPicker />

:::info

- **Lagune** kører på **Node.js** bag kulisserne, men du bruger det sprog, du vil.
- Hvis du vil køre helt offline, så installér **Lagune** i dit projekt med `npm i -D lagune@{{version}}`.

:::

## Kategorier

Sikkerhedsviden i **Lagune** kommer som [**specialiseringer**](/docs/catalog), grupperet i [**kategorier**](/docs/categories).

<CategoryPicker />

:::tip
Et projekt starter med `owasp`, og [`/lagune-charter`](/docs/commands/charter) tilføjer de kategorier, som dets læsning af projektet understøtter.
:::

## Krav

Du skal have [**Node.js (LTS)**](https://nodejs.org/en/download/package-manager) installeret på dit system.
