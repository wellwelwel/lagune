Log ind på **Devin**, og installér derefter pluginnet fra din terminal:

```bash
devin auth login
devin plugins install wellwelwel/lagune
```

## Opdatering

Kør følgende for at opdatere **Lagune**:

```bash
devin plugins update lagune
```

## Kommandoer

Skriv kommandoerne under pluginnets navn, såsom `/lagune:lagune-charter` for `/lagune-charter`. Menuen `/` viser dem også.
