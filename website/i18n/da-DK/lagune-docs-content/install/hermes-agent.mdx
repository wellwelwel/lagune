Installér pluginnet fra din terminal:

```bash
hermes plugins install wellwelwel/lagune --enable
```

- Når **Hermes Agent** beder dig bekræfte et plugin uden for sit katalog, så **bekræft det**.
- Når den tilbyder at installere repositoriets afhængigheder til **Node.js**, så **afvis**.

## Opdatering

Kør følgende for at opdatere **Lagune**:

```bash
hermes plugins update lagune
```

## Kommandoer

Skriv kommandoerne under pluginnets navn, såsom `/lagune:lagune-charter` for `/lagune-charter` og `/lagune:lagune` for `/lagune`.
