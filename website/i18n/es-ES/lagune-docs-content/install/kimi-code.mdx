Instala el plugin desde una sesión de **Kimi Code**, elige **Trust and install** y después inicia una sesión nueva para cargarlo:

```prompt
/plugins install https://github.com/wellwelwel/lagune
/new
```

## Actualización

Para actualizar **Lagune**, vuelve a instalarlo:

```prompt
/plugins install https://github.com/wellwelwel/lagune
/new
```

## Comandos

Escribe los comandos precedidos del nombre del plugin, como `/lagune:lagune-charter` para `/lagune-charter`. El menú `/` los muestra como `/skill:lagune:lagune-charter`, que también funciona.
