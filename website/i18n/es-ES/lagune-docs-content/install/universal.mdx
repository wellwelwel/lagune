<InstallHeader name='skills.sh' />

Instala los comandos de **Lagune** en tu proyecto desde tu terminal con [**skills.sh**](https://www.skills.sh/wellwelwel/lagune), manteniendo **Project** como ámbito de instalación:

```bash
npx skills add wellwelwel/lagune --skill '*'
```

O pega este prompt en tu agente:

```md
Ejecuta `npx --yes skills add wellwelwel/lagune` y sigue ahora las instrucciones de skill que genere. Lee su salida completa, redirigiéndola antes a un archivo temporal si hace falta. Resuelve las rutas relativas a partir del directorio de archivos de apoyo que indique.
```

  </TabItem>
  <TabItem value="github-cli" label="GitHub CLI">

<InstallHeader name='GitHub CLI' />

Instala los comandos de **Lagune** en tu proyecto desde tu terminal con [**GitHub CLI**](https://cli.github.com/) 2.90.0 o posterior:

```bash
gh skill install wellwelwel/lagune --all --scope project
```

O pega este prompt en tu agente:

```md
Ejecuta `gh skill install wellwelwel/lagune --all --scope project` y lee su salida completa, redirigiéndola antes a un archivo temporal si hace falta.
```

  </TabItem>
</Tabs>

## Actualización

<Tabs groupId="skills-installer">
  <TabItem value="skills-sh" label="skills.sh" default>

Para actualizar **Lagune**, ejecuta:

```bash
npx skills update
```

O pega este prompt en tu agente:

```md
Ejecuta `npx --yes skills update -y` y lee su salida completa, redirigiéndola antes a un archivo temporal si hace falta.
```

  </TabItem>
  <TabItem value="github-cli" label="GitHub CLI">

Para actualizar **Lagune**, ejecuta:

```bash
gh skill update --all
```

O pega este prompt en tu agente:

```md
Ejecuta `gh skill update --all` y lee su salida completa, redirigiéndola antes a un archivo temporal si hace falta.
```

  </TabItem>
</Tabs>

---

:::warning[Una sola vía de instalación por agente]
Instala **Lagune** por una única vía: **skills.sh**, **GitHub CLI** o su **plugin**.
:::

:::info[Permisos]

Los comandos ejecutan el motor como `npx --yes lagune@{{version}}`, y la [página de instalación de cada agente](/docs) muestra la regla que lo permite de antemano. En un sandbox sin acceso a la red, instala el motor en tu proyecto desde tu propio terminal, una vez y tras cada actualización:

```bash
npm i -D lagune@{{version}}
```

:::
