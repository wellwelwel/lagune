Una vez que [instalas](/docs) **Lagune**, tu agente de **IA** desbloquea un conjunto de skills. Hay dos formas de usarlas, y ambas se rigen por tus **principios de seguridad**: proteger el trabajo nuevo a medida que lo desarrollas, o ejecutar la auditoría completa sobre un proyecto.

<Tabs queryString="mode">
  <TabItem value="build" label="⌨️ Construcción / Desarrollo" default>

No hace falta que termines tu trabajo antes de protegerlo. Usa [**`/lagune`**](/docs/commands/lagune) para lo que estás escribiendo **ahora mismo**:

| Skill                                         | Qué hace por ti                                                                                 |
| --------------------------------------------- | ----------------------------------------------------------------------------------------------- |
| [**/lagune-charter**](/docs/commands/charter) | Fija las reglas de seguridad de tu proyecto, la base sobre la que construye `/lagune`           |
| [**/lagune**](/docs/commands/lagune)          | Crea lo que pides y lo bastiona a medida que se escribe, guiado por tus principios de seguridad |

:::tip[Úsalo cuando quieras]
[**`/lagune`**](/docs/commands/lagune) respeta tus principios de seguridad cada vez que se ejecuta. Acepta cualquier prompt, crea lo que pediste y lo bastiona con valores por defecto seguros sobre la marcha, no después.
:::

#### Skills especiales

| Skill                                               | Qué hace                                                                                           |
| --------------------------------------------------- | -------------------------------------------------------------------------------------------------- |
| [**/lagune-specialize**](/docs/commands/specialize) | Enseña a **Lagune** una nueva especialización de seguridad a partir de artículos, exploits o temas |

  </TabItem>
  <TabItem value="audit" label="🔬 Auditoría: flujo Blue Team">

El **flujo Blue Team** completo: leer lo que hace un proyecto, identificar sus riesgos y cerrarlos. Cada fase se apoya en la anterior, así que basta con seguir la lista de arriba abajo:

| #   | Skill                                         | Qué hace por ti                                                                               |
| --- | --------------------------------------------- | --------------------------------------------------------------------------------------------- |
| 1   | [**/lagune-charter**](/docs/commands/charter) | Fija las reglas de seguridad de tu proyecto, propuestas para ti o adaptadas a lo que le digas |
| 2   | [**/lagune-detect**](/docs/commands/detect)   | Lee tu código e identifica qué hace tu sistema y dónde están los riesgos                      |
| 3   | [**/lagune-plan**](/docs/commands/plan)       | Convierte lo que encontró detect en un plan de defensa, con una corrección para cada hallazgo |
| 4   | [**/lagune-harden**](/docs/commands/harden)   | Aplica a tu código las correcciones del plan, de forma segura y una a una                     |
| 5   | [**/lagune-verify**](/docs/commands/verify)   | Demuestra que cada corrección aplicada se sostiene y cierra las que superan la prueba         |

---
