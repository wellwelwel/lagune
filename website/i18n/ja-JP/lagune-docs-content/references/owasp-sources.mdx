# OWASP 出典マッピング：攻撃 × Cheat Sheet

このドキュメントでは、OWASP のすべての**攻撃**（`www-community`）と **Cheat Sheet**（`CheatSheetSeries`）をセキュリティのカテゴリに対応づけ、それぞれ公式の公開ページにリンクしています。同じカテゴリ内で同等の項目は、チェックリストの 1 行にまとめています。同じリスクを扱う攻撃と Cheat Sheet は、カンマ区切りで並べています。直接対応するものがない項目は、それぞれ単独の行にしています。

- クレジットは OWASP に帰属します。攻撃のページは `https://owasp.org/www-community/attacks/<attack>`、Cheat Sheet は `https://cheatsheetseries.owasp.org/cheatsheets/<cheat>.html` にあります。

## 25. ビジネスロジックと機能の悪用

ビジネスロジックと機能の悪用には、攻撃対象領域ごとの専門知識が守れるような、単一のコード上の攻撃対象領域がありません。防御はアプリケーション固有の設計によるもので、プロジェクトの脅威モデリングから導かれるのと同じ考え方です。"対象外" に移しました。

## 31. クラウド、コンテナー、インフラストラクチャ

コンテナーとワークロードの設定は、開発者がアプリと一緒にリリースする、コードとして管理された設定です（`Dockerfile`、Compose、Pod の `securityContext`）。`harden` が修正し、`verify` が証明できる実在の攻撃対象領域なので、対象に含めます。クラスター管理（RBAC、etcd、API サーバー、アドミッション制御、ネットワークセグメンテーション）は運用者の領域なので、対象外のままです。

- [x] [Docker Security](https://cheatsheetseries.owasp.org/cheatsheets/Docker_Security_Cheat_Sheet.html), [Node.js Docker](https://cheatsheetseries.owasp.org/cheatsheets/NodeJS_Docker_Cheat_Sheet.html) (container)
- [x] [Kubernetes Security](https://cheatsheetseries.owasp.org/cheatsheets/Kubernetes_Security_Cheat_Sheet.html)（container：ワークロードと Pod の部分。クラスター管理は対象外のまま）

## 33. シークレットと設定

シークレット管理は運用の領域で、保管庫、CI/CD、クラウドの設定、ローテーションが関わります。コードに関わる唯一の側面（ソースコードにハードコードされたシークレット）は決定論的なスキャンが扱うもので、リスクを扱う専門知識の対象ではありません。"対象外" に移しました。

## 34. プロセス、設計、ガバナンス

ユーザーのプライバシー保護はポリシーと設計の問題（データの最小化、透明性、保持期間）であり、専門知識が守るコード上の攻撃対象領域ではありません。"対象外" に移しました。

## 36. 組み込み / IoT / 特殊な分野

自動車とドローンのセキュリティは組み込みシステムの分野（CAN バス、OTA ファームウェア、センサーと無線の完全性、物理アクセス）であり、Lagune が監査する Web アプリケーションや API のソースコードではありません。"対象外" に移しました。

## 対象外（コード上の攻撃対象領域なし）

ここに挙げる項目は専門知識が扱う領域ではなく、チェックボックスもありません。ガバナンス、プロセス、運用面の堅牢化、またはフレームワークの使い方に関するもので、攻撃対象領域ごとの専門知識が守れるような、単一のコード上の攻撃対象領域を持ちません。セキュリティ上の価値は確かにありますが、その価値があるのはプロセスとアーキテクチャ（フレームワークの場合は、その言語専用のスキル）であり、このカタログが提供する防御ではありません。作業項目ではなく、参考として掲載しています。
