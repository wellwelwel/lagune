[**skills.sh**](https://www.skills.sh/wellwelwel/lagune) でターミナルからプロジェクトに **Lagune** のコマンドをインストールします：

```bash
npx skills add wellwelwel/lagune -y
```

または、次のプロンプトをエージェントに貼り付けます：

```md
`npx --yes skills add wellwelwel/lagune --yes` を実行し、生成されたスキルの指示に今すぐ従ってください。必要なら先に一時ファイルへリダイレクトして、出力全体を読んでください。相対パスは、出力に示されたサポートファイルのディレクトリを基準に解決してください。
```

  </TabItem>
  <TabItem value="github-cli" label="GitHub CLI">

<InstallHeader name='GitHub CLI' />

[**GitHub CLI**](https://cli.github.com/) 2.90.0 以降を使って、ターミナルからプロジェクトに **Lagune** のコマンドをインストールします：

```bash
gh skill install wellwelwel/lagune --all --scope project
```

または、次のプロンプトをエージェントに貼り付けます：

```md
`gh skill install wellwelwel/lagune --all --scope project` を実行し、必要なら先に一時ファイルへリダイレクトして、出力全体を読んでください。
```

  </TabItem>
</Tabs>

## 更新

<Tabs groupId="skills-installer">
  <TabItem value="skills-sh" label="skills.sh" default>

**Lagune** を更新するには、次のコマンドを実行します：

```bash
npx skills update
```

または、次のプロンプトをエージェントに貼り付けます：

```md
`npx --yes skills update -y` を実行し、必要なら先に一時ファイルへリダイレクトして、出力全体を読んでください。
```

  </TabItem>
  <TabItem value="github-cli" label="GitHub CLI">

**Lagune** を更新するには、次のコマンドを実行します：

```bash
gh skill update --all
```

または、次のプロンプトをエージェントに貼り付けます：

```md
`gh skill update --all` を実行し、必要なら先に一時ファイルへリダイレクトして、出力全体を読んでください。
```

  </TabItem>
</Tabs>

---

:::info[サンドボックス]

ネットワークにアクセスできないサンドボックスでは、コマンドがエンジンをダウンロードできません。自分のターミナルからプロジェクトにエンジンをインストールします。最初に一度、その後は更新のたびに実行してください：

```bash
npm i -D lagune@{{version}}
```

:::
