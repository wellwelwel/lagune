**Lagune** は、AI エージェントがプロジェクトをより安全にするのを手伝います。コードに対して実行すると、エージェントはシステムが実際に何をしているかを把握したうえで、そのシステムにとって重要なセキュリティ作業を順に案内します。**Lagune** は、[Security-Driven Hardening (SDH)](/docs/references/paper) という方法論の最初のプロジェクトです。

:::tip[OSS を応援]
**Lagune** が気に入りましたか？<ArrowLink to="https://github.com/wellwelwel/lagune">**GitHub** で ⭐ をお願いします</ArrowLink>
:::

## エージェントを選ぶ

<AgentPicker />

:::info

- **Lagune** は内部で **Node.js** を使って動作しますが、開発に使う言語は自由です。
- 完全にオフラインで実行するには、`npm i -D lagune@{{version}}` で **Lagune** をプロジェクトにインストールします。

:::

## カテゴリ

**Lagune** のセキュリティに関する知見は [**専門知識**](/docs/catalog) という単位で提供され、[**カテゴリ**](/docs/categories) ごとにまとめられています。

<CategoryPicker />

:::tip
プロジェクトは `owasp` から始まり、[`/lagune-charter`](/docs/commands/charter) がプロジェクトを読み解いたうえで、その内容に裏付けられたカテゴリを追加します。
:::

## 動作要件

システムに [**Node.js (LTS)**](https://nodejs.org/en/download/package-manager) がインストールされている必要があります。
