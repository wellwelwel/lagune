**Lagune** aide votre agent IA à rendre un projet plus sûr. Vous le pointez vers votre code, et l'agent comprend ce que fait réellement votre système, puis vous guide dans le travail de sécurité qui compte pour lui. **Lagune** est le premier projet de la méthodologie [Security-Driven Hardening (SDH)](/docs/references/paper).

:::tip[Soutenez l'open source]
Vous aimez **Lagune** ? <ArrowLink to="https://github.com/wellwelwel/lagune">Donnez-nous une ⭐ sur **GitHub**</ArrowLink>
:::

## Choisissez votre agent

<AgentPicker />

:::info

- **Lagune** tourne sur **Node.js** en coulisses, mais vous utilisez le langage que vous voulez.
- Pour fonctionner entièrement hors ligne, installez **Lagune** dans votre projet avec `npm i -D lagune@{{version}}`.

:::

## Catégories

Les connaissances de sécurité de **Lagune** se présentent sous forme de [**spécialisations**](/docs/catalog), regroupées en [**catégories**](/docs/categories).

<CategoryPicker />

:::tip
Un projet commence avec `owasp`, et [`/lagune-charter`](/docs/commands/charter) ajoute les catégories que justifie sa lecture du projet.
:::

## Prérequis

Vous devez avoir [**Node.js (LTS)**](https://nodejs.org/en/download/package-manager) installé sur votre système.
