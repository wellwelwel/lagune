Une fois **Lagune** [installé](/docs), votre agent **IA** débloque un ensemble de skills. Il y a deux façons de les utiliser, toutes deux encadrées par la **charter** : sécuriser le nouveau travail pendant que vous le construisez, ou lancer l'audit complet d'un projet.

<Tabs queryString="mode">
  <TabItem value="build" label="⌨️ Construction / développement" default>

Inutile de finir votre travail avant de le sécuriser. Utilisez [**`/lagune`**](/docs/commands/lagune) pour le travail que vous écrivez **en ce moment** :

| Skill                                         | Ce qu'il fait pour vous                                                                    |
| --------------------------------------------- | ------------------------------------------------------------------------------------------ |
| [**/lagune-charter**](/docs/commands/charter) | Fixe les règles de sécurité de votre projet, la base sur laquelle `/lagune` construit      |
| [**/lagune**](/docs/commands/lagune)          | Construit ce que vous demandez et le durcit au fil de l'écriture, en suivant vos principes |

:::tip[Utilisez-le à tout moment]
[**`/lagune`**](/docs/commands/lagune) respecte vos principes de sécurité à chaque exécution. Il accepte n'importe quel prompt, construit ce que vous avez demandé et le durcit avec des valeurs par défaut sûres au fur et à mesure, pas plus tard.
:::

#### Skills spéciaux

| Skill                                               | Ce qu'il fait                                                                                              |
| --------------------------------------------------- | ---------------------------------------------------------------------------------------------------------- |
| [**/lagune-specialize**](/docs/commands/specialize) | Enseigne à **Lagune** une nouvelle spécialisation de sécurité à partir d'articles, d'exploits ou de sujets |

  </TabItem>
  <TabItem value="audit" label="🔬 Audit : flux Blue Team">

Le **flux Blue Team** complet : comprendre ce que fait un projet, cartographier ses risques et les clôturer. Chaque phase s'appuie sur la précédente, il suffit donc de suivre la liste de haut en bas :

| #   | Skill                                         | Ce qu'il fait pour vous                                                                             |
| --- | --------------------------------------------- | --------------------------------------------------------------------------------------------------- |
| 1   | [**/lagune-charter**](/docs/commands/charter) | Fixe les règles de sécurité de votre projet, proposées pour vous ou façonnées par ce que vous dites |
| 2   | [**/lagune-detect**](/docs/commands/detect)   | Lit votre code et cartographie ce que fait votre système et où se trouvent les risques              |
| 3   | [**/lagune-plan**](/docs/commands/plan)       | Transforme ce que detect a trouvé en plan de défense, avec un correctif pour chaque constat         |
| 4   | [**/lagune-harden**](/docs/commands/harden)   | Applique à votre code les correctifs du plan, en toute sécurité et un par un                        |
| 5   | [**/lagune-verify**](/docs/commands/verify)   | Prouve que chaque correctif appliqué est efficace et clôture ceux qui passent la preuve             |
