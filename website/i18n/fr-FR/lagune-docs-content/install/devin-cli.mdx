Connectez-vous à **Devin**, puis installez le plugin depuis votre terminal :

```bash
devin auth login
devin plugins install wellwelwel/lagune
```

## Mise à jour

Pour mettre à jour **Lagune**, exécutez :

```bash
devin plugins update lagune
```

## Commandes

Tapez les commandes sous le nom du plugin, comme `/lagune:lagune-charter` pour `/lagune-charter`. Le menu `/` les liste aussi.
