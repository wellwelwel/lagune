O **Lagune** ajuda seu agente de IA a deixar um projeto mais seguro. Você aponta para o seu código, o agente descobre o que o seu sistema realmente faz e então guia você pelo trabalho de segurança que importa para ele. O **Lagune** é o primeiro projeto da metodologia [Security-Driven Hardening (SDH)](/docs/references/paper).

:::tip[Apoie o open source]
Curtiu o **Lagune**? <ArrowLink to="https://github.com/wellwelwel/lagune">Dê uma ⭐ no **GitHub**</ArrowLink>
:::

## Escolha o seu agente

<AgentPicker />

:::info

- Por baixo dos panos, o **Lagune** roda em **Node.js**, mas você usa a linguagem que quiser.
- Para rodar totalmente offline, instale o **Lagune** no seu projeto com `npm i -D lagune@{{version}}`.

:::

## Categorias

O conhecimento de segurança do **Lagune** vem em [**especializações**](/docs/catalog), agrupadas em [**categorias**](/docs/categories).

<CategoryPicker />

:::tip
Todo projeto começa com `owasp`, e o [`/lagune-charter`](/docs/commands/charter) adiciona as categorias que a leitura dele sobre o projeto justifica.
:::

## Requisitos

Você precisa ter o [**Node.js (LTS)**](https://nodejs.org/en/download/package-manager) instalado no seu sistema.
