Depois que o **Lagune** está [instalado](/docs), o seu agente de **IA** ganha um conjunto de skills. Há duas formas de usá-las, e as duas são regidas pelo **charter**: proteger o trabalho novo enquanto você o constrói ou rodar a auditoria completa em um projeto.

<Tabs queryString="mode">
  <TabItem value="build" label="⌨️ Construção / desenvolvimento" default>

Você não precisa terminar o seu trabalho antes de protegê-lo. Use o [**`/lagune`**](/docs/commands/lagune) para o trabalho que você está escrevendo **agora**:

| Skill                                         | O que ela faz por você                                                                       |
| --------------------------------------------- | -------------------------------------------------------------------------------------------- |
| [**/lagune-charter**](/docs/commands/charter) | Define as regras de segurança do seu projeto, a base sobre a qual o `/lagune` constrói       |
| [**/lagune**](/docs/commands/lagune)          | Constrói o que você pede e aplica hardening enquanto o código é escrito, guiado pelo charter |

:::tip[Use a qualquer momento]
O [**`/lagune`**](/docs/commands/lagune) respeita as regras do seu charter sempre que roda. Ele aceita qualquer prompt, constrói o que você pediu e o protege com padrões seguros ao longo do caminho, e não depois.
:::

#### Skills especiais

| Skill                                               | O que ela faz                                                                                    |
| --------------------------------------------------- | ------------------------------------------------------------------------------------------------ |
| [**/lagune-specialize**](/docs/commands/specialize) | Ensina ao **Lagune** uma nova especialização de segurança a partir de artigos, exploits ou temas |

  </TabItem>
  <TabItem value="audit" label="🔬 Auditoria: fluxo Blue Team">

O **fluxo Blue Team** completo: entender o que um projeto faz, mapear os riscos dele e eliminá-los. Cada skill se apoia na anterior, então basta seguir a lista de cima para baixo:

| #   | Skill                                         | O que ela faz por você                                                                             |
| --- | --------------------------------------------- | -------------------------------------------------------------------------------------------------- |
| 1   | [**/lagune-charter**](/docs/commands/charter) | Define as regras de segurança do seu projeto, propostas para você ou moldadas pelo que você disser |
| 2   | [**/lagune-detect**](/docs/commands/detect)   | Lê o seu código e mapeia o que o seu sistema faz e onde estão os riscos                            |
| 3   | [**/lagune-plan**](/docs/commands/plan)       | Transforma o que o detect encontrou em um plano de defesa, com uma correção para cada achado       |
| 4   | [**/lagune-harden**](/docs/commands/harden)   | Aplica ao seu código as correções do plano, com segurança e uma de cada vez                        |
| 5   | [**/lagune-verify**](/docs/commands/verify)   | Comprova que cada correção aplicada se sustenta e encerra as que passarem                          |
