Faça login no **Devin** e depois instale o plugin pelo terminal:

```bash
devin auth login
devin plugins install wellwelwel/lagune
```

## Atualização

Para atualizar o **Lagune**, execute:

```bash
devin plugins update lagune
```

## Comandos

Digite os comandos com o nome do plugin na frente, como `/lagune:lagune-charter` para `/lagune-charter`. O menu `/` também os lista.
