Instale o plugin pelo terminal:

```bash
hermes plugins install wellwelwel/lagune --enable
```

- Quando o **Hermes Agent** pedir para você confirmar um plugin de fora do catálogo dele, **confirme**.
- Quando ele oferecer instalar as dependências de **Node.js** do repositório, **recuse**.

## Atualização

Para atualizar o **Lagune**, execute:

```bash
hermes plugins update lagune
```

## Comandos

Digite os comandos com o nome do plugin na frente, como `/lagune:lagune-charter` para `/lagune-charter` e `/lagune:lagune` para `/lagune`.
