🔀 Перенесіть проєкт **Lagune** на основі маніфесту на **Lagune** на основі навичок, зберігши все, що ви написали.

:::danger[Повідомлення про застарілість]

Проєкт із маніфестом працюватиме як є до `v1.x`: `npx lagune` передає `init`, `pull`, `update`, `add`, `remove`, `list` і дашборд версії `lagune@0.15.0`, останній на основі маніфесту.

:::

## Перенесення

1. Переконайтеся, що поточну роботу закомічено, а потім виконайте migrate з кореня проєкту:

   ```bash
   npx lagune migrate
   ```

2. Закомітьте зміни, які вона внесла, окремим комітом, щоб перенесення залишилося однією зміною, яку легко переглянути.
3. Встановіть команди для свого агента, як показано на [сторінці встановлення](/docs).
4. Якщо в проєкті вже є артефакт detect, plan чи harden, попросіть [`/lagune-repair`](/docs/commands/repair) узгодити старі посилання в них і у ваших власних спеціалізаціях:

   ```prompt
   /lagune-repair Узгодь застосовані спеціалізації (раніше sub-skills) в артефактах у `.lagune/memory/` (`detect.md`, `plan.md` і `harden.md`) з назвами, які наводить новий каталог, і перепиши кожен виклик, який мої власні спеціалізації в `.lagune/catalog/` роблять до старих хуків у `.lagune/hooks/`, як виклик інструмента `lagune_read` або `lagune_write`.
   ```

## Що змінюється

| До                                                                    | Після                                                                             |
| --------------------------------------------------------------------- | --------------------------------------------------------------------------------- |
| `.lagune/templates/`, `.lagune/hooks/` і `.lagune/specializations.md` | Видалено: кожна навичка містить свій шаблон, а хуки виконує рушій                 |
| Копії вбудованих спеціалізацій у `.lagune/skills/`                    | Видалено: вбудовані спеціалізації надає рушій                                     |
| Ваші власні спеціалізації в `.lagune/skills/`                         | Переміщено в `.lagune/catalog/`                                                   |
| `.lagune/skills.json`, індекс ваших власних спеціалізацій             | Об'єднано з `.lagune/configs.json`                                                |
| Категорії маніфесту                                                   | Записано в `.lagune/configs.json`                                                 |
| Старі команди агента, як-от `/lagune.detect`                          | Видалено: [встановлення **Lagune**](/docs) приносить нові, як-от `/lagune-detect` |
| Блок **Lagune** у `.gitignore`                                        | Видалено разом із файлом, якщо в ньому більше нічого не було                      |
| `.lagune/proofs/`, який ігнорував цей блок                            | Не потрапляє в коміти завдяки власному `.gitignore`                               |
| `.lagune/manifest.json`                                               | Видалено останнім                                                                 |

Ваша робота з безпеки залишається як є: принципи безпеки, артефакт, створений кожною фазою, і карта відстеження зі шляхами, на які вказує кожна знахідка.
