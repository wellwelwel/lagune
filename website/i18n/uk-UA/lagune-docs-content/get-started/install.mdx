**Lagune** допомагає вашому ШІ-агенту зробити проєкт безпечнішим. Ви спрямовуєте його на свій код, агент з'ясовує, що насправді робить ваша система, а потім веде вас через роботу з безпеки, важливу саме для неї. **Lagune** є першим проєктом методології [Security-Driven Hardening (SDH)](/docs/references/paper).

:::tip[Підтримайте відкритий код]
Подобається **Lagune**? <ArrowLink to="https://github.com/wellwelwel/lagune">Поставте нам ⭐ на **GitHub**</ArrowLink>
:::

## Оберіть свій агент

<AgentPicker />

:::info

- Під капотом **Lagune** працює на **Node.js**, але ви використовуєте будь-яку мову, яку хочете.
- Щоб працювати повністю офлайн, встановіть **Lagune** у свій проєкт командою `npm i -D lagune@{{version}}`.

:::

## Категорії

Знання **Lagune** з безпеки надходять у вигляді [**спеціалізацій**](/docs/catalog), згрупованих у [**категорії**](/docs/categories).

<CategoryPicker />

:::tip
Проєкт починає з `owasp`, а [`/lagune-charter`](/docs/commands/charter) додає категорії, які підтверджує її аналіз проєкту.
:::

## Вимоги

У вашій системі має бути встановлено [**Node.js (LTS)**](https://nodejs.org/en/download/package-manager).
