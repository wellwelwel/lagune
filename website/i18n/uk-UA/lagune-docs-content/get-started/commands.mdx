Щойно **Lagune** [встановлено](/docs), ваш **ШІ**-агент отримує набір навичок. Користуватися ними можна двома способами, і обидва підпорядковані **принципам безпеки**: захищати нову роботу під час розробки або проводити повний аудит проєкту.

<Tabs queryString="mode">
  <TabItem value="build" label="⌨️ Створення / розробка" default>

Не треба завершувати роботу, перш ніж її захищати. Використовуйте [**`/lagune`**](/docs/commands/lagune) для роботи, яку пишете **просто зараз**:

| Навичка                                       | Що вона робить для вас                                                               |
| --------------------------------------------- | ------------------------------------------------------------------------------------ |
| [**/lagune-charter**](/docs/commands/charter) | Встановлює правила безпеки вашого проєкту, основу, на яку спирається `/lagune`       |
| [**/lagune**](/docs/commands/lagune)          | Створює те, що ви просите, і посилює захист під час написання, за принципами безпеки |

:::tip[Використовуйте будь-коли]
[**`/lagune`**](/docs/commands/lagune) дотримується правил із ваших принципів безпеки щоразу, коли запускається. Вона приймає будь-який промпт, створює те, що ви попросили, і посилює захист безпечними налаштуваннями за замовчуванням одразу, а не пізніше.
:::

#### Спеціальні навички

| Навичка                                             | Що вона робить                                                                       |
| --------------------------------------------------- | ------------------------------------------------------------------------------------ |
| [**/lagune-specialize**](/docs/commands/specialize) | Навчає **Lagune** нової спеціалізації з безпеки на основі статей, експлойтів або тем |

  </TabItem>
  <TabItem value="audit" label="🔬 Аудит: процес Blue Team">

Повний **процес Blue Team**: прочитати, що робить проєкт, визначити його ризики й закрити їх. Кожна фаза спирається на попередню, тож достатньо пройти список згори донизу:

| #   | Навичка                                       | Що вона робить для вас                                                                       |
| --- | --------------------------------------------- | -------------------------------------------------------------------------------------------- |
| 1   | [**/lagune-charter**](/docs/commands/charter) | Встановлює правила безпеки вашого проєкту, запропоновані для вас або сформовані з ваших слів |
| 2   | [**/lagune-detect**](/docs/commands/detect)   | Читає ваш код і визначає, що робить ваша система і де ризики                                 |
| 3   | [**/lagune-plan**](/docs/commands/plan)       | Перетворює те, що знайшла фаза detect, на план захисту з виправленням для кожної знахідки    |
| 4   | [**/lagune-harden**](/docs/commands/harden)   | Застосовує виправлення з плану до вашого коду, безпечно й по одному                          |
| 5   | [**/lagune-verify**](/docs/commands/verify)   | Доводить, що кожне застосоване виправлення діє, і закриває ті, що пройшли перевірку          |
