Запустіть **Lagune** напряму, без підкоманди, щоб отримати інтерактивний огляд `.lagune/` наживо. Він запускає дашборд і відкриває його на випадковому порту:

```bash
npx lagune
```

- [x] **Live Reload**
- [x] **Приватно** й **локально**
- [x] Показує все, що містить `.lagune/`, починаючи з перших принципів безпеки
- [x] **Керуйте** категоріями проєкту і тим, що перевіряють його хуки, просто з браузера
- [x] Не потрібні ні `node_modules`, ні `package.json` 📦
