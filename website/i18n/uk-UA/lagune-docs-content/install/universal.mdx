<InstallHeader name='skills.sh' />

Встановіть команди **Lagune** у свій проєкт із термінала через [**skills.sh**](https://www.skills.sh/wellwelwel/lagune), залишивши **Project** як область встановлення:

```bash
npx skills add wellwelwel/lagune --skill '*'
```

Або вставте цей промпт у свій агент:

```md
Виконай `npx --yes skills add wellwelwel/lagune` і одразу дотримуйся згенерованих інструкцій навички. Прочитай увесь вивід команди, за потреби спершу перенаправивши його в тимчасовий файл. Розв'язуй відносні шляхи від каталогу допоміжних файлів, який вона надає.
```

  </TabItem>
  <TabItem value="github-cli" label="GitHub CLI">

<InstallHeader name='GitHub CLI' />

Встановіть команди **Lagune** у свій проєкт із термінала через [**GitHub CLI**](https://cli.github.com/) версії 2.90.0 або новішої:

```bash
gh skill install wellwelwel/lagune --all --scope project
```

Або вставте цей промпт у свій агент:

```md
Виконай `gh skill install wellwelwel/lagune --all --scope project` і прочитай увесь вивід, за потреби спершу перенаправивши його в тимчасовий файл.
```

  </TabItem>
</Tabs>

## Оновлення

<Tabs groupId="skills-installer">
  <TabItem value="skills-sh" label="skills.sh" default>

Щоб оновити **Lagune**, виконайте:

```bash
npx skills update
```

Або вставте цей промпт у свій агент:

```md
Виконай `npx --yes skills update -y` і прочитай увесь вивід, за потреби спершу перенаправивши його в тимчасовий файл.
```

  </TabItem>
  <TabItem value="github-cli" label="GitHub CLI">

Щоб оновити **Lagune**, виконайте:

```bash
gh skill update --all
```

Або вставте цей промпт у свій агент:

```md
Виконай `gh skill update --all` і прочитай увесь вивід, за потреби спершу перенаправивши його в тимчасовий файл.
```

  </TabItem>
</Tabs>

---

:::info[Дозволи]

Команди запускають рушій як `npx --yes lagune@{{version}}`, а [сторінка встановлення кожного агента](/docs) показує правило, що дозволяє його заздалегідь. У пісочниці без доступу до мережі встановіть рушій у свій проєкт із власного термінала, один раз і після кожного оновлення:

```bash
npm i -D lagune@{{version}}
```

:::
