**Devin**에 로그인한 다음 터미널에서 플러그인을 설치하세요:

```bash
devin auth login
devin plugins install wellwelwel/lagune
```

## 업데이트

**Lagune**을 업데이트하려면 다음 명령어를 실행하세요:

```bash
devin plugins update lagune
```

## 명령어

명령어는 플러그인 이름을 붙여 입력하세요. 예를 들어 `/lagune:lagune-charter` 명령어를 입력하면 `/lagune-charter` 명령어가 실행됩니다. `/` 메뉴에서도 명령어 목록을 볼 수 있습니다.
