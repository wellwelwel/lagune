**Kimi Code** 세션에서 플러그인을 설치하고 **Trust and install**을 선택한 다음, 새 세션을 시작해 플러그인을 불러오세요:

```text
/plugins install https://github.com/wellwelwel/lagune
/new
```

## 업데이트

**Lagune**을 업데이트하려면 다시 설치하세요:

```text
/plugins install https://github.com/wellwelwel/lagune
/new
```

## 명령어

명령어는 플러그인 이름을 붙여 입력하세요. 예를 들어 `/lagune:lagune-charter` 명령어를 입력하면 `/lagune-charter` 명령어가 실행됩니다. `/` 메뉴에는 명령어가 `/skill:lagune:lagune-charter` 형식으로 표시되며, 이 형식으로 입력해도 실행됩니다.
