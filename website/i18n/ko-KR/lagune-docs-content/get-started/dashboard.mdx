하위 명령어 없이 **Lagune**을 바로 실행하면 `.lagune/` 폴더를 인터랙티브한 실시간 뷰로 볼 수 있습니다. 임의의 포트에서 대시보드를 띄우고 엽니다:

```bash
npx lagune
```

- [x] **실시간 새로고침**
- [x] **비공개**이며 **로컬**에서 동작
- [x] 첫 보안 원칙부터 `.lagune/` 폴더에 담긴 모든 내용 표시
- [x] 브라우저에서 프로젝트의 카테고리와 훅의 스캔 대상을 직접 **관리**
- [x] `node_modules` 폴더도 `package.json` 파일도 필요 없음 📦
