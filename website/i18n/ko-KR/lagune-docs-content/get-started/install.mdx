**Lagune**은 AI 에이전트가 프로젝트를 더 안전하게 만들도록 돕습니다. 코드를 대상으로 실행하면 에이전트가 시스템이 실제로 하는 일을 파악하고, 그 시스템에 중요한 보안 작업을 차근차근 안내합니다. **Lagune**은 [Security-Driven Hardening (SDH)](/docs/references/paper) 방법론의 첫 번째 프로젝트입니다.

:::tip[오픈 소스 응원하기]
**Lagune**이 마음에 드시나요? <ArrowLink to="https://github.com/wellwelwel/lagune">**GitHub**에서 ⭐ 하나 눌러 주세요</ArrowLink>
:::

## 에이전트 선택하기

<AgentPicker />

:::info

- **Lagune**은 내부적으로 **Node.js**에서 실행되지만, 개발 언어는 무엇이든 자유롭게 쓸 수 있습니다.
- 완전히 오프라인으로 실행하려면 `npm i -D lagune@{{version}}` 명령어로 프로젝트에 **Lagune**을 설치하세요.

:::

## 카테고리

**Lagune**의 보안 지식은 [**카테고리**](/docs/categories)별로 묶인 [**전문 지식**](/docs/catalog) 형태로 제공됩니다.

<CategoryPicker />

:::tip
프로젝트는 `owasp` 카테고리로 시작하며, [`/lagune-charter`](/docs/commands/charter) 명령어가 프로젝트를 읽고 근거가 확인된 카테고리를 추가합니다.
:::

## 요구 사항

시스템에 [**Node.js (LTS)**](https://nodejs.org/en/download/package-manager)가 설치되어 있어야 합니다.
