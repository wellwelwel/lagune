Melde dich bei **Devin** an und installiere dann das Plugin über dein Terminal:

```bash
devin auth login
devin plugins install wellwelwel/lagune
```

## Aktualisierung

Um **Lagune** zu aktualisieren, führe Folgendes aus:

```bash
devin plugins update lagune
```

## Befehle

Gib die Befehle mit vorangestelltem Plugin-Namen ein, etwa `/lagune:lagune-charter` für `/lagune-charter`. Auch das Menü `/` listet sie auf.
