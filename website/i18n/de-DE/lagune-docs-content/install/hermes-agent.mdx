Installiere das Plugin über dein Terminal:

```bash
hermes plugins install wellwelwel/lagune --enable
```

- Wenn **Hermes Agent** dich bittet, ein Plugin von außerhalb seines Katalogs zu bestätigen, **bestätige es**.
- Wenn er anbietet, die Abhängigkeiten des Repositorys für **Node.js** zu installieren, **lehne ab**.

## Aktualisierung

Um **Lagune** zu aktualisieren, führe Folgendes aus:

```bash
hermes plugins update lagune
```

## Befehle

Gib die Befehle mit vorangestelltem Plugin-Namen ein, etwa `/lagune:lagune-charter` für `/lagune-charter` und `/lagune:lagune` für `/lagune`.
