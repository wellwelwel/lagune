Sobald **Lagune** [installiert](/docs) ist, schaltet dein **KI**-Agent eine Reihe von Skills frei. Es gibt zwei Wege, sie zu nutzen, und beide folgen deinen **Sicherheitsprinzipien**: neue Arbeit schon beim Entwickeln absichern oder das vollständige Audit über ein Projekt laufen lassen.

<Tabs queryString="mode">
  <TabItem value="build" label="⌨️ Bauen / Entwickeln" default>

Du musst deine Arbeit nicht erst fertigstellen, bevor du sie absicherst. Nutze [**`/lagune`**](/docs/commands/lagune) für die Arbeit, die du **gerade jetzt** schreibst:

| Skill                                         | Was er für dich tut                                                                                   |
| --------------------------------------------- | ----------------------------------------------------------------------------------------------------- |
| [**/lagune-charter**](/docs/commands/charter) | Legt die Sicherheitsregeln deines Projekts fest, die Grundlage, auf der `/lagune` aufbaut             |
| [**/lagune**](/docs/commands/lagune)          | Baut, worum du bittest, und härtet es schon beim Schreiben, geleitet von deinen Sicherheitsprinzipien |

:::tip[Nutze ihn jederzeit]
[**`/lagune`**](/docs/commands/lagune) befolgt die Regeln deiner Sicherheitsprinzipien bei jeder Ausführung. Er nimmt jeden Prompt an, baut, worum du gebeten hast, und härtet es dabei mit sicheren Standardwerten, nicht erst später.
:::

---

#### Spezielle Skills

| Skill                                               | Was er tut                                                                                           |
| --------------------------------------------------- | ---------------------------------------------------------------------------------------------------- |
| [**/lagune-specialize**](/docs/commands/specialize) | Bringt **Lagune** anhand von Artikeln, Exploits oder Themen eine neue Sicherheitsspezialisierung bei |

  </TabItem>
  <TabItem value="audit" label="🔬 Auditieren: Blue-Team-Workflow">

Der vollständige **Blue-Team-Workflow**: lesen, was ein Projekt tut, seine Risiken erfassen und schließen. Jede Phase baut auf der vorherigen auf, du musst der Liste also nur von oben nach unten folgen:

| #   | Skill                                         | Was er für dich tut                                                                                       |
| --- | --------------------------------------------- | --------------------------------------------------------------------------------------------------------- |
| 1   | [**/lagune-charter**](/docs/commands/charter) | Legt die Sicherheitsregeln deines Projekts fest, für dich vorgeschlagen oder nach deinen Vorgaben geformt |
| 2   | [**/lagune-detect**](/docs/commands/detect)   | Liest deinen Code und erfasst, was dein System tut und wo die Risiken liegen                              |
| 3   | [**/lagune-plan**](/docs/commands/plan)       | Macht aus dem, was detect gefunden hat, einen Abwehrplan mit einer Korrektur für jeden Befund             |
| 4   | [**/lagune-harden**](/docs/commands/harden)   | Setzt die Korrekturen des Plans in deinem Code um, sicher und eine nach der anderen                       |
| 5   | [**/lagune-verify**](/docs/commands/verify)   | Weist nach, dass jede umgesetzte Korrektur greift, und schließt die ab, die den Nachweis bestehen         |

---

#### Spezielle Skills

| Skill                                               | Was er tut                                                                                                             |
| --------------------------------------------------- | ---------------------------------------------------------------------------------------------------------------------- |
| [**/lagune-specialize**](/docs/commands/specialize) | Bringt **Lagune** anhand von Artikeln, Exploits oder Themen eine neue Sicherheitsspezialisierung bei                   |
| [**/lagune-prove**](/docs/commands/prove)           | Macht aus jedem erkannten Befund einen ausführbaren, ausschließlich defensiven Nachweis für die Responsible Disclosure |
