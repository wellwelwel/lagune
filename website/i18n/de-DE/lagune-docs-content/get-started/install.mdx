**Lagune** hilft deinem KI-Agenten, ein Projekt sicherer zu machen. Du setzt es auf deinen Code an, und der Agent findet heraus, was dein System tatsächlich tut, und führt dich dann durch die Sicherheitsarbeit, die dafür zählt. **Lagune** ist das erste Projekt der Methodik [Security-Driven Hardening (SDH)](/docs/references/paper).

:::tip[Open Source unterstützen]
Gefällt dir **Lagune**? <ArrowLink to="https://github.com/wellwelwel/lagune">Gib uns einen ⭐ auf **GitHub**</ArrowLink>
:::

## Wähle deinen Agenten

<AgentPicker />

:::info

- **Lagune** läuft unter der Haube mit **Node.js**, aber du arbeitest in der Sprache deiner Wahl.
- Um **Lagune** komplett offline auszuführen, installiere es mit `npm i -D lagune@{{version}}` in deinem Projekt.

:::

## Kategorien

Das Sicherheitswissen von **Lagune** steckt in [**Spezialisierungen**](/docs/catalog), gruppiert in [**Kategorien**](/docs/categories).

<CategoryPicker />

:::tip
Ein Projekt beginnt mit `owasp`, und [`/lagune-charter`](/docs/commands/charter) fügt die Kategorien hinzu, für die seine Lesart des Projekts spricht.
:::

## Voraussetzungen

Auf deinem System muss [**Node.js (LTS)**](https://nodejs.org/en/download/package-manager) installiert sein.
