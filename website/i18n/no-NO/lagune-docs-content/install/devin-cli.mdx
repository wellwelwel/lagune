Logg inn på **Devin**, og installer deretter pluginen fra terminalen:

```bash
devin auth login
devin plugins install wellwelwel/lagune
```

## Oppdatering

Oppdater **Lagune** ved å kjøre:

```bash
devin plugins update lagune
```

## Kommandoer

Skriv kommandoene med navnet på pluginen foran, for eksempel `/lagune:lagune-charter` for `/lagune-charter`. Menyen `/` viser dem også.
