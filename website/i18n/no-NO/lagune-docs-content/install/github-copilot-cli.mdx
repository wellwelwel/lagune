Installer pluginen fra terminalen:

```bash
copilot plugin marketplace add wellwelwel/lagune
copilot plugin install lagune@lagune
```

I en editor installerer du **Lagune** for **GitHub Copilot** med [**skills.sh**](/docs/install/universal).

## Oppdatering

Kjør følgende for å oppdatere **Lagune**:

```bash
copilot plugin marketplace update lagune
copilot plugin update lagune@lagune
```

## Kommandoer

Skriv inn kommandoene med navn, for eksempel `/lagune-charter`.
