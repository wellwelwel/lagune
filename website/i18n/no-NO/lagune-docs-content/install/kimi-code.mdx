Installer pluginen fra en økt i **Kimi Code**, velg **Trust and install**, og start deretter en ny økt for å laste den inn:

```text
/plugins install https://github.com/wellwelwel/lagune
/new
```

## Oppdatering

Installer **Lagune** på nytt for å oppdatere det:

```text
/plugins install https://github.com/wellwelwel/lagune
/new
```

## Kommandoer

Skriv inn kommandoene med navnet på pluginen foran, for eksempel `/lagune:lagune-charter` for `/lagune-charter`. Menyen `/` viser dem som `/skill:lagune:lagune-charter`, og det fungerer også.
