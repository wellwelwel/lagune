Masuk ke **Devin**, lalu instal plugin dari terminal Anda:

```bash
devin auth login
devin plugins install wellwelwel/lagune
```

## Pembaruan

Untuk memperbarui **Lagune**, jalankan:

```bash
devin plugins update lagune
```

## Perintah

Ketik perintah dengan nama plugin di depannya, misalnya `/lagune:lagune-charter` untuk `/lagune-charter`. Menu `/` juga menampilkan daftarnya.
