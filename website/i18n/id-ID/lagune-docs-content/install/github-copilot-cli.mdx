Instal plugin dari terminal Anda:

```bash
copilot plugin marketplace add wellwelwel/lagune
copilot plugin install lagune@lagune
```

Di editor, instal **Lagune** untuk **GitHub Copilot** dengan [**skills.sh**](/docs/install/universal).

## Pembaruan

Untuk memperbarui **Lagune**, jalankan:

```bash
copilot plugin marketplace update lagune
copilot plugin update lagune@lagune
```

## Perintah

Ketik perintah dengan namanya, misalnya `/lagune-charter`.
