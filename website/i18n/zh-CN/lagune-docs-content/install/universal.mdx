<Tabs groupId="skills-route">
  <TabItem value="terminal" label="终端" default>

在终端中用 [**skills.sh**](https://www.skills.sh/wellwelwel/lagune) 安装 **Lagune** 的命令：

```bash
npx skills add wellwelwel/lagune
```

  </TabItem>
  <TabItem value="prompt" label="提示词">

把这段提示词粘贴到你的智能体中：

```md
运行 `npx --yes skills add wellwelwel/lagune`，然后立即按照生成的 skill 指令操作。完整阅读它的输出，必要时先把输出重定向到临时文件。相对路径以它提供的支持文件目录为基准解析。
```

  </TabItem>
</Tabs>

## 更新

<Tabs groupId="skills-route">
  <TabItem value="terminal" label="终端" default>

运行以下命令更新 **Lagune**：

```bash
npx skills update
```

  </TabItem>
  <TabItem value="prompt" label="提示词">

把这段提示词粘贴到你的智能体中来更新 **Lagune**：

```md
运行 `npx --yes skills update -y`，并完整阅读它的输出，必要时先把输出重定向到临时文件。
```

  </TabItem>
</Tabs>

---

:::warning[每个智能体只用一种安装方式]
安装 **Lagune** 时，要么用 **skills.sh**，要么用它的**插件**，不要两者同时使用。
:::

:::info[权限]

这些命令以 `npx --yes lagune@{{version}}` 的形式运行引擎，每个 [智能体的安装页面](/docs) 都列出了预先允许它的规则。如果沙箱无法访问网络，就在你自己的终端中把引擎安装到项目里，先装一次，之后每次更新后再装一次：

```bash
npm i -D lagune@{{version}}
```

:::
