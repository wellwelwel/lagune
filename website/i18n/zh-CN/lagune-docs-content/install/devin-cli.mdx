先登录 **Devin**，然后在终端中安装插件：

```bash
devin auth login
devin plugins install wellwelwel/lagune
```

## 更新

运行以下命令更新 **Lagune**：

```bash
devin plugins update lagune
```

## 命令

输入命令时加上插件的名称作为前缀，例如用 `/lagune:lagune-charter` 运行 `/lagune-charter`。`/` 菜单中也会列出这些命令。
