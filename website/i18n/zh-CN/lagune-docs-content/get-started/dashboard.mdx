不带子命令直接运行 **Lagune**，就能获得 `.lagune/` 的交互式实时视图。它会在一个随机端口上启动仪表盘并打开它：

```bash
npx lagune
```

- [x] **实时刷新**
- [x] **私密**且**本地**
- [x] 从首次运行 charter 起，展示 `.lagune/` 中的全部内容
- [x] 直接在浏览器中**管理**项目的类别，以及它的 hook 扫描哪些内容
- [x] 无需 `node_modules` 或 `package.json` 📦
