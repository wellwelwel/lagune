[安装](/docs) **Lagune** 之后，你的 **AI** 智能体就会解锁一组 Skills。它们有两种用法，都遵循**安全原则**：一边构建一边保障新代码的安全，或者对整个项目运行完整审计。

<Tabs queryString="mode">
  <TabItem value="build" label="⌨️ 构建 / 开发" default>

你不必等工作做完才去保障安全。你**此刻**在写的内容，就交给 [**`/lagune`**](/docs/commands/lagune)：

| Skill                                         | 它能为你做什么                                        |
| --------------------------------------------- | ----------------------------------------------------- |
| [**/lagune-charter**](/docs/commands/charter) | 设定项目的安全规则，也就是 `/lagune` 构建时依据的基础 |
| [**/lagune**](/docs/commands/lagune)          | 按你的要求构建，并在安全原则的指引下边写边加固        |

:::tip[随时可用]
[**`/lagune`**](/docs/commands/lagune) 每次运行都会遵守你的安全原则。它接受任何提示词，按你的要求构建，并在构建过程中就用安全的默认设置加固，而不是事后再补。
:::

| Skill                                               | 作用                                                           |
| --------------------------------------------------- | -------------------------------------------------------------- |
| [**/lagune-specialize**](/docs/commands/specialize) | 根据文章、漏洞利用代码或主题，教会 **Lagune** 一个新的安全专项 |

  </TabItem>
  <TabItem value="audit" label="🔬 审计：Blue Team 流程">

完整的 **Blue Team 流程**：读懂项目在做什么，梳理它的风险，再逐一消除。每一步都建立在上一步的基础上，所以照着列表从上往下做就够了：

| #   | Skill                                         | 它能为你做什么                                             |
| --- | --------------------------------------------- | ---------------------------------------------------------- |
| 1   | [**/lagune-charter**](/docs/commands/charter) | 设定项目的安全规则，可以由它为你提议，也可以按你的想法来定 |
| 2   | [**/lagune-detect**](/docs/commands/detect)   | 读取你的代码，梳理系统在做什么、风险在哪里                 |
| 3   | [**/lagune-plan**](/docs/commands/plan)       | 把 detect 的发现转化为防御计划，为每个发现项配上修复       |
| 4   | [**/lagune-harden**](/docs/commands/harden)   | 把计划中的修复安全地、逐项应用到你的代码中                 |
| 5   | [**/lagune-verify**](/docs/commands/verify)   | 证明每项已应用的修复确实有效，并将有效的发现项结案         |

#### 特殊 Skills

| Skill                                               | 作用                                                             |

| Skill                                       | 作用                       |
| ------------------------------------------- | -------------------------- |
| [**/lagune-repair**](/docs/commands/repair) | 修复 **Lagune** 的内部追踪 |
