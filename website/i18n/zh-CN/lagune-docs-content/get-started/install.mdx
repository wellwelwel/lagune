**Lagune** 帮助你的 AI 智能体提升项目的安全性。你把它指向自己的代码，智能体就会弄清楚你的系统实际在做什么，再带你完成对它而言真正重要的安全工作。**Lagune** 是 [Security-Driven Hardening (SDH)](/docs/references/paper) 方法论的第一个项目。

:::tip[支持开源]
喜欢 **Lagune**？<ArrowLink to="https://github.com/wellwelwel/lagune">到 **GitHub** 给我们点个 ⭐</ArrowLink>
:::

## 选择你的智能体

<AgentPicker />

:::info

- **Lagune** 底层基于 **Node.js** 运行，但你用什么语言都可以。
- 如需完全离线运行，用 `npm i -D lagune@{{version}}` 把 **Lagune** 安装到你的项目中。

:::

## 类别

**Lagune** 的安全知识以 [**专项**](/docs/catalog) 的形式提供，并按 [**类别**](/docs/categories) 分组。

<CategoryPicker />

:::tip
项目起初只启用 `owasp`，随后 [`/lagune-charter`](/docs/commands/charter) 会根据它对项目的解读，添加有依据的类别。
:::

## 环境要求

你需要在系统中安装 [**Node.js (LTS)**](https://nodejs.org/en/download/package-manager)。
