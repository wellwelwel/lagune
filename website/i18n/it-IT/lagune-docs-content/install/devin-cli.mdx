Accedi a **Devin**, poi installa il plugin dal terminale:

```bash
devin auth login
devin plugins install wellwelwel/lagune
```

## Aggiornamento

Per aggiornare **Lagune**, esegui:

```bash
devin plugins update lagune
```

## Comandi

Digita i comandi con il nome del plugin, come `/lagune:lagune-charter` per `/lagune-charter`. Li elenca anche il menu `/`.
