Installa il plugin dal terminale:

```bash
hermes plugins install wellwelwel/lagune --enable
```

- Quando **Hermes Agent** ti chiede di confermare un plugin esterno al suo catalogo, **confermalo**.
- Quando propone di installare le dipendenze **Node.js** del repository, **rifiuta**.

## Aggiornamento

Per aggiornare **Lagune**, esegui:

```bash
hermes plugins update lagune
```

## Comandi

Digita i comandi con il nome del plugin, come `/lagune:lagune-charter` per `/lagune-charter` e `/lagune:lagune` per `/lagune`.
