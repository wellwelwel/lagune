شغّل **Lagune** مباشرة دون أمر فرعي للحصول على عرض تفاعلي مباشر للمجلد `.lagune/`. يقدّم لوحة تحكم ويفتحها على منفذ عشوائي:

```bash
npx lagune
```

- [x] **إعادة تحميل مباشرة**
- [x] **خاصة** و **محلية**
- [x] تعرض كل ما يحتويه `.lagune/`، بدءًا من أول ميثاق أمان
- [x] **أدِر** فئات المشروع وما تفحصه hooks الخاصة به، مباشرة من متصفحك
- [x] لا حاجة إلى `node_modules` أو `package.json` 📦
