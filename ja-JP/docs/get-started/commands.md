# AI エージェントのためのセキュリティスキル

> Lagune で AI エージェントが使えるようになるスキル：既存のプロジェクトを監査することも、開発しながら新しいコードを安全にすることもでき、どちらもセキュリティ原則に従います。

正規 URL: https://lagune.ai/ja-JP/docs/get-started/commands
言語: ja-JP
原文: https://lagune.ai/docs/get-started/commands
最終更新日: 2026-11-03

**Lagune** を [インストール](https://lagune.ai/ja-JP/docs) すると、**AI** エージェントで一連のスキルが使えるようになります。使い方は 2 通りあり、どちらも**セキュリティ原則**に従います：開発しながら新しいコードを安全にするか、プロジェクト全体を監査するかです。

**⌨️ 構築 / 開発**

作業を終えてからセキュリティ対策をする必要はありません。**いま**書いているコードには [**`/lagune`**](https://lagune.ai/ja-JP/docs/commands/lagune) を使いましょう：

| スキル                                        | できること                                                           |
| --------------------------------------------- | -------------------------------------------------------------------- |
| [**/lagune-charter**](https://lagune.ai/ja-JP/docs/commands/charter) | プロジェクトのセキュリティルールを定め、`/lagune` が構築の土台にする |
| [**/lagune**](https://lagune.ai/ja-JP/docs/commands/lagune)          | 依頼されたものを構築し、セキュリティ原則に沿って書きながら堅牢化する |

**いつでも使える**

[**`/lagune`**](https://lagune.ai/ja-JP/docs/commands/lagune) は、実行するたびにセキュリティ原則で定めたルールを守ります。どんなプロンプトでも受け付け、依頼されたものを構築し、後からではなく作業を進めながら、安全なデフォルト設定で堅牢化します。

#### 特別なスキル

| スキル                                              | 役割                                                                                   |
| --------------------------------------------------- | -------------------------------------------------------------------------------------- |
| [**/lagune-specialize**](https://lagune.ai/ja-JP/docs/commands/specialize) | 記事、エクスプロイト、トピックから、新しいセキュリティの専門知識を **Lagune** に教える |

**🔬 監査：Blue Team フロー**

**Blue Team フロー**の全体像です：プロジェクトが何をしているかを読み取り、リスクを洗い出して解消します。各ステップは前のステップを土台にしているので、一覧を上から順に実行するだけで済みます：

| #   | スキル                                        | できること                                                             |
| --- | --------------------------------------------- | ---------------------------------------------------------------------- |
| 1   | [**/lagune-charter**](https://lagune.ai/ja-JP/docs/commands/charter) | プロジェクトのセキュリティルールを、提案に任せるか要望に沿って定める   |
| 2   | [**/lagune-detect**](https://lagune.ai/ja-JP/docs/commands/detect)   | コードを読み、システムが何をしているか、リスクがどこにあるかを洗い出す |
| 3   | [**/lagune-plan**](https://lagune.ai/ja-JP/docs/commands/plan)       | detect が見つけたものを防御計画にまとめ、検出事項ごとに修正を用意する  |
| 4   | [**/lagune-harden**](https://lagune.ai/ja-JP/docs/commands/harden)   | 計画の修正を、安全に 1 つずつコードへ適用する                          |
| 5   | [**/lagune-verify**](https://lagune.ai/ja-JP/docs/commands/verify)   | 適用した各修正が実際に有効かを証明し、有効だった検出事項をクローズする |

## よくある質問

### Lagune にはどんなスキルがありますか？

開発しながら作業を堅牢化する /lagune と、5 フェーズの Blue Team 監査フロー（/lagune-charter、/lagune-detect、/lagune-plan、/lagune-harden、/lagune-verify）です。さらに /lagune-specialize と /lagune-prove もあります。

### Lagune の Blue Team フローとは何ですか？

5 つのフェーズからなる監査です：charter（ルールを定める）、detect（リスクを洗い出す）、plan（評価して修正を計画する）、harden（修正を適用する）、verify（修正が有効かを証明してクローズする）。

### /lagune と監査フローの違いは何ですか？

/lagune は、決まったフローに従うことなく、新しいコードを書きながら安全にします。監査フローは、既存のプロジェクトに対して 5 つのフェーズを順番に実行します。
