# /lagune-specialize: プレーンテキストでセキュリティの専門知識を学習させる

> 渡したセキュリティの資料やトピックを、必要なときに読み込まれる新しい専門知識にまとめます。

正規 URL: https://lagune.ai/ja-JP/docs/commands/specialize
言語: ja-JP
原文: https://lagune.ai/docs/commands/specialize
最終更新日: 2026-11-04

🎓 渡した資料やトピックから、**Lagune** に新しい専門知識を教えます。

資料を読み込み、[組み込みの専門知識](https://lagune.ai/ja-JP/docs/catalog) とまったく同じ形式の、対象を絞った防御専用の専門知識にまとめます。そのため、以後は detect フェーズと verify フェーズが、ほかの専門知識と同じようにこれを読み込みます。行うのは監査と説明だけで、攻撃用の入力やエクスプロイトを書くことも、コードに手を加えることもありません。

**記事から**

```prompt
# リンクや参考資料：Lagune がそこから防御策をまとめます
/lagune-specialize https://owasp.org/www-community/attacks/SQL_Injection
```

**エクスプロイトから**

```prompt
# 攻撃を資料にする場合：それでも専門知識は防御のためのものです
/lagune-specialize "' OR 1=1 -- がクエリ文字列に SQL を差し込む"
```

**トピックから**

```prompt
# または、扱う内容を挙げるだけでも構いません
/lagune-specialize SQL インジェクション
```

**攻撃は資料にできても、出力にはならない**

防御が目的であれば、攻撃を題材にしても問題ありません。エクスプロイトの解説記事は、防御策にまとめるための学習材料になります。生成される専門知識は常に監査と説明を行うもので、実際に動くエクスプロイトやペイロード、検知回避の手段を生み出すことはありません。

## 書き出すもの

結果はプロジェクト内の 2 つのファイルで、コードと一緒にコミットしてレビューできます：

- 専門知識そのもの。`.lagune/catalog/<name>.md` に、[組み込みの専門知識](https://lagune.ai/ja-JP/docs/catalog) と同じ形式で書き出されます。
- `.lagune/configs.json` 内のエントリ。プロジェクトはここに独自の専門知識を登録し、カタログはそれを組み込みの専門知識と統合します。

その後、カタログを一覧表示して、新しいエントリが含まれていることを確認します。独自の専門知識は、カテゴリにかかわらず常にカタログに含まれます。コマンドを追加したり、パッケージに手を加えたりする必要はありません。新しい専門知識は、自分のプロジェクトに書き込まれる知識ファイル 1 つとインデックスのエントリ 1 つだけです。

## 上書きせず、磨き上げる

すでにある名前で専門知識を作ると、`regex` のような組み込みのものでも、以前に自分で作ったものでも、現在のファイルを置き換えずに**照合して更新**します。既存の内容を読み、新しい知識を取り込み、今も有効な部分は残し、変わった部分は書き直します。確認されないまま破棄される内容はありません。自分の専門知識は同じ名前の組み込みの専門知識より優先されるため、組み込みの専門知識を失うことなく、自分のプロジェクト向けに磨き上げられます。

**ヒント**

- 新しい専門知識は、組み込みのものとまったく同じように読み込まれます。detect フェーズと verify フェーズが必要に応じて読み込むほか、`npx lagune read catalog <name>` で自分で読み込み、タスクを与えることもできます。
- 資料の出どころ（記事、著者、リンク、標準規格）が特定できる場合は、専門知識にその出典を明記します。トピックだけを渡した場合、出典は付きません。

**注記**

**呼び出したときにだけ実行されます**：エージェントが自分から開始することはありません。

## よくある質問

### セキュリティの専門知識を独自に追加するにはどうすればいいですか？

資料やトピックを付けて /lagune-specialize を実行します。防御専用の専門知識にまとめて .lagune/catalog/<name>.md に書き出し、.lagune/configs.json にエントリを追加します。

### Lagune はエクスプロイトの解説記事から学習できますか？

はい。ただし資料としてであり、出力としてではありません。攻撃は資料にはなっても、生み出されるものにはなりません。specialize が攻撃用の入力やエクスプロイトを書くことはありません。

### specialize は組み込みの専門知識を上書きしますか？

いいえ。上書きはせず、内容を磨き上げます。
