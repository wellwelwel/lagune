# /lagune: AI が書くそばからコードを安全に

> 依頼したものを構築し、セキュリティ原則に沿って書きながら堅牢化します。決まったフローに従う必要はありません。

正規 URL: https://lagune.ai/ja-JP/docs/commands/lagune
言語: ja-JP
原文: https://lagune.ai/docs/commands/lagune
最終更新日: 2026-11-04

⌨️ 依頼した作業を、書くそばから安全な形で仕上げます。**`/lagune`** はどの段階でもどんなプロンプトでも受け付け、求められたものを構築し、引き渡す前に安全なデフォルト設定で堅牢化します。

## 使い方

どんなプロンプトにも **`/lagune`** を付けて、いつもどおりに作業内容を説明します。

**📘 エージェント向けの指示**

```md
# エージェント向けのプロジェクト指示

<!-- ... -->

## セキュリティ

- コードを作成または変更するときは、必ず `/lagune` スキルを使い、デフォルトで安全性が高まるようにしてください。
```

    - 例：**AGENTS.md**、**CLAUDE.md**、**.github/copilot-instructions.md**、**.cursorrules** など。

**💬 新機能**

```prompt
/lagune ユーザーがプロフィールに自分の写真をアップロードできるようにしてください。
```

**💬 修正**

```prompt
/lagune ユーザーがフォームを送信しても何も起きません。原因を調べて修正してください。
```

**💬 リファクタリング**

```prompt
/lagune ペイロード処理のロジックを疎結合にして改善してください
```

**セキュリティ原則は任意だが、あるとより効果的**

**`/lagune`** はセキュリティ原則があってもなくても動作します。セキュリティ原則があれば、プロジェクト独自のルールがすべての構築に反映されます。[`/lagune-charter`](https://lagune.ai/ja-JP/docs/commands/charter) で一度定めておけば十分です。

## 仕組み

Lagune には何も書き込まずに、次の 3 つのステップで作業を進めます：

1. セキュリティ原則があれば読み込んで構築全体をその原則に従わせ、まだない場合はデフォルトで安全なベースラインを代わりに使います。
2. プロジェクトの [カタログ](https://lagune.ai/ja-JP/docs/catalog) の一覧を取得し、作業に関わる専門知識だけを、監査フローと同じようにオンデマンドで読み込みます。
3. コードを書きながら防御を施し、作業を引き渡す前に自分の成果を読み直して、対策が実際に有効かを確認します。

その結果、プロジェクトには最初の 1 行から安全な、動作するコードが残ります。

**いつでも使える**

detect も plan も、後片付けも不要です。**`/lagune`** は作ったばかりのひな形にも、成熟したコードベースへの変更にも同じように使え、後からではなく作業を進めながら堅牢化します。

## しないこと

- `.lagune` ディレクトリには成果物も追跡情報も一切書き込まないため、生み出すのは依頼した堅牢化済みのコードだけです。
- プロンプトに応えるためにルールを緩めることはないため、依頼内容がセキュリティ原則に反する場合は、そのまま安全でない形で構築せず、まず手を止めて知らせます。

## よくある質問

### /lagune は何をしますか？

どの段階でもどんなプロンプトでも受け付け、依頼されたものを構築し、引き渡す前に安全なデフォルト設定で堅牢化します。防御は後からではなく、コードを書きながら施します。

### /lagune を使うにはセキュリティ原則が必要ですか？

いいえ。セキュリティ原則があってもなくても動作します。セキュリティ原則があれば、プロジェクト独自のルールがすべての構築に反映されます。なければ、デフォルトで安全なベースラインを使います。

### /lagune と Blue Team フローの違いは何ですか？

/lagune は、決まったフローに従うことなく、新しいコードを書きながら安全にします。Blue Team フローは、既存のプロジェクトに対して 5 つの監査フェーズを順番に実行します。

### /lagune は検出事項を追跡したり、成果物を書き込んだりしますか？

いいえ。.lagune ディレクトリには成果物も追跡情報も一切書き込みません。生み出すのは、依頼した堅牢化済みのコードだけです。

### エージェントに /lagune を自動で使わせるにはどうすればよいですか？

エージェントの指示ファイル（AGENTS.md、CLAUDE.md、.cursorrules など）に、コードを作成または変更するときは必ず /lagune スキルを使うよう指示を追加します。
