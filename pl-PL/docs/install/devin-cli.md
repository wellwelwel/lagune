# Instalacja wtyczki Lagune w Devin CLI

> Zainstaluj wtyczkę Lagune w Devin CLI i aktualizuj ją.

Adres kanoniczny: https://lagune.ai/pl-PL/docs/install/devin-cli
Język: pl-PL
Oryginał: https://lagune.ai/docs/install/devin-cli
Ostatnia aktualizacja: 2026-11-09

Zaloguj się na konto **Devin**, a następnie zainstaluj wtyczkę z terminala:

```bash
devin auth login
devin plugins install wellwelwel/lagune
```

## Aktualizacja

Aby zaktualizować wtyczkę **Lagune**, uruchom:

```bash
devin plugins update lagune
```

## Polecenia

Wpisuj polecenia poprzedzone nazwą wtyczki, na przykład `/lagune:lagune-charter` zamiast `/lagune-charter`. Wyświetla je też menu `/`.
