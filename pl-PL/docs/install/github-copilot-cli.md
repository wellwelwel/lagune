# Instalacja wtyczki Lagune w GitHub Copilot CLI

> Zainstaluj wtyczkę Lagune w GitHub Copilot CLI i aktualizuj ją.

Adres kanoniczny: https://lagune.ai/pl-PL/docs/install/github-copilot-cli
Język: pl-PL
Oryginał: https://lagune.ai/docs/install/github-copilot-cli
Ostatnia aktualizacja: 2026-11-09

Zainstaluj wtyczkę z terminala:

```bash
copilot plugin marketplace add wellwelwel/lagune
copilot plugin install lagune@lagune
```

W edytorze zainstaluj polecenia **Lagune** dla **GitHub Copilot** za pomocą [**skills.sh**](https://lagune.ai/pl-PL/docs/install/universal).

## Aktualizacja

Aby zaktualizować wtyczkę **Lagune**, uruchom:

```bash
copilot plugin marketplace update lagune
copilot plugin update lagune@lagune
```

## Polecenia

Wpisuj nazwy poleceń, na przykład `/lagune-charter`.

## Najczęściej zadawane pytania

### Jak zainstalować wtyczkę Lagune w GitHub Copilot CLI?

Uruchom copilot plugin marketplace add wellwelwel/lagune, a następnie copilot plugin install lagune@lagune.

### Jak zaktualizować wtyczkę Lagune w GitHub Copilot CLI?

Uruchom copilot plugin marketplace update lagune, a następnie copilot plugin update lagune@lagune.

### Jak uruchamiać polecenia Lagune w GitHub Copilot CLI?

Wpisuj ich nazwy, na przykład /lagune-charter.

### Czy Lagune działa z GitHub Copilot w VS Code?

Tak. W VS Code lub innym edytorze zainstaluj polecenia Lagune za pomocą skills.sh zamiast wtyczki.
