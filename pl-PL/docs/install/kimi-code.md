# Instalacja wtyczki Lagune w Kimi Code

> Zainstaluj wtyczkę Lagune w Kimi Code i aktualizuj ją.

Adres kanoniczny: https://lagune.ai/pl-PL/docs/install/kimi-code
Język: pl-PL
Oryginał: https://lagune.ai/docs/install/kimi-code
Ostatnia aktualizacja: 2026-11-09

Zainstaluj wtyczkę w sesji **Kimi Code**, wybierz **Trust and install**, a następnie rozpocznij nową sesję, aby wczytać wtyczkę:

```text
/plugins install https://github.com/wellwelwel/lagune
/new
```

## Aktualizacja

Aby zaktualizować wtyczkę **Lagune**, zainstaluj ją ponownie:

```text
/plugins install https://github.com/wellwelwel/lagune
/new
```

## Polecenia

Wpisuj polecenia poprzedzone nazwą wtyczki, na przykład `/lagune:lagune-charter` zamiast `/lagune-charter`. Menu `/` pokazuje je jako `/skill:lagune:lagune-charter` i ta forma również działa.

## Najczęściej zadawane pytania

### Jak zainstalować wtyczkę Lagune w Kimi Code?

W sesji Kimi Code uruchom /plugins install https://github.com/wellwelwel/lagune, wybierz Trust and install, a następnie uruchom /new.

### Jak zaktualizować wtyczkę Lagune w Kimi Code?

Ponownie uruchom /plugins install https://github.com/wellwelwel/lagune, a następnie /new.

### Jak uruchamiać polecenia Lagune w Kimi Code?

Wpisuj je poprzedzone nazwą wtyczki, na przykład /lagune:lagune-charter, albo tak, jak pokazuje je menu /, na przykład /skill:lagune:lagune-charter.
