# Installa Lagune su Kimi Code come plugin

> Installa Lagune su Kimi Code come plugin e tienilo aggiornato.

Canonico: https://lagune.ai/it-IT/docs/install/kimi-code
Lingua: it-IT
Originale: https://lagune.ai/docs/install/kimi-code
Ultimo aggiornamento: 2026-11-05

Installa il plugin da una sessione di **Kimi Code**, scegli **Trust and install**, poi avvia una nuova sessione per caricarlo:

```text
/plugins install https://github.com/wellwelwel/lagune
/new
```

## Aggiornamento

Per aggiornare **Lagune**, installalo di nuovo:

```text
/plugins install https://github.com/wellwelwel/lagune
/new
```

## Comandi

Digita i comandi con il nome del plugin, come `/lagune:lagune-charter` per `/lagune-charter`. Il menu `/` li elenca come `/skill:lagune:lagune-charter`, e funziona anche così.

## Domande frequenti

### Come installo Lagune su Kimi Code?

In una sessione di Kimi Code, esegui /plugins install https://github.com/wellwelwel/lagune, scegli Trust and install, poi esegui /new.

### Come aggiorno Lagune su Kimi Code?

Esegui di nuovo /plugins install https://github.com/wellwelwel/lagune, poi /new.

### Come eseguo i comandi di Lagune su Kimi Code?

Digitali con il nome del plugin, come /lagune:lagune-charter, oppure come li elenca il menu /, come /skill:lagune:lagune-charter.
