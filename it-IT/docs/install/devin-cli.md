# Installa Lagune su Devin CLI come plugin

> Installa Lagune su Devin CLI come plugin e tienilo aggiornato.

Canonico: https://lagune.ai/it-IT/docs/install/devin-cli
Lingua: it-IT
Originale: https://lagune.ai/docs/install/devin-cli
Ultimo aggiornamento: 2026-11-05

Accedi a **Devin**, poi installa il plugin dal terminale:

```bash
devin auth login
devin plugins install wellwelwel/lagune
```

## Aggiornamento

Per aggiornare **Lagune**, esegui:

```bash
devin plugins update lagune
```

## Comandi

Digita i comandi con il nome del plugin, come `/lagune:lagune-charter` per `/lagune-charter`. Li elenca anche il menu `/`.
