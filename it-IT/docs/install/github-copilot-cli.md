# Installa Lagune su GitHub Copilot CLI come plugin

> Installa Lagune su GitHub Copilot CLI come plugin e tienilo aggiornato.

Canonico: https://lagune.ai/it-IT/docs/install/github-copilot-cli
Lingua: it-IT
Originale: https://lagune.ai/docs/install/github-copilot-cli
Ultimo aggiornamento: 2026-11-04

Installa il plugin dal terminale:

```bash
copilot plugin marketplace add wellwelwel/lagune
copilot plugin install lagune@lagune
```

In un editor, installa **Lagune** per **GitHub Copilot** con [**skills.sh**](https://lagune.ai/it-IT/docs/install/universal).

## Aggiornamento

Per aggiornare **Lagune**, esegui:

```bash
copilot plugin marketplace update lagune
copilot plugin update lagune@lagune
```

## Comandi

Digita i comandi per nome, come `/lagune-charter`.

## Domande frequenti

### Come installo Lagune su GitHub Copilot CLI?

Esegui copilot plugin marketplace add wellwelwel/lagune, poi copilot plugin install lagune@lagune.

### Come aggiorno Lagune su GitHub Copilot CLI?

Esegui copilot plugin marketplace update lagune, poi copilot plugin update lagune@lagune.

### Come eseguo i comandi di Lagune su GitHub Copilot CLI?

Digitali per nome, come /lagune-charter.

### Posso usare Lagune con GitHub Copilot in VS Code?

Sì. In VS Code o in un altro editor, installa Lagune con skills.sh invece che con il plugin.
