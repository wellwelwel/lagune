# Installa Lagune su Hermes Agent come plugin

> Installa Lagune su Hermes Agent come plugin e tienilo aggiornato.

Canonico: https://lagune.ai/it-IT/docs/install/hermes-agent
Lingua: it-IT
Originale: https://lagune.ai/docs/install/hermes-agent
Ultimo aggiornamento: 2026-11-03

Installa il plugin dal terminale:

```bash
hermes plugins install wellwelwel/lagune --enable
```

- Quando **Hermes Agent** ti chiede di confermare un plugin esterno al suo catalogo, **confermalo**.
- Quando propone di installare le dipendenze **Node.js** del repository, **rifiuta**.

## Aggiornamento

Per aggiornare **Lagune**, esegui:

```bash
hermes plugins update lagune
```

## Comandi

Digita i comandi con il nome del plugin, come `/lagune:lagune-charter` per `/lagune-charter` e `/lagune:lagune` per `/lagune`.

## Domande frequenti

### Come installo Lagune su Hermes Agent?

Esegui hermes plugins install wellwelwel/lagune --enable. Conferma il plugin quando richiesto e rifiuta l'installazione delle dipendenze Node.js del repository.

### Come aggiorno Lagune su Hermes Agent?

Esegui hermes plugins update lagune.

### Come eseguo i comandi di Lagune su Hermes Agent?

Digitali con il nome del plugin, come /lagune:lagune-charter e /lagune:lagune.
