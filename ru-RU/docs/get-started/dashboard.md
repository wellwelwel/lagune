Запустите **Lagune** напрямую, без подкоманды, чтобы получить интерактивное представление `.lagune/` в реальном времени. Команда поднимает дашборд и открывает его на случайном порту:

```bash
npx lagune
```

- [x] **Управляйте** категориями проекта прямо из браузера
- [x] Не нужны ни `node_modules`, ни `package.json` 📦

## Частые вопросы

### Как открыть дашборд Lagune?

Выполните npx lagune без подкоманды в корне проекта. Команда поднимает представление .lagune/ в реальном времени на случайном порту и открывает его в браузере.

### Дашборд приватный?

Да. Он работает только на вашем компьютере, по локальному адресу, недоступному ни для какого другого компьютера.

### Можно ли менять проект из дашборда?

Только его категории, из браузера. Все остальное в дашборде доступно только для чтения.
