# Схема конфигурации

> JSON Schema для конфигурации проекта Lagune, дающая автодополнение и проверку в редакторе, следуя текущей версии Lagune или с закреплением конкретной версии.

Канонический URL: https://lagune.ai/ru-RU/docs/references/configs-schema
Язык: ru-RU
Оригинал: https://lagune.ai/docs/references/configs-schema
Последнее обновление: 2026-11-05

`.lagune/configs.json` фиксирует [**категории**](https://lagune.ai/ru-RU/docs/categories), которые использует проект, индексирует его собственные [**специализации**](https://lagune.ai/ru-RU/docs/catalog) и задает, что пропускают [**проверки**](https://lagune.ai/ru-RU/docs/hooks/configure). Его JSON Schema позволяет редактору автодополнять каждое поле и помечать опечатку или неизвестную категорию прямо во время правки файла.

## Текущая схема

Каждый раз, когда **Lagune** записывает файл и не находит в нем `$schema`, он указывает в файле текущую схему:

```json
{
  "$schema": "https://lagune.ai/schemas/configs.json",
  "categories": ["owasp", "javascript"]
}
```

Этот адрес всегда следует за текущей версией **Lagune**. Файл, записанный до **Lagune** 0.16.0, получит его при следующем изменении, а до тех пор каждая фаза будет об этом напоминать.

## Закрепление версии

Каждый релиз **Lagune** начиная с 0.16.0 несет схему в том виде, в каком она была в этой версии, опубликованную в **npm** и раздаваемую через **jsDelivr**. Чтобы закрепить версию, укажите нужную версию после `lagune@` в адресе `$schema`:

```json
{
  "$schema": "https://cdn.jsdelivr.net/npm/lagune@0.16.0/schemas/configs.json"
}
```

Версия принимает любой диапазон semver:

| Версия              | Схема                           |
| ------------------- | ------------------------------- |
| `0.16.0`            | Схема из 0.16.0                 |
| `0.16.x` или `0.16` | Схема из последнего релиза 0.16 |
| `0.x` или `0`       | Схема из последнего релиза 0.x  |
| `latest`            | Схема из последнего релиза      |

## Частые вопросы

### Нужна ли Lagune схема?

Нет. Схема помогает только редактору, а Lagune читает файл одинаково с $schema и без него.

### Перезапишет ли Lagune закрепленную схему?

Нет. Lagune записывает $schema, только если в файле его нет, и сохраняет любой адрес, который вы задали.

### Когда стоит закреплять версию?

Когда проект работает с конкретной версией Lagune, чтобы редактор проверял файл по тому, что принимает эта версия.
