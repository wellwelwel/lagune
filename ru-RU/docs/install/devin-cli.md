# Установка Lagune в Devin CLI как плагина

> Установите Lagune в Devin CLI как плагин и поддерживайте его в актуальном состоянии.

Канонический URL: https://lagune.ai/ru-RU/docs/install/devin-cli
Язык: ru-RU
Оригинал: https://lagune.ai/docs/install/devin-cli
Последнее обновление: 2026-11-04

Войдите в **Devin**, затем установите плагин из терминала:

```bash
devin auth login
devin plugins install wellwelwel/lagune
```

## Обновление

Чтобы обновить **Lagune**, выполните:

```bash
devin plugins update lagune
```

## Команды

Вводите команды с именем плагина, например `/lagune:lagune-charter` для `/lagune-charter`. Меню `/` тоже их показывает.
