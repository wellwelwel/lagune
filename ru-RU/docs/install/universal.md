# Установка Lagune в любой агент через skills.sh

> Установите Lagune в любой ИИ-агент через CLI skills и поддерживайте его в актуальном состоянии.

Канонический URL: https://lagune.ai/ru-RU/docs/install/universal
Язык: ru-RU
Оригинал: https://lagune.ai/docs/install/universal
Последнее обновление: 2026-11-04

**Терминал**

Установите команды **Lagune** из терминала через [**skills.sh**](https://www.skills.sh/wellwelwel/lagune):

```bash
npx skills add wellwelwel/lagune
```

**Промпт**

Вставьте этот промпт в своего агента:

```md
Выполни `npx --yes skills add wellwelwel/lagune` и сразу следуй сгенерированным инструкциям навыка. Прочитай весь вывод, при необходимости сначала перенаправив его во временный файл. Разрешай относительные пути от директории со вспомогательными файлами, которую он указывает.
```

## Обновление

**Терминал**

Чтобы обновить **Lagune**, выполните:

```bash
npx skills update
```

**Промпт**

Чтобы обновить **Lagune**, вставьте этот промпт в своего агента:

```md
Выполни `npx --yes skills update -y` и прочитай весь вывод, при необходимости сначала перенаправив его во временный файл.
```

---

**Один способ на агента**

Устанавливайте **Lagune** либо через **skills.sh**, либо через его **плагин**, но никогда обоими способами.

**Разрешения**

Команды запускают движок как `npx --yes lagune@0.17.0`, а на [странице установки каждого агента](https://lagune.ai/ru-RU/docs) показано правило, которое разрешает его заранее. В песочнице без доступа к сети установите движок в проект из своего терминала, один раз и после каждого обновления:

```bash
npm i -D lagune@0.17.0
```

## Частые вопросы

### Как установить Lagune в любой ИИ-агент?

Выполните npx skills add wellwelwel/lagune в своем проекте или вставьте промпт установки в своего агента.

### Как обновить Lagune, установленный через CLI skills?

Выполните npx skills update или вставьте промпт обновления в своего агента.

### Можно ли установить Lagune и через CLI skills, и как плагин?

Нет. При обоих способах агент показывает каждую команду дважды или использует одну копию и скрывает другую.
