# Установка Lagune в любой агент через skills.sh или GitHub CLI

> Установите Lagune в любой ИИ-агент через CLI skills или GitHub CLI и поддерживайте его в актуальном состоянии.

Канонический URL: https://lagune.ai/ru-RU/docs/install/universal
Язык: ru-RU
Оригинал: https://lagune.ai/docs/install/universal
Последнее обновление: 2026-11-07

**skills.sh**

Установите команды **Lagune** в свой проект из терминала через [**skills.sh**](https://www.skills.sh/wellwelwel/lagune), оставив **Project** в качестве области установки:

```bash
npx skills add wellwelwel/lagune --skill '*'
```

Или вставьте этот промпт в своего агента:

```md
Выполни `npx --yes skills add wellwelwel/lagune` и сразу следуй сгенерированным инструкциям навыка. Прочитай весь вывод, при необходимости сначала перенаправив его во временный файл. Разрешай относительные пути от директории со вспомогательными файлами, которую он указывает.
```

**GitHub CLI**

Установите команды **Lagune** в свой проект из терминала через [**GitHub CLI**](https://cli.github.com/) версии 2.90.0 или новее:

```bash
gh skill install wellwelwel/lagune --all --scope project
```

Или вставьте этот промпт в своего агента:

```md
Выполни `gh skill install wellwelwel/lagune --all --scope project` и прочитай весь вывод, при необходимости сначала перенаправив его во временный файл.
```

## Обновление

**skills.sh**

Чтобы обновить **Lagune**, выполните:

```bash
npx skills update
```

Или вставьте этот промпт в своего агента:

```md
Выполни `npx --yes skills update -y` и прочитай весь вывод, при необходимости сначала перенаправив его во временный файл.
```

**GitHub CLI**

Чтобы обновить **Lagune**, выполните:

```bash
gh skill update --all
```

Или вставьте этот промпт в своего агента:

```md
Выполни `gh skill update --all` и прочитай весь вывод, при необходимости сначала перенаправив его во временный файл.
```

---

**Песочница**

В песочнице без доступа к сети команды не могут скачать движок. Установите его в проект из своего терминала, один раз и после каждого обновления:

```bash
npm i -D lagune@0.18.0
```

## Частые вопросы

### Как установить Lagune в любой ИИ-агент?

Выполните в своем проекте npx skills add wellwelwel/lagune --skill '*' или gh skill install wellwelwel/lagune --all --scope project либо вставьте промпт установки в своего агента.

### Как обновить Lagune в любом ИИ-агенте?

Если вы установили Lagune через skills.sh, выполните npx skills update, а если через GitHub CLI, выполните gh skill update --all. Также можно вставить промпт обновления в своего агента.

### Можно ли установить Lagune сразу несколькими способами?

Нет. При двух способах агент показывает каждую команду дважды или использует одну копию и скрывает другую.
