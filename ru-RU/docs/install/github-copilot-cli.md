# Установка Lagune в GitHub Copilot CLI как плагина

> Установите Lagune в GitHub Copilot CLI как плагин и поддерживайте его в актуальном состоянии.

Канонический URL: https://lagune.ai/ru-RU/docs/install/github-copilot-cli
Язык: ru-RU
Оригинал: https://lagune.ai/docs/install/github-copilot-cli
Последнее обновление: 2026-11-03

Установите плагин из терминала:

```bash
copilot plugin marketplace add wellwelwel/lagune
copilot plugin install lagune@lagune
```

В редакторе устанавливайте **Lagune** для **GitHub Copilot** через [**skills.sh**](https://lagune.ai/ru-RU/docs/install/universal).

## Обновление

Чтобы обновить **Lagune**, выполните:

```bash
copilot plugin marketplace update lagune
copilot plugin update lagune@lagune
```

## Команды

Вводите команды по имени, например `/lagune-charter`.

## Частые вопросы

### Как установить Lagune в GitHub Copilot CLI?

Выполните copilot plugin marketplace add wellwelwel/lagune, затем copilot plugin install lagune@lagune.

### Как обновить Lagune в GitHub Copilot CLI?

Выполните copilot plugin marketplace update lagune, затем copilot plugin update lagune@lagune.

### Как запускать команды Lagune в GitHub Copilot CLI?

Вводите их по имени, например /lagune-charter.

### Можно ли использовать Lagune с GitHub Copilot в VS Code?

Да. В VS Code или другом редакторе устанавливайте Lagune через skills.sh, а не как плагин.
