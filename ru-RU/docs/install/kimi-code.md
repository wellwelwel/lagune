# Установка Lagune в Kimi Code как плагина

> Установите Lagune в Kimi Code как плагин и поддерживайте его в актуальном состоянии.

Канонический URL: https://lagune.ai/ru-RU/docs/install/kimi-code
Язык: ru-RU
Оригинал: https://lagune.ai/docs/install/kimi-code
Последнее обновление: 2026-11-05

Установите плагин из сессии **Kimi Code**, выберите **Trust and install**, а затем начните новую сессию, чтобы он загрузился:

```text
/plugins install https://github.com/wellwelwel/lagune
/new
```

## Обновление

Чтобы обновить **Lagune**, установите его снова:

```text
/plugins install https://github.com/wellwelwel/lagune
/new
```

## Команды

Вводите команды с именем плагина, например `/lagune:lagune-charter` для `/lagune-charter`. Меню `/` показывает их как `/skill:lagune:lagune-charter`, и такая форма тоже работает.

## Частые вопросы

### Как установить Lagune в Kimi Code?

В сессии Kimi Code выполните /plugins install https://github.com/wellwelwel/lagune, выберите Trust and install, а затем выполните /new.

### Как обновить Lagune в Kimi Code?

Снова выполните /plugins install https://github.com/wellwelwel/lagune, а затем /new.

### Как запускать команды Lagune в Kimi Code?

Вводите их с именем плагина, например /lagune:lagune-charter, или так, как их показывает меню /, например /skill:lagune:lagune-charter.
