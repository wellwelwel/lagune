# Cara menginstal Lagune di Devin CLI sebagai plugin

> Instal Lagune di Devin CLI sebagai plugin, dan jaga agar tetap terbaru.

Kanonis: https://lagune.ai/id-ID/docs/install/devin-cli
Bahasa: id-ID
Asli: https://lagune.ai/docs/install/devin-cli
Terakhir diperbarui: 2026-11-06

Masuk ke **Devin**, lalu instal plugin dari terminal Anda:

```bash
devin auth login
devin plugins install wellwelwel/lagune
```

## Pembaruan

Untuk memperbarui **Lagune**, jalankan:

```bash
devin plugins update lagune
```

## Perintah

Ketik perintah dengan nama plugin di depannya, misalnya `/lagune:lagune-charter` untuk `/lagune-charter`. Menu `/` juga menampilkan daftarnya.
