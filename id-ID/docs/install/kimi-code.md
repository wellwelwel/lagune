# Cara menginstal Lagune di Kimi Code sebagai plugin

> Instal Lagune di Kimi Code sebagai plugin, dan jaga agar tetap terbaru.

Kanonis: https://lagune.ai/id-ID/docs/install/kimi-code
Bahasa: id-ID
Asli: https://lagune.ai/docs/install/kimi-code
Terakhir diperbarui: 2026-11-06

Instal plugin dari sesi **Kimi Code**, pilih **Trust and install**, lalu mulai sesi baru untuk memuatnya:

```text
/plugins install https://github.com/wellwelwel/lagune
/new
```

## Pembaruan

Untuk memperbarui **Lagune**, instal ulang:

```text
/plugins install https://github.com/wellwelwel/lagune
/new
```

## Perintah

Ketik perintah dengan nama plugin di depannya, misalnya `/lagune:lagune-charter` untuk `/lagune-charter`. Menu `/` menampilkannya sebagai `/skill:lagune:lagune-charter`, yang juga bisa dipakai.

## Pertanyaan yang sering diajukan

### Bagaimana cara menginstal Lagune di Kimi Code?

Di sesi Kimi Code, jalankan /plugins install https://github.com/wellwelwel/lagune, pilih Trust and install, lalu jalankan /new.

### Bagaimana cara memperbarui Lagune di Kimi Code?

Jalankan lagi /plugins install https://github.com/wellwelwel/lagune, lalu /new.

### Bagaimana cara menjalankan perintah Lagune di Kimi Code?

Ketik perintah dengan nama plugin di depannya, misalnya /lagune:lagune-charter, atau seperti yang ditampilkan menu /, misalnya /skill:lagune:lagune-charter.
