# Cara menginstal Lagune di GitHub Copilot CLI sebagai plugin

> Instal Lagune di GitHub Copilot CLI sebagai plugin, dan jaga agar tetap terbaru.

Kanonis: https://lagune.ai/id-ID/docs/install/github-copilot-cli
Bahasa: id-ID
Asli: https://lagune.ai/docs/install/github-copilot-cli
Terakhir diperbarui: 2026-11-06

Instal plugin dari terminal Anda:

```bash
copilot plugin marketplace add wellwelwel/lagune
copilot plugin install lagune@lagune
```

Di editor, instal **Lagune** untuk **GitHub Copilot** dengan [**skills.sh**](https://lagune.ai/id-ID/docs/install/universal).

## Pembaruan

Untuk memperbarui **Lagune**, jalankan:

```bash
copilot plugin marketplace update lagune
copilot plugin update lagune@lagune
```

## Perintah

Ketik perintah dengan namanya, misalnya `/lagune-charter`.
