# วิธีติดตั้ง Lagune บน Kimi Code แบบปลั๊กอิน

> ติดตั้ง Lagune บน Kimi Code แบบปลั๊กอิน และอัปเดตให้เป็นเวอร์ชันล่าสุดเสมอ

Canonical: https://lagune.ai/th-TH/docs/install/kimi-code
ภาษา: th-TH
ต้นฉบับ: https://lagune.ai/docs/install/kimi-code
อัปเดตล่าสุด: 2026-11-07

ติดตั้งปลั๊กอินจากเซสชัน **Kimi Code** เลือก **Trust and install** แล้วเริ่มเซสชันใหม่เพื่อโหลดปลั๊กอิน:

```text
/plugins install https://github.com/wellwelwel/lagune
/new
```

## การอัปเดต

หากต้องการอัปเดต **Lagune** ให้ติดตั้งใหม่อีกครั้ง:

```text
/plugins install https://github.com/wellwelwel/lagune
/new
```

## คำสั่ง

พิมพ์คำสั่งโดยมีชื่อปลั๊กอินนำหน้า เช่น `/lagune:lagune-charter` แทน `/lagune-charter` ส่วนเมนู `/` แสดงคำสั่งเป็น `/skill:lagune:lagune-charter` ซึ่งใช้ได้เช่นกัน

## คำถามที่พบบ่อย

### ติดตั้ง Lagune บน Kimi Code ได้อย่างไร

ในเซสชัน Kimi Code ให้รัน /plugins install https://github.com/wellwelwel/lagune เลือก Trust and install แล้วรัน /new

### อัปเดต Lagune บน Kimi Code ได้อย่างไร

รัน /plugins install https://github.com/wellwelwel/lagune อีกครั้ง แล้วรัน /new

### รันคำสั่งของ Lagune บน Kimi Code ได้อย่างไร

พิมพ์คำสั่งโดยมีชื่อปลั๊กอินนำหน้า เช่น /lagune:lagune-charter หรือพิมพ์ตามที่เมนู / แสดง เช่น /skill:lagune:lagune-charter
