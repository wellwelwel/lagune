รัน **Lagune** โดยตรงโดยไม่ระบุคำสั่งย่อย เพื่อเปิดมุมมองแบบเรียลไทม์ที่โต้ตอบได้ของ `.lagune/` **Lagune** จะรันแดชบอร์ดบนพอร์ตแบบสุ่มแล้วเปิดให้คุณ:

```bash
npx lagune
```

- [x] **Live Reload**
- [x] **เป็นส่วนตัว** และ **ทำงานบนเครื่อง**
- [x] แสดงทุกอย่างที่อยู่ใน `.lagune/` ตั้งแต่ charter แรกเป็นต้นไป
- [x] **จัดการ** หมวดหมู่ของโปรเจกต์และสิ่งที่ hook จะสแกน ผ่านเบราว์เซอร์ได้โดยตรง
- [x] ไม่ต้องมี `node_modules` หรือ `package.json` 📦

## คำถามที่พบบ่อย

### เปิดแดชบอร์ดของ Lagune อย่างไร

รัน npx lagune โดยไม่ระบุคำสั่งย่อยที่รากของโปรเจกต์ คำสั่งนี้จะรันมุมมองแบบเรียลไทม์ของ .lagune/ บนพอร์ตแบบสุ่ม แล้วเปิดในเบราว์เซอร์ของคุณ

### แดชบอร์ดเป็นส่วนตัวไหม

ใช่ แดชบอร์ดทำงานบนเครื่องของคุณเท่านั้น โดยใช้ที่อยู่ภายในเครื่องที่คอมพิวเตอร์เครื่องอื่นเข้าถึงไม่ได้

### แก้ไขโปรเจกต์จากแดชบอร์ดได้ไหม

ได้เฉพาะหมวดหมู่ของโปรเจกต์และสิ่งที่ hook ละเว้น ผ่านเบราว์เซอร์ของคุณ ส่วนข้อมูลอื่นทั้งหมดที่แดชบอร์ดแสดงเป็นแบบอ่านอย่างเดียว
