# Skill ด้านความปลอดภัยสำหรับเอเจนต์ AI

> Skill ที่เอเจนต์ AI ของคุณได้รับจาก Lagune: ตรวจสอบโปรเจกต์ที่มีอยู่แล้ว หรือทำให้งานใหม่ปลอดภัยไปพร้อมกับที่สร้าง ทั้งหมดอยู่ภายใต้ charter

Canonical: https://lagune.ai/th-TH/docs/get-started/commands
ภาษา: th-TH
ต้นฉบับ: https://lagune.ai/docs/get-started/commands
อัปเดตล่าสุด: 2026-11-07

เมื่อ [ติดตั้ง](https://lagune.ai/th-TH/docs) **Lagune** แล้ว เอเจนต์ **AI** ของคุณจะได้รับชุด skill ที่ใช้ได้ 2 แบบ และทั้งสองแบบอยู่ภายใต้ **charter**: ทำให้งานใหม่ปลอดภัยไปพร้อมกับที่สร้าง หรือรันการตรวจสอบเต็มรูปแบบกับโปรเจกต์

**⌨️ สร้างและพัฒนา**

คุณไม่จำเป็นต้องทำงานให้เสร็จก่อนจึงจะทำให้ปลอดภัย ใช้ [**`/lagune`**](https://lagune.ai/th-TH/docs/commands/lagune) กับงานที่คุณกำลังเขียน**อยู่ตอนนี้**:

| Skill                                         | สิ่งที่ทำให้คุณ                                                             |
| --------------------------------------------- | --------------------------------------------------------------------------- |
| [**/lagune-charter**](https://lagune.ai/th-TH/docs/commands/charter) | กำหนดกฎความปลอดภัยของโปรเจกต์ ซึ่งเป็นรากฐานที่ `/lagune` ยึดในการสร้าง     |
| [**/lagune**](https://lagune.ai/th-TH/docs/commands/lagune)          | สร้างสิ่งที่คุณขอและเสริมความปลอดภัยไปพร้อมกับที่เขียน ตามแนวทางของ charter |

**ใช้ได้ทุกเมื่อ**

[**`/lagune`**](https://lagune.ai/th-TH/docs/commands/lagune) ทำตามกฎใน charter ของคุณทุกครั้งที่รัน โดยรับ prompt ใดก็ได้ สร้างสิ่งที่คุณขอ และเสริมความปลอดภัยด้วยค่าเริ่มต้นที่ปลอดภัยไประหว่างทาง ไม่ใช่ทีหลัง

## คำถามที่พบบ่อย

### Lagune เพิ่ม skill อะไรบ้าง

คำสั่ง /lagune สำหรับเสริมความปลอดภัยให้งานไปพร้อมกับที่สร้าง และขั้นตอนการตรวจสอบแบบ Blue Team ทั้ง 5 เฟส: /lagune-charter, /lagune-detect, /lagune-plan, /lagune-harden, /lagune-verify รวมถึง /lagune-specialize และ /lagune-prove

### ขั้นตอนแบบ Blue Team ของ Lagune คืออะไร

การตรวจสอบ 5 เฟส: charter (กำหนดกฎ) detect (ทำแผนผังความเสี่ยง) plan (ให้คะแนนและวางแผนการแก้ไข) harden (นำการแก้ไขไปใช้) และ verify (พิสูจน์ว่าการแก้ไขใช้ได้จริงแล้วปิดให้จบ)

### /lagune ต่างจากขั้นตอนการตรวจสอบอย่างไร

คำสั่ง /lagune ทำให้งานใหม่ปลอดภัยไปพร้อมกับที่คุณเขียน โดยไม่ต้องทำตามขั้นตอนใด ส่วนขั้นตอนการตรวจสอบรันทั้ง 5 เฟสตามลำดับกับโปรเจกต์ที่มีอยู่แล้ว
