# สคีมาของ configs

> JSON Schema สำหรับ configs ของโปรเจกต์ Lagune ให้ editor เติมคำอัตโนมัติและตรวจความถูกต้องของไฟล์ได้ โดยอ้างอิง Lagune เวอร์ชันล่าสุดหรือตรึงไว้ที่เวอร์ชันใดเวอร์ชันหนึ่ง

Canonical: https://lagune.ai/th-TH/docs/references/configs-schema
ภาษา: th-TH
ต้นฉบับ: https://lagune.ai/docs/references/configs-schema
อัปเดตล่าสุด: 2026-11-07

ไฟล์ `.lagune/configs.json` บันทึก [**หมวดหมู่**](https://lagune.ai/th-TH/docs/categories) ที่โปรเจกต์ใช้ ทำดัชนี [**ความรู้เฉพาะทาง**](https://lagune.ai/th-TH/docs/catalog) ของโปรเจกต์เอง และกำหนดสิ่งที่ [**ตัวตรวจ**](https://lagune.ai/th-TH/docs/hooks/configure) จะข้ามไป JSON Schema ของไฟล์นี้ช่วยให้ editor ของคุณเติมแต่ละฟิลด์อัตโนมัติ และทำเครื่องหมายคำที่พิมพ์ผิดหรือหมวดหมู่ที่ไม่รู้จักขณะที่คุณแก้ไขไฟล์

## สคีมาล่าสุด

ทุกครั้งที่ **Lagune** เขียนไฟล์นี้แล้วไม่พบ `$schema` ในไฟล์ **Lagune** จะชี้ไฟล์ไปที่สคีมาล่าสุด:

```json
{
  "$schema": "https://lagune.ai/schemas/configs.json",
  "categories": ["owasp", "javascript"]
}
```

ที่อยู่นี้อ้างอิง **Lagune** เวอร์ชันล่าสุดเสมอ ไฟล์ที่เขียนก่อน **Lagune** 0.16.0 จะได้ที่อยู่นี้เมื่อไฟล์เปลี่ยนครั้งถัดไป และทุกเฟสจะแจ้งเรื่องนี้จนกว่าจะถึงตอนนั้น

## ตรึงเวอร์ชัน

ทุกรีลีสของ **Lagune** ตั้งแต่ 0.16.0 เป็นต้นไปมีสคีมาตามที่เป็นในเวอร์ชันนั้น เผยแพร่บน **npm** และให้บริการผ่าน **jsDelivr** หากต้องการตรึงเวอร์ชัน ให้ใส่เวอร์ชันต่อจาก `lagune@` ในที่อยู่ `$schema`:

```json
{
  "$schema": "https://cdn.jsdelivr.net/npm/lagune@0.16.0/schemas/configs.json"
}
```

เวอร์ชันรองรับช่วง semver ทุกรูปแบบ:

| เวอร์ชัน             | สคีมา                     |
| -------------------- | ------------------------- |
| `0.16.0`             | สคีมาจาก 0.16.0           |
| `0.16.x` หรือ `0.16` | สคีมาจากรีลีส 0.16 ล่าสุด |
| `0.x` หรือ `0`       | สคีมาจากรีลีส 0.x ล่าสุด  |
| `latest`             | สคีมาจากรีลีสล่าสุด       |

## คำถามที่พบบ่อย

### Lagune จำเป็นต้องใช้สคีมาไหม

ไม่จำเป็น สคีมาช่วยแค่ editor ของคุณ และ Lagune อ่านไฟล์แบบเดียวกันไม่ว่าจะมี $schema หรือไม่

### Lagune จะเขียนทับสคีมาที่ตรึงเวอร์ชันไว้ไหม

ไม่ Lagune เขียน $schema เฉพาะเมื่อไฟล์ยังไม่มี และคงที่อยู่ใดก็ตามที่คุณตั้งไว้

### ควรตรึงเวอร์ชันเมื่อไร

เมื่อโปรเจกต์รัน Lagune เวอร์ชันที่เจาะจง เพื่อให้ editor ตรวจไฟล์ตามสิ่งที่เวอร์ชันนั้นยอมรับ
