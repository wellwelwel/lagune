# /lagune: โค้ดปลอดภัยตั้งแต่ตอนที่ AI เขียน

> สร้างสิ่งที่คุณขอและเสริมความปลอดภัยไปพร้อมกับตอนเขียนโค้ด โดยมี charter เป็นแนวทาง และไม่ต้องทำตามเวิร์กโฟลว์ใด

Canonical: https://lagune.ai/th-TH/docs/commands/lagune
ภาษา: th-TH
ต้นฉบับ: https://lagune.ai/docs/commands/lagune
อัปเดตล่าสุด: 2026-11-09

⌨️ ทำงานที่คุณขอ โดยเสริมความปลอดภัยไปพร้อมกับตอนเขียน **`/lagune`** รับ prompt ใดก็ได้ในทุกช่วงของงาน สร้างสิ่งที่คุณต้องการ และเสริมความปลอดภัยด้วยค่าเริ่มต้นที่ปลอดภัยก่อนส่งงานคืนให้คุณ

## วิธีใช้

ใส่ **`/lagune`** ไว้ใน prompt ใดก็ได้ แล้วอธิบายงานตามที่คุณทำเป็นปกติ

**📘 คำสั่งสำหรับเอเจนต์**

```md
# คำสั่งของโปรเจกต์ฉันสำหรับเอเจนต์

<!-- ... -->

## ความปลอดภัย

- ทุกครั้งที่คุณสร้างหรือแก้ไขโค้ด ให้ใช้ skill `/lagune` ([**lagune.ai**](https://lagune.ai/llms.txt)) ซึ่งมีชื่อว่า `/lagune:lagune` เมื่อติดตั้งเป็นปลั๊กอิน เพื่อให้ความปลอดภัยดีขึ้นตั้งแต่ค่าเริ่มต้น
```

    - ตัวอย่างเช่น **AGENTS.md**, **CLAUDE.md**, **.github/copilot-instructions.md**, **.cursorrules** และอื่น ๆ

**💬 ฟีเจอร์**

```prompt
/lagune ให้ผู้ใช้อัปโหลดรูปของตัวเองในหน้าโปรไฟล์ได้
```

**💬 การแก้บั๊ก**

```prompt
/lagune ผู้ใช้กดส่งฟอร์มแล้วไม่มีอะไรเกิดขึ้น ช่วยหาสาเหตุแล้วแก้ไขให้
```

**💬 การรีแฟกเตอร์**

```prompt
/lagune แยกส่วนและปรับปรุงลอจิกของ payload
```

**ไม่มี charter ก็ใช้ได้ แต่มีจะดีกว่า**

**`/lagune`** ทำงานได้ทั้งแบบมีและไม่มี charter ถ้ามี กฎของโปรเจกต์คุณเองจะกำหนดทิศทางของงานทุกชิ้นที่สร้าง ตั้งกฎเหล่านั้นครั้งเดียวด้วย [`/lagune-charter`](https://lagune.ai/th-TH/docs/commands/charter)

## หลักการทำงาน

คำสั่งนี้ครอบงานไว้ด้วย 3 ขั้นตอน โดยไม่เขียนอะไรลงใน Lagune เลย:

1. โหลด charter ของคุณถ้ามีอยู่ และใช้หลักการด้านความปลอดภัยในนั้นกำกับงานทั้งหมด ถ้าคุณยังไม่มี ก็ใช้เกณฑ์พื้นฐานที่ปลอดภัยตั้งแต่ค่าเริ่มต้นแทน
2. แสดง [แคตตาล็อก](https://lagune.ai/th-TH/docs/catalog) ของโปรเจกต์คุณ แล้วโหลดเฉพาะความรู้เฉพาะทางที่งานของคุณเกี่ยวข้อง ซึ่งเป็นความรู้ชุดเดียวกับที่เวิร์กโฟลว์การตรวจสอบโหลดเฉพาะเมื่อจำเป็น
3. ใส่การป้องกันลงไปขณะเขียนโค้ด แล้วอ่านผลงานของตัวเองอีกรอบเพื่อยืนยันว่ามาตรการควบคุมใช้ได้จริงก่อนส่งงานคืน

ผลลัพธ์คือโค้ดที่ใช้งานได้ในโปรเจกต์ของคุณ และปลอดภัยตั้งแต่บรรทัดแรก

**ใช้ได้ทุกเมื่อ**

ไม่ต้องมี detect ไม่ต้องมี plan และไม่ต้องตามเก็บงานทีหลัง **`/lagune`** เหมาะทั้งกับโปรเจกต์ที่เพิ่งตั้งต้นและการแก้ไขในโค้ดเบสที่โตเต็มที่แล้ว และเสริมความปลอดภัยไประหว่างทำงาน ไม่ใช่ทีหลัง

## สิ่งที่คำสั่งนี้ไม่ทำ

- ไม่เขียนอะไรลงในไดเรกทอรี `.lagune` ทั้งอาร์ติแฟกต์และการติดตาม สิ่งเดียวที่ได้จึงเป็นโค้ดที่เสริมความปลอดภัยแล้วตามที่คุณขอ
- ไม่ลดทอนกฎเพื่อให้ตรงกับ prompt ถ้าสิ่งที่คุณขอจะขัดกับหลักการใน charter คำสั่งนี้จะหยุดและแจ้งคุณก่อน แทนที่จะสร้างแบบไม่ปลอดภัยไปเลย

## คำถามที่พบบ่อย

### /lagune ทำอะไร

รับ prompt ใดก็ได้ในทุกช่วงของงาน สร้างสิ่งที่คุณขอ และเสริมความปลอดภัยด้วยค่าเริ่มต้นที่ปลอดภัยก่อนส่งงานคืน โดยใส่การป้องกันลงไปขณะเขียนโค้ด ไม่ใช่ทีหลัง

### ต้องมี charter ก่อนถึงจะใช้ /lagune ได้ไหม

ไม่ต้อง คำสั่งนี้ทำงานได้ทั้งแบบมีและไม่มี charter ถ้ามี กฎของโปรเจกต์คุณเองจะกำหนดทิศทางของงานทุกชิ้นที่สร้าง ถ้าไม่มี ก็ใช้เกณฑ์พื้นฐานที่ปลอดภัยตั้งแต่ค่าเริ่มต้นแทน

### /lagune ต่างจากขั้นตอนแบบ Blue Team อย่างไร

/lagune ทำให้งานใหม่ปลอดภัยไปพร้อมกับตอนที่คุณเขียน โดยไม่ต้องทำตามเวิร์กโฟลว์ใด ส่วนขั้นตอนแบบ Blue Team จะรันเฟสการตรวจสอบทั้ง 5 เฟสตามลำดับกับโปรเจกต์ที่มีอยู่แล้ว

### /lagune ติดตามข้อตรวจพบหรือเขียนอาร์ติแฟกต์ไหม

ไม่ คำสั่งนี้ไม่เขียนอะไรลงในไดเรกทอรี .lagune ทั้งอาร์ติแฟกต์และการติดตาม สิ่งเดียวที่ได้คือโค้ดที่เสริมความปลอดภัยแล้วตามที่คุณขอ

### ทำอย่างไรให้เอเจนต์ใช้ /lagune เองโดยอัตโนมัติ

เพิ่มคำสั่งลงในไฟล์คำสั่งของเอเจนต์ (AGENTS.md, CLAUDE.md, .cursorrules และไฟล์ทำนองเดียวกัน) ให้เอเจนต์ใช้ skill /lagune ทุกครั้งที่สร้างหรือแก้ไขโค้ด
