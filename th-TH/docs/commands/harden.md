# /lagune-harden: นำการแก้ไขด้านความปลอดภัยไปใช้กับโค้ดของคุณ

> นำการแก้ไขจากแผนไปใช้กับโค้ดของคุณอย่างปลอดภัย ทีละรายการ

Canonical: https://lagune.ai/th-TH/docs/commands/harden
ภาษา: th-TH
ต้นฉบับ: https://lagune.ai/docs/commands/harden
อัปเดตล่าสุด: 2026-11-07

🔧 นำการแก้ไขจากแผนไปใช้กับโค้ดของคุณอย่างปลอดภัย ทีละรายการ

## วิธีใช้

**นำไปใช้ทั้งหมด**

```prompt
/lagune-harden
```

**ระบุ path**

```prompt
/lagune-harden src/routes/upload.ts
```

**ตามระดับความสำคัญ**

```prompt
/lagune-harden เฉพาะระดับวิกฤตและสูง
```

## หลักการทำงาน

plan ตัดสินการแก้ไขแต่ละรายการไว้แล้ว harden จึงแค่นำไปใช้ เฟสนี้เป็นเฟสเดียวที่แตะโค้ดของคุณ จึงทำงานอย่างระมัดระวัง: นำการแก้ไขไปใช้ทีละรายการเพื่อให้ตรวจทานการเปลี่ยนแปลงแต่ละครั้งได้ง่าย และไม่ลดทอนมาตรการควบคุมเพื่อให้การแก้ไขลงตัว ตัวอย่างเช่น การแก้ไขเรื่องการอัปโหลด:

- **การอัปโหลดไฟล์** (สถานะ: **Applied**)
  - _สิ่งที่เปลี่ยน:_ ตรวจชนิดจริงและขนาดของไฟล์ ปฏิเสธทุกอย่างที่ไม่ได้คาดไว้ เปลี่ยนชื่อไฟล์ตอนบันทึก และเก็บไว้ในที่ที่รันเป็นโค้ดไม่ได้
  - _ตำแหน่ง:_ ฟังก์ชัน `handleUpload` และ helper สำหรับจัดเก็บที่ฟังก์ชันนี้เรียกใช้

ถ้านำการแก้ไขไปใช้ได้ไม่ครบ harden จะทำส่วนที่ทำได้อย่างปลอดภัย แล้วทำเครื่องหมายส่วนที่เหลือเป็น **Partial** หรือ **Blocked** โดยเปิดค้างไว้

**นำไปใช้แล้วยังไม่เท่ากับผ่านการพิสูจน์**

Applied ยังไม่ได้แปลว่าพิสูจน์แล้ว นั่นคือหน้าที่ของ [verify](https://lagune.ai/th-TH/docs/commands/verify)

**เคล็ดลับ**

- คำสั่งนี้สร้างต่อจากแผนทั้งหมด ถ้าการแก้ไขหรือไฟล์ใดยังไม่เคยอยู่ในแผน คำสั่งนี้จะบอกให้คุณรัน `/lagune-plan` กับสิ่งนั้นก่อน
- รันซ้ำเพื่อปรับบันทึกให้ตรงกับสภาพปัจจุบัน: การเปลี่ยนแปลงที่ถูกย้อนกลับจะหายไป และการแก้ไขที่เพิ่งนำไปใช้จะเข้ามา
- บันทึก hardening อยู่ที่ `.lagune/memory/harden.md`

**ต้องรัน plan ก่อน และจะแก้ไขโค้ดของคุณ**

harden สร้างต่อจาก [`/lagune-plan`](https://lagune.ai/th-TH/docs/commands/plan) และเป็นเฟสเดียวที่แก้ไขโค้ดของคุณ

## ถัดไป

พิสูจน์ว่าการแก้ไขแต่ละรายการใช้ได้จริง: [`/lagune-verify`](https://lagune.ai/th-TH/docs/commands/verify)

## คำถามที่พบบ่อย

### /lagune-harden แก้ไขโค้ดของฉันไหม

ใช่ เป็นเฟสเดียวที่แตะโค้ดของคุณ โดยนำการแก้ไขจากแผนไปใช้ทีละรายการ

### Applied, Partial และ Blocked หมายถึงอะไร

เป็นสถานะที่ Lagune บันทึกให้การแก้ไขแต่ละรายการ Applied หมายถึงแก้ไขแล้ว Partial หมายถึงแก้ไขได้เพียงบางส่วน และ Blocked หมายถึงนำการแก้ไขไปใช้ไม่ได้ Applied ยังไม่ได้แปลว่าพิสูจน์แล้ว

### Lagune นำการแก้ไขไปใช้โดยไม่ถามก่อนไหม

การแก้ไขโค้ดแต่ละครั้งต้องรอให้คุณอนุมัติหรือไม่ ขึ้นอยู่กับเอเจนต์และโหมดสิทธิ์ที่คุณใช้รัน ไม่ใช่ Lagune ซึ่งไม่ได้เพิ่มขั้นตอนยืนยันของตัวเอง แต่ Lagune ก็ไม่ลดทอนมาตรการควบคุมเพื่อให้การแก้ไขลงตัว และถ้าการแก้ไขใดจะขัดกับกฎใน charter ก็จะหยุดและแจ้งคุณก่อน
