# /lagune-specialize: สร้างความรู้เฉพาะทางด้านความปลอดภัยด้วยข้อความธรรมดา

> กลั่นกรองแหล่งข้อมูลหรือหัวข้อด้านความปลอดภัยที่คุณให้มา ให้เป็นความรู้เฉพาะทางใหม่ที่โหลดเฉพาะเมื่อจำเป็น

Canonical: https://lagune.ai/th-TH/docs/commands/specialize
ภาษา: th-TH
ต้นฉบับ: https://lagune.ai/docs/commands/specialize
อัปเดตล่าสุด: 2026-11-07

🎓 สอนความรู้เฉพาะทางใหม่ให้ **Lagune** จากแหล่งข้อมูลหรือหัวข้อที่คุณให้มา

คำสั่งนี้อ่านเนื้อหาแล้วกลั่นกรองให้เป็นความรู้เฉพาะทางที่เจาะจงและใช้เพื่อการป้องกันเท่านั้น โดยมีรูปแบบเหมือน [ความรู้เฉพาะทางในตัว](https://lagune.ai/th-TH/docs/catalog) ทุกประการ เฟส detect และ verify จึงโหลดไปใช้ได้เหมือนรายการอื่น ๆ คำสั่งนี้ทำได้แค่ตรวจสอบและอธิบาย: ไม่เขียนอินพุตสำหรับโจมตีหรือ exploit และไม่แตะต้องโค้ดของคุณ

**จากบทความ**

```prompt
# ลิงก์หรือแหล่งอ้างอิง: Lagune กลั่นกรองให้เป็นการป้องกัน
/lagune-specialize https://owasp.org/www-community/attacks/SQL_Injection
```

**จาก exploit**

```prompt
# ใช้การโจมตีเป็นแหล่งข้อมูล: ความรู้เฉพาะทางที่ได้ยังเป็นการป้องกัน
/lagune-specialize "' OR 1=1 -- แทรก SQL เข้าไปในข้อความของ query"
```

**จากหัวข้อ**

```prompt
# หรือแค่บอกว่าต้องการให้ครอบคลุมเรื่องอะไร
/lagune-specialize SQL injection
```

**การโจมตีเป็นแหล่งข้อมูลได้ แต่ไม่มีวันเป็นผลลัพธ์**

ชี้คำสั่งนี้ไปที่การโจมตีได้ถ้าเป้าหมายคือป้องกันการโจมตีนั้น: บทความที่อธิบาย exploit เป็นเนื้อหาให้ศึกษา ซึ่งคำสั่งนี้กลั่นกรองให้เป็นการป้องกัน ความรู้เฉพาะทางที่ได้จะตรวจสอบและอธิบายเสมอ และไม่สร้าง exploit ที่ใช้งานได้จริง payload หรือวิธีหลบเลี่ยงการตรวจจับ

## สิ่งที่คำสั่งนี้เขียน

ผลลัพธ์คือไฟล์ 2 ไฟล์ในโปรเจกต์ของคุณ ซึ่ง commit และตรวจทานไปพร้อมกับโค้ดของคุณได้:

- ความรู้เฉพาะทางที่ `.lagune/catalog/<name>.md` ซึ่งมีรูปแบบเหมือน [ความรู้เฉพาะทางในตัว](https://lagune.ai/th-TH/docs/catalog)
- รายการของความรู้นั้นใน `.lagune/configs.json` ซึ่งเป็นที่ที่โปรเจกต์ของคุณทำดัชนีความรู้เฉพาะทางของตัวเอง เพื่อให้แคตตาล็อกรวมเข้ากับรายการในตัว

จากนั้นคำสั่งนี้จะแสดงแคตตาล็อกเพื่อยืนยันว่ามีรายการใหม่อยู่แล้ว ความรู้เฉพาะทางของคุณเองอยู่ในแคตตาล็อกเสมอ ไม่ว่าแคตตาล็อกจะมีหมวดหมู่ใด คุณไม่ต้องเพิ่มคำสั่งหรือแตะต้องแพ็กเกจ: ความรู้เฉพาะทางใหม่คือไฟล์ความรู้หนึ่งไฟล์กับรายการดัชนีหนึ่งรายการ ซึ่งเขียนลงในโปรเจกต์ของคุณเอง

## ปรับปรุง ไม่ใช่เขียนทับ

การสร้างความรู้เฉพาะทางด้วยชื่อที่มีอยู่แล้ว ไม่ว่าจะเป็นรายการในตัวอย่าง `regex` หรือรายการที่คุณเคยสร้างไว้ จะ **ปรับไฟล์เดิมให้ตรงกับสภาพปัจจุบัน** แทนการแทนที่ไฟล์ คำสั่งนี้อ่านสิ่งที่มีอยู่ ผสานความรู้ใหม่เข้าไป เก็บส่วนที่ยังใช้ได้ และเขียนส่วนที่เปลี่ยนไปใหม่ คำสั่งนี้ไม่ทิ้งอะไรโดยไม่ได้อ่านก่อน ความรู้เฉพาะทางของคุณจะแทนที่รายการในตัวที่ชื่อเดียวกัน คุณจึงปรับรายการในตัวให้คมขึ้นสำหรับโปรเจกต์ของคุณเองได้โดยไม่สูญเสียรายการนั้น

**เคล็ดลับ**

- ความรู้เฉพาะทางใหม่โหลดเหมือนรายการในตัวทุกประการ: เฟส detect และ verify หยิบไปใช้เฉพาะเมื่อจำเป็น หรือคุณโหลดเองด้วย `npx lagune read catalog <name>` แล้วมอบงานให้
- เมื่อเนื้อหามีที่มาที่ระบุได้ (บทความ ผู้เขียน ลิงก์ หรือมาตรฐาน) ความรู้เฉพาะทางจะให้เครดิตที่มานั้น ส่วนหัวข้อเปล่า ๆ จะไม่มีแหล่งที่มา

**หมายเหตุ**

**คำสั่งนี้รันเฉพาะเมื่อคุณเรียกใช้เท่านั้น:** เอเจนต์ไม่เริ่มรันเอง

## คำถามที่พบบ่อย

### เพิ่มความรู้เฉพาะทางด้านความปลอดภัยของตัวเองได้อย่างไร

รัน /lagune-specialize พร้อมแหล่งข้อมูลหรือหัวข้อ คำสั่งนี้จะกลั่นกรองให้เป็นความรู้เฉพาะทางเพื่อการป้องกันเท่านั้น เขียนลงใน .lagune/catalog/<name>.md พร้อมรายการใน .lagune/configs.json

### Lagune เรียนรู้จากบทความที่อธิบาย exploit ได้ไหม

ได้ ในฐานะแหล่งข้อมูล แต่ไม่มีวันเป็นผลลัพธ์ การโจมตีเป็นแหล่งข้อมูลได้ แต่ไม่มีวันเป็นสิ่งที่สร้างออกมา specialize ไม่เขียนอินพุตสำหรับโจมตีหรือ exploit

### specialize เขียนทับความรู้เฉพาะทางในตัวไหม

ไม่ คำสั่งนี้ปรับปรุง ไม่ใช่เขียนทับ
