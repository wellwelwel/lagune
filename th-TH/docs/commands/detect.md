> อ่านโค้ดของคุณ แล้วทำแผนผังว่าระบบทำอะไรบ้างและความเสี่ยงอยู่ตรงไหน

🔬 รู้ว่าระบบของคุณทำอะไรจริง ๆ และความเสี่ยงอยู่ตรงไหน

detect อ่านโค้ดและบันทึกเฉพาะสิ่งที่พบจริง พร้อมหลักฐานที่เฟสถัดไปต้องใช้ หลักที่กำกับเฟสนี้คือการตรวจหา ไม่ใช่การแต่งขึ้นเอง

## วิธีใช้

**สแกนทั้งโปรเจกต์**

```prompt
/lagune-detect
```

**ระบุ path**

```prompt
/lagune-detect src/routes/ src/auth.ts
```

**อธิบายข้อกังวล**

```prompt
/lagune-detect ตรวจให้แน่ใจว่าข้อมูลลูกค้าไม่มีทางรั่วไหล
```

## สิ่งที่คำสั่งนี้ทำแผนผัง

**Lagune** อ่านโค้ดและทำแผนผังสิ่งที่พบ ข้อตรวจพบแต่ละรายการบอกว่าคืออะไร ทำไมจึงสำคัญ และมีหลักฐานอะไร ตัวอย่างเช่น:

- **การอัปโหลดไฟล์** ระบบรับไฟล์จากผู้ใช้:
  - _ทำไมจึงสำคัญ:_ ไฟล์ที่ปลอมตัวเป็นรูปภาพอาจซ่อนโค้ดอันตรายไว้
  - _หลักฐาน:_ handler `POST /upload` เชื่อ MIME type ที่ไคลเอนต์ส่งมา โดยไม่ตรวจชนิดจริงของไฟล์
- **การล็อกอินและเซสชัน** ผู้ใช้ล็อกอินเพื่อเข้าบัญชีของตัวเอง:
  - _ทำไมจึงสำคัญ:_ การจัดการเซสชันที่อ่อนแอทำให้บัญชีหนึ่งถูกอีกบัญชีหนึ่งยึดได้
  - _หลักฐาน:_ ลอจิกการออกเซสชัน ซึ่งออกเซสชันโดยไม่กำหนดเวลาหมดอายุ

ระหว่างนั้น detect จะให้ผลตัดสินกับความรู้เฉพาะทางทุกรายการใน [แคตตาล็อก](https://lagune.ai/th-TH/docs/catalog) ของโปรเจกต์คุณโดยเทียบกับโค้ด นำรายการที่มีบริบทตรงกับโปรเจกต์ไปใช้ และบันทึกไว้ใต้ **Applied specializations** ซึ่งเป็นรายการที่ harden และ verify นำกลับมาใช้

จากนั้นคุณจะได้แผนผังที่ชัดเจนว่าระบบทำอะไรบ้างและความเสี่ยงอยู่ตรงไหน พร้อมให้ขั้นตอนถัดไปลงมือ

**เคล็ดลับ**

- รันซ้ำเพื่ออัปเดตแผนผัง: ข้อตรวจพบที่แก้แล้วจะหายไป และข้อตรวจพบใหม่จะเข้ามา
- แผนผังจาก detect อยู่ที่ `.lagune/memory/detect.md`

## ถัดไป

เปลี่ยนแผนผังเป็นแผน: [`/lagune-plan`](https://lagune.ai/th-TH/docs/commands/plan)

## คำถามที่พบบ่อย

### /lagune-detect ทำอะไร

อ่านโค้ดของคุณและทำแผนผังว่าระบบทำอะไรบ้างและความเสี่ยงอยู่ตรงไหน โดยบันทึกเฉพาะสิ่งที่พบจริง หลักของคำสั่งนี้คือการตรวจหา ไม่ใช่การแต่งขึ้นเอง

### ข้อตรวจพบใน Lagune คืออะไร

ข้อตรวจพบคือความเสี่ยงหนึ่งรายการที่ตรวจพบ ซึ่งบอกว่าคืออะไร ทำไมจึงสำคัญ และมีหลักฐานอะไรในโค้ด เป็นหน่วยที่ติดตามและส่งต่อไปยัง plan, harden และ verify

### แผนผังจาก detect เก็บไว้ที่ไหน

ที่ .lagune/memory/detect.md

### detect ใช้ความรู้เฉพาะทางรายการไหนบ้าง

ความรู้เฉพาะทางทุกรายการในแคตตาล็อกของโปรเจกต์คุณจะได้รับผลตัดสินโดยเทียบกับโค้ด detect นำรายการที่มีบริบทตรงกับโปรเจกต์ไปใช้ และบันทึกไว้ใต้ Applied specializations
