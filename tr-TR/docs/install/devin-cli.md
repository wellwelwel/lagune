# Devin CLI için Lagune eklentisi kurulumu

> Lagune'yi Devin CLI için eklenti olarak kurun ve güncel tutun.

Kanonik URL: https://lagune.ai/tr-TR/docs/install/devin-cli
Dil: tr-TR
Orijinal: https://lagune.ai/docs/install/devin-cli
Son güncelleme: 2026-11-03

**Devin** hesabınıza giriş yapın, ardından eklentiyi terminalden kurun:

```bash
devin auth login
devin plugins install wellwelwel/lagune
```

## Güncelleme

**Lagune**'yi güncellemek için şunu çalıştırın:

```bash
devin plugins update lagune
```

## Komutlar

Komutları eklentinin adıyla birlikte yazın, örneğin `/lagune:lagune-charter` yazarak `/lagune-charter` komutunu çalıştırın. `/` menüsü de onları listeler.
