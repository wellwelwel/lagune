# Kimi Code için Lagune eklentisi kurulumu

> Lagune'yi Kimi Code için eklenti olarak kurun ve güncel tutun.

Kanonik URL: https://lagune.ai/tr-TR/docs/install/kimi-code
Dil: tr-TR
Orijinal: https://lagune.ai/docs/install/kimi-code
Son güncelleme: 2026-11-05

Eklentiyi bir **Kimi Code** oturumundan kurun, **Trust and install** seçeneğini seçin, ardından eklentiyi yüklemek için yeni bir oturum başlatın:

```text
/plugins install https://github.com/wellwelwel/lagune
/new
```

## Güncelleme

**Lagune**'yi güncellemek için yeniden kurun:

```text
/plugins install https://github.com/wellwelwel/lagune
/new
```

## Komutlar

Komutları eklentinin adıyla birlikte yazın, örneğin `/lagune:lagune-charter` yazarak `/lagune-charter` komutunu çalıştırın. `/` menüsü onları `/skill:lagune:lagune-charter` biçiminde listeler ve bu biçim de çalışır.

## Sıkça sorulan sorular

### Kimi Code için Lagune nasıl kurulur?

Bir Kimi Code oturumunda /plugins install https://github.com/wellwelwel/lagune komutunu çalıştırın, Trust and install seçeneğini seçin, ardından /new komutunu çalıştırın.

### Kimi Code kullanırken Lagune nasıl güncellenir?

/plugins install https://github.com/wellwelwel/lagune komutunu yeniden, ardından /new komutunu çalıştırın.

### Kimi Code kullanırken Lagune komutları nasıl çalıştırılır?

Eklentinin adıyla birlikte, örneğin /lagune:lagune-charter şeklinde ya da / menüsünün listelediği gibi, örneğin /skill:lagune:lagune-charter şeklinde yazın.
