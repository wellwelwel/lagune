# Встановлення Lagune у будь-який агент через skills.sh

> Встановіть Lagune у будь-який ШІ-агент через CLI skills і підтримуйте його оновленим.

Канонічна URL-адреса: https://lagune.ai/uk-UA/docs/install/universal
Мова: uk-UA
Оригінал: https://lagune.ai/docs/install/universal
Останнє оновлення: 2026-11-03

**Термінал**

Встановіть команди **Lagune** з термінала через [**skills.sh**](https://www.skills.sh/wellwelwel/lagune):

```bash
npx skills add wellwelwel/lagune
```

**Промпт**

Вставте цей промпт у свій агент:

```md
Виконай `npx --yes skills add wellwelwel/lagune` і просто зараз дотримуйся згенерованих інструкцій навички. Прочитай увесь її вивід, за потреби спершу перенаправивши його в тимчасовий файл. Розв'язуй відносні шляхи від каталогу допоміжних файлів, який вона надає.
```

## Оновлення

**Термінал**

Щоб оновити **Lagune**, виконайте:

```bash
npx skills update
```

**Промпт**

Щоб оновити **Lagune**, вставте цей промпт у свій агент:

```md
Виконай `npx --yes skills update -y` і прочитай увесь її вивід, за потреби спершу перенаправивши його в тимчасовий файл.
```

---

**Один спосіб на агента**

Встановлюйте **Lagune** або через **skills.sh**, або через його **плагін**, але ніколи обома способами.

**Дозволи**

Команди запускають рушій як `npx --yes lagune@0.18.0`, а [сторінка встановлення кожного агента](https://lagune.ai/uk-UA/docs) показує правило, що дозволяє його заздалегідь. У пісочниці без доступу до мережі встановіть рушій у свій проєкт із власного термінала, один раз і після кожного оновлення:

```bash
npm i -D lagune@0.18.0
```

## Часті запитання

### Як встановити Lagune у будь-який ШІ-агент?

Виконайте npx skills add wellwelwel/lagune у своєму проєкті або вставте промпт для встановлення у свій агент.

### Як оновити Lagune, встановлений через CLI skills?

Виконайте npx skills update або вставте промпт для оновлення у свій агент.

### Чи можна встановити Lagune і через CLI skills, і через плагін?

Ні. Якщо встановити обома способами, агент показує кожну команду двічі або використовує одну копію й приховує іншу.
