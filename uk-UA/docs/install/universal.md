# Встановлення Lagune у будь-який агент через skills.sh або GitHub CLI

> Встановіть Lagune у будь-який ШІ-агент через CLI skills або GitHub CLI і підтримуйте його оновленим.

Канонічна URL-адреса: https://lagune.ai/uk-UA/docs/install/universal
Мова: uk-UA
Оригінал: https://lagune.ai/docs/install/universal
Останнє оновлення: 2026-11-09

**skills.sh**

Встановіть команди **Lagune** у свій проєкт із термінала через [**skills.sh**](https://www.skills.sh/wellwelwel/lagune):

```bash
npx skills add wellwelwel/lagune -y
```

Або вставте цей промпт у свій агент:

```md
Виконай `npx --yes skills add wellwelwel/lagune --yes` і одразу дотримуйся згенерованих інструкцій навички. Прочитай увесь вивід команди, за потреби спершу перенаправивши його в тимчасовий файл. Розв'язуй відносні шляхи від каталогу допоміжних файлів, який вона надає.
```

**GitHub CLI**

Встановіть команди **Lagune** у свій проєкт із термінала через [**GitHub CLI**](https://cli.github.com/) версії 2.90.0 або новішої:

```bash
gh skill install wellwelwel/lagune --all --scope project
```

Або вставте цей промпт у свій агент:

```md
Виконай `gh skill install wellwelwel/lagune --all --scope project` і прочитай увесь вивід, за потреби спершу перенаправивши його в тимчасовий файл.
```

## Оновлення

**skills.sh**

Щоб оновити **Lagune**, виконайте:

```bash
npx skills update
```

Або вставте цей промпт у свій агент:

```md
Виконай `npx --yes skills update -y` і прочитай увесь вивід, за потреби спершу перенаправивши його в тимчасовий файл.
```

**GitHub CLI**

Щоб оновити **Lagune**, виконайте:

```bash
gh skill update --all
```

Або вставте цей промпт у свій агент:

```md
Виконай `gh skill update --all` і прочитай увесь вивід, за потреби спершу перенаправивши його в тимчасовий файл.
```

---

**Пісочниця**

У пісочниці без доступу до мережі команди не можуть завантажити рушій. Встановіть його у свій проєкт із власного термінала, один раз і після кожного оновлення:

```bash
npm i -D lagune@0.18.2
```

## Часті запитання

### Як встановити Lagune у будь-який ШІ-агент?

Виконайте у своєму проєкті npx skills add wellwelwel/lagune -y чи gh skill install wellwelwel/lagune --all --scope project або вставте промпт для встановлення у свій агент.

### Як оновити Lagune у будь-якому ШІ-агенті?

Якщо ви встановили Lagune через skills.sh, виконайте npx skills update, а якщо через GitHub CLI, виконайте gh skill update --all. Також можна вставити промпт для оновлення у свій агент.

### Чи можна встановити Lagune кількома способами одночасно?

Ні. Якщо встановити двома способами, агент показує кожну команду двічі або використовує одну копію й приховує іншу.
