# Встановлення Lagune у Kimi Code як плагіна

> Встановіть Lagune у Kimi Code як плагін і підтримуйте його оновленим.

Канонічна URL-адреса: https://lagune.ai/uk-UA/docs/install/kimi-code
Мова: uk-UA
Оригінал: https://lagune.ai/docs/install/kimi-code
Останнє оновлення: 2026-11-05

Встановіть плагін із сесії **Kimi Code**, виберіть **Trust and install**, а потім почніть нову сесію, щоб завантажити його:

```text
/plugins install https://github.com/wellwelwel/lagune
/new
```

## Оновлення

Щоб оновити **Lagune**, встановіть його знову:

```text
/plugins install https://github.com/wellwelwel/lagune
/new
```

## Команди

Вводьте команди з назвою плагіна, як-от `/lagune:lagune-charter` для `/lagune-charter`. Меню `/` показує їх як `/skill:lagune:lagune-charter`, і така форма теж працює.

## Часті запитання

### Як встановити Lagune у Kimi Code?

У сесії Kimi Code виконайте /plugins install https://github.com/wellwelwel/lagune, виберіть Trust and install, а потім виконайте /new.

### Як оновити Lagune у Kimi Code?

Знову виконайте /plugins install https://github.com/wellwelwel/lagune, а потім /new.

### Як запускати команди Lagune у Kimi Code?

Вводьте їх з назвою плагіна, як-от /lagune:lagune-charter, або так, як їх показує меню /, як-от /skill:lagune:lagune-charter.
