# Встановлення Lagune в Hermes Agent як плагіна

> Встановіть Lagune в Hermes Agent як плагін і підтримуйте його оновленим.

Канонічна URL-адреса: https://lagune.ai/uk-UA/docs/install/hermes-agent
Мова: uk-UA
Оригінал: https://lagune.ai/docs/install/hermes-agent
Останнє оновлення: 2026-11-03

Встановіть плагін із термінала:

```bash
hermes plugins install wellwelwel/lagune --enable
```

- Коли **Hermes Agent** попросить підтвердити плагін не з його каталогу, **підтвердьте**.
- Коли він запропонує встановити залежності **Node.js** з репозиторію, **відмовтеся**.

## Оновлення

Щоб оновити **Lagune**, виконайте:

```bash
hermes plugins update lagune
```

## Команди

Вводьте команди з назвою плагіна, як-от `/lagune:lagune-charter` для `/lagune-charter` і `/lagune:lagune` для `/lagune`.

## Часті запитання

### Як встановити Lagune в Hermes Agent?

Виконайте hermes plugins install wellwelwel/lagune --enable. Підтвердьте плагін, коли попросять, і відмовтеся від встановлення залежностей Node.js з репозиторію.

### Як оновити Lagune в Hermes Agent?

Виконайте hermes plugins update lagune.

### Як запускати команди Lagune в Hermes Agent?

Вводьте їх з назвою плагіна, як-от /lagune:lagune-charter і /lagune:lagune.
