# Встановлення Lagune в Devin CLI як плагіна

> Встановіть Lagune в Devin CLI як плагін і підтримуйте його оновленим.

Канонічна URL-адреса: https://lagune.ai/uk-UA/docs/install/devin-cli
Мова: uk-UA
Оригінал: https://lagune.ai/docs/install/devin-cli
Останнє оновлення: 2026-11-03

Увійдіть у **Devin**, а потім встановіть плагін із термінала:

```bash
devin auth login
devin plugins install wellwelwel/lagune
```

## Оновлення

Щоб оновити **Lagune**, виконайте:

```bash
devin plugins update lagune
```

## Команди

Вводьте команди з назвою плагіна, як-от `/lagune:lagune-charter` для `/lagune-charter`. Меню `/` також показує їх.

## Часті запитання

### Як встановити Lagune в Devin CLI?

Увійдіть за допомогою devin auth login, а потім виконайте devin plugins install wellwelwel/lagune.

### Як оновити Lagune в Devin CLI?

Виконайте devin plugins update lagune.

### Як запускати команди Lagune в Devin CLI?

Вводьте їх з назвою плагіна, як-от /lagune:lagune-charter. Меню / також показує їх.
