# Встановлення Lagune у GitHub Copilot CLI як плагіна

> Встановіть Lagune у GitHub Copilot CLI як плагін і підтримуйте його оновленим.

Канонічна URL-адреса: https://lagune.ai/uk-UA/docs/install/github-copilot-cli
Мова: uk-UA
Оригінал: https://lagune.ai/docs/install/github-copilot-cli
Останнє оновлення: 2026-11-05

Встановіть плагін із термінала:

```bash
copilot plugin marketplace add wellwelwel/lagune
copilot plugin install lagune@lagune
```

У редакторі встановіть **Lagune** для **GitHub Copilot** через [**skills.sh**](https://lagune.ai/uk-UA/docs/install/universal).

## Оновлення

Щоб оновити **Lagune**, виконайте:

```bash
copilot plugin marketplace update lagune
copilot plugin update lagune@lagune
```

## Команди

Вводьте команди за назвою, як-от `/lagune-charter`.

## Часті запитання

### Як встановити Lagune у GitHub Copilot CLI?

Виконайте copilot plugin marketplace add wellwelwel/lagune, а потім copilot plugin install lagune@lagune.

### Як оновити Lagune у GitHub Copilot CLI?

Виконайте copilot plugin marketplace update lagune, а потім copilot plugin update lagune@lagune.

### Як запускати команди Lagune у GitHub Copilot CLI?

Вводьте їх за назвою, як-от /lagune-charter.

### Чи можна використовувати Lagune з GitHub Copilot у VS Code?

Так. У VS Code чи іншому редакторі встановіть Lagune через skills.sh замість плагіна.
