```bash
npx lagune
```

## Часті запитання

### Як відкрити дашборд Lagune?

Виконайте npx lagune без підкоманди в корені проєкту. Він запускає огляд .lagune/ наживо на випадковому порту й відкриває його у вашому браузері.

### Чи дашборд приватний?

Так. Він працює лише на вашому комп'ютері, за локальною адресою, до якої не може дістатися жоден інший комп'ютер.

### Чи можна змінювати проєкт з дашборду?

Лише його категорії, з браузера. Усе інше, що показує дашборд, доступне лише для читання.
