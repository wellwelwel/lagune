# Схема конфігурації

> JSON Schema для конфігурації проєкту Lagune, що дає автодоповнення й валідацію у вашому редакторі, за поточною версією Lagune чи із закріпленою версією.

Канонічна URL-адреса: https://lagune.ai/uk-UA/docs/references/configs-schema
Мова: uk-UA
Оригінал: https://lagune.ai/docs/references/configs-schema
Останнє оновлення: 2026-11-05

`.lagune/configs.json` записує [**категорії**](https://lagune.ai/uk-UA/docs/categories), які використовує проєкт, індексує його власні [**спеціалізації**](https://lagune.ai/uk-UA/docs/catalog) і визначає, що пропускають [**перевіряльники**](https://lagune.ai/uk-UA/docs/hooks/configure). Його JSON Schema дає вашому редактору змогу автодоповнювати кожне поле й позначати друкарську помилку чи невідому категорію ще під час редагування файлу.

## Поточна схема

Щоразу, коли **Lagune** записує файл і не знаходить у ньому `$schema`, він спрямовує файл на поточну схему:

```json
{
  "$schema": "https://lagune.ai/schemas/configs.json",
  "categories": ["owasp", "javascript"]
}
```

Ця адреса завжди відповідає поточній версії **Lagune**. Файл, записаний до **Lagune** 0.16.0, отримує її під час наступної зміни, а доти кожна фаза нагадує про це.

## Закріплення версії

Кожен реліз **Lagune**, починаючи з 0.16.0, містить схему в тому вигляді, якою вона була в цій версії, опубліковану в **npm** і доступну через **jsDelivr**. Щоб закріпити версію, вкажіть потрібну версію після `lagune@` в адресі `$schema`:

```json
{
  "$schema": "https://cdn.jsdelivr.net/npm/lagune@0.16.0/schemas/configs.json"
}
```

Версія приймає будь-який діапазон semver:

| Версія              | Схема                          |
| ------------------- | ------------------------------ |
| `0.16.0`            | Схема з 0.16.0                 |
| `0.16.x` або `0.16` | Схема з останнього релізу 0.16 |
| `0.x` або `0`       | Схема з останнього релізу 0.x  |
| `latest`            | Схема з останнього релізу      |

## Часті запитання

### Чи потрібна Lagune схема?

Ні. Схема лише допомагає вашому редактору, а Lagune читає файл однаково з $schema і без нього.

### Чи перезапише Lagune закріплену схему?

Ні. Lagune записує $schema лише тоді, коли у файлі її немає, і зберігає будь-яку задану вами адресу.

### Коли варто закріплювати версію?

Коли проєкт працює з конкретною версією Lagune, щоб ваш редактор перевіряв файл за тим, що приймає ця версія.
